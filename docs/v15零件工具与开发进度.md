# 原生零件工具 v15：第一批实现与待办

这是当前原生助手上的独立开发，没有复制、克隆或移植 codex-creo-mcp 的源代码。依据本机 Creo 10 Pro/TOOLKIT 官方头文件及随 SDK 安装的手册实现。界面仍为进程内 Windows 原生窗口，AI 仍使用本机隐藏 Codex 引擎，无 MCP、浏览器、截图或键鼠模拟。

## 本次已经写入并编译的第一批

| 功能 | 实现范围 |
|---|---|
| 读取零件 | 当前模型身份、子类型、单位、工作目录、包络、体积、Creo 返回的质量 |
| 读取特征 | ID、名称、类型、活动/抑制状态及失败标记 |
| 读取尺寸 | 符号、值、类型、所属特征、关系驱动与反向标记 |
| 读取参数 | 已有模型参数的名称、类型、值、锁定状态 |
| 读取几何 | 边 ID/类型/长度，面 ID/类型/面积 |
| 修改尺寸 | 同一活动特征的 1～8 个普通尺寸；核对实际旧值、所属特征，重生成、读回；失败尝试恢复并验证 |
| 修改参数 | 已有且未锁定的字符串、浮点、整数、布尔模型参数；核对类型及旧值，重生成、读回；失败尝试恢复 |
| 复制 | 创建命名内存副本，拒绝会话与磁盘重名，不自动保存或切换窗口 |
| 重命名 | 当前零件在内存重命名，拒绝重名并读回；不删除原磁盘文件 |
| 显示 | 显示会话内或当前工作目录内的指定零件；仅用户明确要求时切换模型窗口 |
| 抑制/恢复 | 无子特征的普通孔、圆角、倒角、切除；核对 ID/类型/状态并读回 |
| 重生成 | 重生成后检查特征失败状态 |
| 保存 | 用户明确要求时由 Creo 保存，不清理旧版本 |
| STEP 导出 | 用户明确要求时导出到当前工作目录，检查重名和输出文件非空；未验证所有导出几何的等价性 |

上述列表表示源码接入和编译完成，不表示所有路径已经实机验证。已有模板空模型及基础板/圆柱创建沿用原实现；基础拉伸仍不随基准面移动。

## 怎么使用

加载 v15 后可以输入：

- `读取尺寸`、`读取特征`、`读取参数`、`读取几何`、`读取质量`：本地读取，不调用 AI。
- `自检零件工具`：在已有活动零件时运行原生核心自检，不调用 AI。
- “把当前零件中 d5 的尺寸从 80 改为 100，单位毫米”：AI 根据当次真实快照和单位生成操作，不能猜测尺寸。
- “把当前零件 DESCRIPTION 参数改为测试板”：仅当参数存在、类型合适且未锁定时可执行。
- “复制当前零件，副本名 test_board”。
- “显示零件 test_board”。
- “将当前零件重命名为 test_board_2”。
- “保存当前零件”。
- “将当前零件导出 STEP，文件名 test_board_export”。

每次最多执行一项操作；修改并保存、多特征批量修改等复合任务暂不自动串联。修改默认仅保留在内存。新名称限 31 位英文字母、数字、下划线或短横线，不含路径及后缀。

新版本会按本条请求的关键词，选择性发送当前零件的特征、尺寸、参数或几何摘要；普通聊天不附带整张参数/几何表，减少无关上下文。明确要求“详细”“全部”“分析”时展开全表，仍受读取上限约束。旧版只发送模型名。近期对话和长期记忆保存机制保留。

## 写入保护与运行自检

- 请求绑定当次活动模型句柄、名称、版本戳及工作目录；执行时变化则拒绝。
- 尺寸还核对所属特征、原值及关系驱动状态；反向尺寸和负值方向翻转暂不支持。
- 首次修改尺寸、参数或抑制/恢复前，必须在已经加载的助手内通过实际核心自检。自检仅创建一个不显示、不保存的独立模板零件，检查尺寸修改后的体积、退化尺寸失败恢复、中文参数读回及旧值失配拒绝，随后尝试从内存清理测试零件。
- 自检失败则不修改目标零件，并写明失败阶段。自检回执不代表孔、圆角、钣金等后续功能经过验证。
- 源模型已有失败特征时拒绝写入。失败回滚若未能验证，会明确报告，不能声称原模型已经恢复。
- 读取上限：256 个特征、256 个尺寸、64 个模型参数、各 64 个边/面。超限或读取不全会报告；不能据此猜测未列出的数据。
- 不自动重启 Creo，不自动点击插件信任确认，不热替换正在加载的 DLL。

## 加载与回退

`protk.dat` 指向 `codex_native_ai_v15.dll`。退出并重新启动 Creo 后加载；窗口标题应显示 v15。已运行的 v14 不会自动改变。

`protk.before-v15.dat` 保存本次修改前的注册配置，旧 DLL 保留。需要回退时，将该备份内容恢复到 `protk.dat`，下次启动生效。不要移动本目录，否则绝对路径注册会失效。
