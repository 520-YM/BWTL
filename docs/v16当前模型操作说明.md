# v16 当前模型操作修订

v15 增加的是尺寸/参数等工具，没有实现“在当前空零件里拉伸”，装配读取也只取窗口模型并拒绝装配。因此截图中的拒绝是功能限制，不能说成已有实时建模能力。

## 本轮源码修订

- 增加 `CREO_OP EXTRUDE 当前零件名 BOX 长 宽 高 中心孔直径`，以及 `CYLINDER 外径 外径 高 中心孔直径`。输入单位毫米，无孔为0。
- 在当前空实体零件中创建第一个基础拉伸，复用已有基础拉伸后端。目标模型名和句柄保持，不复制模板、不另建零件；保留当前零件的基准和参数。
- 输入“拉伸一个正方体”时，应询问缺少的边长；拿到边长后在当前空实体零件执行。新建独立模型必须明确要求。宿主额外拦截把“当前模型操作”错误转换为 `CREO_PLAN` 的回复。
- 装配环境使用 SDK 的 `ProMdlActiveGet` 识别实际激活的组件。请求绑定窗口模型、操作目标、目标版本及所在装配版本；变化时拒绝旧指令。
- 当前活动组件的尺寸/参数修改和基础拉伸会重生成所在装配。同一零件的多个实例共享模型，修改会影响全部实例。
- 明确说“当前装配/顶层装配/总装配”时，读取窗口装配作为目标。装配本身支持读取、驱动尺寸/参数修改、重生成及保存；不能把装配作为实体零件拉伸。
- 失败时尝试移除本次新增的不完整特征，并检查空零件状态。若回滚未能验证，明确报告，不能声称恢复成功。
- 内置“自检零件工具”已改为先复制一个隐藏空模板，再在这个已存在的测试零件内拉伸；不会显示或保存测试零件。

## 使用

加载后窗口标题应显示 **v16**。当前打开空实体零件时，可以输入：

> 在当前零件拉伸一个边长20毫米的正方体，不新建零件。

装配中请先通过 Creo 正常激活需要编辑的实体零件，再发出指令；不会自动随便挑选组件。

## 仍有的限制

- 当前新增的原位拉伸仅支持空实体零件的第一个基础拉伸；已有实体上继续加料/切除、任意草绘和基准关联拉伸仍未实现。
- 钣金空零件不能用此命令创建板壁。装配组件添加、装配切除等也未实现。
- 基础拉伸位于零件局部XY平面、沿+Z；保留基准，但不随基准面移动。
- 不自动保存，也不会自动重启或操作鼠标键盘。

## 验证与加载

编译链接通过；新增 EXTRUDE 的尺寸、孔径、圆柱一致性、非法数字和多协议冲突测试通过，原有协议及当前/新建路由回归通过。**尚未取得 v16 在实际 Creo 中成功拉伸的回执，不能标记为实机验证通过。**

注册文件 `protk.dat` 指向 `codex_native_ai_v16.dll`，下次重启加载。正在运行的 v15 不会热替换。`protk.before-v16.dat` 保留此前加载配置，旧 DLL 保留。
