# 第 41–50 项高级草绘

适用 BWTL 0.23.0-local.advsketch.1 和本机 Creo Parametric 10.0.0.0。打开普通实体零件，从「插件功能 → 高级草绘」选取命令，填写参数后发送。也可直接描述目标。长度以毫米、角度以度填写。所有写入默认由用户保存。

| 编号 | 功能 | 当前支持的几何与参数 |
| --- | --- | --- |
| 41 | 绘制椭圆 | 输入中心、长短轴全长和旋转角，以精确有理 B 样条表示闭合椭圆 |
| 42 | 绘制长圆槽轮廓 | 输入中心、总长、槽宽和旋转角。总长大于槽宽 |
| 43 | 绘制正多边形 | 支持 3–16 边，尺寸用中心到顶点或中心到边的距离 |
| 44 | 草绘样条 | 支持 3–8 个通过点或 B 样条控制点 |
| 45 | 草绘等距偏移 | 单条直线、圆或圆弧，以及连续凸多边形或由相切直线与圆弧构成的凸闭环。保留源图元 |
| 46 | 草绘镜像 | 围绕指定草绘线镜像一组直线、圆、圆弧、圆锥曲线或样条，保留源图元并生成独立副本 |
| 47 | 草绘修剪与延伸 | 将选定直线端点修剪或延伸至另一条实际直线段上的交点 |
| 48 | 草绘圆角和倒角 | 选择共端点的两条直线，指定圆角半径或等距倒角距离 |
| 49 | 关联投影整条边链 | 2–16 条按顺序列出的实体边或同一特征内的连续曲线段，逐段核对原生关联 |
| 50 | 草绘闭合与自交检查 | 查断点、分叉、重复或重叠和自交。明确要求修复时，可在 0.001–0.25 mm 内合拢唯一配对的普通直线端点 |

例如「在当前零件的 FRONT 平面新建草绘 SLOT_A，RIGHT 为方向参照，绘制中心 (0,0)、总长 30、宽 8、旋转 27 度的长圆槽」。已有草绘可先发送「读取草绘 SLOT_A 的图元编号」，再指定偏移、镜像、修剪或投影。闭合检查会给出实际图元编号和断点位置。间隙修复会复查闭合及重生成。尺寸约束冲突、分叉及无法唯一配对的端点会使操作停止。

原生实现分别维护在 `src/功能/advanced_sketch`。创建使用 Creo 草绘图元，边链用原生投影保留来源。旋转椭圆将四个精确有理二次弧合成一个闭合图元，在 Creo 中读回坐标并核对椭圆方程。[PTC 草绘实体定义](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/korean/creo_toolkit/api/dita/pro2dentdef_h.html) · [PTC 草绘投影](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r12/usascii/creo_toolkit/user_guide/Reference_Entities_and_Use_Edge.html)

高级编辑和轮廓检查支持单个草绘最多 96 个图元。原生验收由 `tests/native_advanced_sketch.c` 在独立 Creo 和临时零件上运行，共 60 项检查。需要回退时，保存工作并正常退出 Creo，再通过 BWTL 安装管理切回 0.23.0-local.modelroute.1。
