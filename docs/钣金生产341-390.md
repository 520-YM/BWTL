# 钣金生产 341–390 开发与验收

这批命令使用 BWTL 自己的 Creo Toolkit 入口。在独立 Creo 进程和测试工作目录里运行，输出以原生特征、实际几何和回执为准。所有尺寸单位为毫米，角度单位为度。涉及零件写入时默认不保存。带编号的面、边和主体均须取自当前模型快照。

其余候选命令由 BWTL_ENABLE_SMX_CANDIDATE 开启。已经独立验收的功能单独接入生产版菜单和聊天。

## 已发布功能

- 第 356 项在 `0.23.0-local.smy.4` 启用。先用 BWTL 将 STEP 导入为普通实体零件，随后选择「插件功能 → 钣金生产 · 导入与复建」，填新副本名、当前实体的大板面和实测板厚。副本转换后要通过外形、表面积、体积与原生展开核对。源件保留，副本默认未保存。已验证等厚平板及一个 90° 折弯的 STEP 来料，复杂来料按实际回执判定。

## 公司数据格式

这些文件使用 UTF-8。字段用空格或制表符分隔，以 # 开头的行为注释。优先读取当前 Creo 工作目录，同名文件不存在时再查 BWTL 的「公司资料 / 公司标准」。生产表需要公司批准的实际数据。测试目录里的材料、版本、孔位和数值只用于验收。

| 文件 | 从左到右的字段 |
| --- | --- |
| BWTL_SMT_TEMPLATES.tsv | 模板键、Creo 模型名、模板版本 |
| BWTL_SMT_MATERIALS.tsv | 材料牌号、标称厚度、实测厚度、表面处理、沿纹向最小内 R、横纹向最小内 R、折弯表标识、材料版本 |
| BWTL_SMT_BENDS.tsv | 牌号、板厚、内 R、角度、加工方式、K 因子、折弯规则版本 |
| BWTL_SMT_STANDARD.tsv | 标准版本、材料版本、折弯规则版本、模板版本 |
| BWTL_SMT_MOUNTS.tsv | 模板键、模板版本、图形、相对 X、相对 Y、宽、辅助尺寸、细节尺寸 |

模板型号必须是可在工作目录加载的空钣金零件。ROUND 的宽是孔径，两个辅助尺寸填 0。SLOT 的宽为总长，辅助尺寸为槽宽，细节尺寸为朝向。D 的宽为直径，辅助尺寸填 0，细节尺寸为削平位置距孔轴的距离。现有参数与即将写入的参数发生冲突时，候选版会拒绝整组写入。

## 重跑独立验收

从 BWTL 源码根目录调用这台机器上的独立验收脚本，选择新的工作目录。测试会启动自己的 Creo 进程，调用 BWTL 原生工具和快照接口，并自行结束该进程。

~~~powershell
& "$env:USERPROFILE/Documents/BWTL-Fieldwork/Run-ProbeHidden.ps1" -Suite Custom -Root (Get-Location).Path -CustomSource (Join-Path (Get-Location) 'tests/native_sheetmetal_production.c') -WorkDirectory "$env:USERPROFILE/Documents/BWTL-Sheetmetal-341-390/recheck"
~~~

检查工作目录中的 production-cases.log 和 machining-result.log。SMX_FAILURES 必须为 0，同时应逐项验证真实结果。无孔或无折弯的读取、无效参照拒绝、参数验证和回滚只作为对应分支的测试。带有效几何的通过用例才计入功能交付。

## 最近一次验收

- 独立 Creo 10 工作目录 native15 的原生测试记录为 95 个检查、92 个通过、3 个失败。失败检查分别是多个独立钣金主体、原生三种拼角避空对比、原生矩形拼角避空。检查数量包含拒绝和回滚用例。
- 对称斜接、偏置斜接和焊缝实测已通过。第一次用贯穿切除时触及对面板壁，去料核对触发了回滚。新实现使用板厚限深，复测通过并保留去料检查。
- 原有钣金功能的 55 项原生检查、11 套回归及隔离脚本通过。当前生产安装仍为 0.23.0-local.asmdelivery.1。

## 本机限制与剩余验收

- Creo 10 的实测中，两个分离的钣金板壁仍返回同一个主体。第 357–358 项的逐主体展开与原生独立主体拆分需要支持多个钣金主体的版本。PTC 的 Toolkit 文档将这项支持标为 Creo 11.0.0.0 起。 [PTC Multibodies in Sheetmetal Design](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/german/creo_toolkit/user_guide/multibodies_in_steetmetal_design.html)
- 闭合件撕裂和展开、分离主体前后的曲面与间隙比对仍需进一步验收。STEP 单折弯样件首次选中了窄端面，转换被拒绝且源件保持原状。改选大板面后复建成功，展开回读到一条折弯线。
- 第 373–374 项的原生避空在当前托盘样件上重生成后没有实际去料，候选版会报告失败并回滚。第 376 项需要带实际重叠区和规定面间隙的样件。第 384 项已读取折后相邻边与展开结果，还需跨弯实际孔槽样件覆盖两类证据。
- 继续开发时保留当前生产版本、回退备份与独立验收目录。逐项记录原生正例及失败保护，按验收通过的功能更新本机。
