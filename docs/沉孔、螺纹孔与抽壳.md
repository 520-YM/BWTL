# BWTL 第 21–25 项

本机版本 `0.23.0-local.holeshell.1`，验收平台为 Creo Parametric 10.0.0.0。打开独立的普通单实体零件，在「智能协作」模式下，从「插件功能 → 实体造型与加工」选择操作。模型由用户保存。

| 项目 | 首批支持范围 | 使用示例 |
|---|---|---|
| 21 台阶沉孔 | 实际平面入口，给出孔位、底孔直径、沉孔直径及台阶深度。底孔可贯穿或指定圆柱钻深。 | 在上表面指定位置创建底孔 Ø6、沉孔 Ø12 深 4 mm 的台阶沉孔，底孔贯穿。 |
| 21 锥形沉头孔 | 实际平面入口，给出孔位、底孔直径、沉头口径及 30°～150° 的锥面夹角。底孔可贯穿或指定圆柱钻深。 | 在上表面指定位置创建底孔 Ø6、沉头 Ø12、夹角 90° 的贯穿沉头孔。 |
| 22 ISO 内螺纹盲孔 | 使用 Creo ISO 孔表选用规格。分别指定有效螺纹深度和圆柱钻深。结果包含 Creo 原生螺纹定义和标注，实体去料为底孔及钻尖。 | 在上表面指定位置创建 ISO M6×1 盲孔，螺纹深 8 mm，圆柱钻深 12 mm。 |
| 23 固定半径圆角 | 1～8 条指定直边，且各边由两个正交平面相交形成。 | 在选定的四条直边做 R1 圆角。 |
| 24 等距离倒角 | 1～8 条指定直边，且各边由两个正交平面相交形成。 | 在选定的四条直边做 1 mm 等距离倒角。 |
| 25 单面向内抽壳 | 一个实际平面开口，均匀壁厚，向内抽壳。 | 去掉顶面作为开口，向内抽壳，壁厚 2 mm。 |

沉孔、沉头孔和螺纹孔沿用正交参照和有符号偏移定位。盲孔钻深量到钻肩，118° 钻尖另占空间。孔型、孔轴、实际圆柱孔壁和去料体积均由 Creo 读回。抽壳检查开口引用、向内方向、壁厚和去料体积。侧面破出、钻尖穿底、规格缺失或壁厚无法成形会返回失败并检查模型恢复情况。

用 `tests/Run-NativeFoundation.ps1 -Suite Machining` 在独立 Creo 中执行验收，查看 `machining-cases.log`、`machining-result.log` 和成功特征的原生元素树。验收包括螺纹粗牙与细牙、正负定位偏移、通孔与盲孔、抽壳后理论体积，以及失败后原特征和体积保留。

回退前保存并正常退出目标 Creo 会话，再使用对应 BWTL 安装管理回退到 `0.23.0-local.sweepblend.1`。已保存的孔和抽壳是 Creo 原生特征。
