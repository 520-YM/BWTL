# 第 241–250 项 装配约束与定位

在 Creo 10 打开目标装配的主表示并退出动态定位。从「BWTL → 插件功能 → 装配约束与定位」选择功能，也可用聊天直接描述。用「读取组件树」区分同型号的多个实例，再读目标实例和基准实例的实际参照。参照 ID 对应当前模型版本，改模后应重新读取。

| 编号 | 功能 | 用法 |
| --- | --- | --- |
| 241 | 读取定位参照 | 读取指定实例或顶层的平面、轴和圆柱面，标出能确认的孔壁。 |
| 242 | 检查定位状态 | 显示约束编号、参照、偏距及 Creo 报告的欠约束状态。 |
| 243 | 固定组件 | 固定普通未约束组件，核对原位置和方向。 |
| 244 | 平面贴合 | 让两面相贴、法向相对。 |
| 245 | 平面平行 | 使两面法向同向，不指定两面间距。 |
| 246 | 平面偏距 | 平面同向，偏距为 Creo 原生有符号毫米值。 |
| 247 | 轴孔同轴 | 两条基准轴或两个圆柱面配对，允许轴向自由度。 |
| 248 | 三面定位 | 两边各选三块正交平面，按顺序同向重合。 |
| 249 | 紧固件定位 | 将同轴和承压面贴合一次写入，允许绕轴转动。 |
| 250 | 修改已有定位偏距 | 先读状态取得 1 起计序号和旧值，只修改该偏距。 |

新增或编辑约束的对象为活动顶层装配中的普通直接零件，参照可来自顶层或已解析的其他组件实例。目标组件与参照采用同一长度单位。固定、三面定位和紧固件定位从未约束的组件开始。已有定位仅在可核对的简单约束内追加或改偏距，复杂约束集、柔性件、替换件、组、阵列成员及有下游依赖的目标暂不写入。偏距使用非零有符号毫米值。

BWTL 重生成装配，读回约束并核对几何。发生失败时核对或恢复原有约束与组件位置。若无法核实恢复，暂停该 Creo 会话的装配写入。模型默认不保存。

## 验收与回退

用带孔底板、同型号支架和圆柱紧固件在独立 Creo 10 会话验证约束及重复实例隔离。回退时保存需要保留的工作，正常退出对应会话，在该会话安装根目录运行 `BWTL-Manage.exe -Rollback`。本次上一版是 `0.23.0-local.seatback.1`。
