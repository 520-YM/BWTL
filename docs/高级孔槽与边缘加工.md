# 第 71–80 项高级孔、槽与边缘加工

本机版本 `0.23.0-local.advmachining.1`，目标为 Creo Parametric 10.0.0.0。入口是「插件功能 → 高级孔、槽与边缘加工」。在当前普通单实体零件中执行，默认不保存。菜单填入需求模板，需补齐实际参照和尺寸；也可直接描述任务。

| 编号 | 功能 | 当前范围与输入 |
| --- | --- | --- |
| 71 | 曲面入口孔 | 圆柱、圆锥入口的径向孔；指定入口面、周向角度基准、轴向定位基准、直径及盲深或贯穿 |
| 72 | 斜孔 | 入口基准点与穿过该点的基准轴、轴正反方向、直径、盲深或贯穿；可先按给定角度建立两点基准轴 |
| 73 | 贯穿螺纹孔 | 平面入口、两个正交定位平面及偏移、Creo ISO 孔表完整规格；原生贯穿螺纹定义与底孔 |
| 74 | 非 ISO 螺纹孔 | 从本机 UNC、UNF 孔表解析完整规格，支持贯穿或有效螺纹深度与盲钻深；未找到规格即拒绝 |
| 75 | 孔口点平 | 入口点、加工轴、座面直径和轴向深度；斜面或曲面入口形成完整圆形平底座面，不附带底孔 |
| 76 | 标准键槽 | 轴外圆或轮毂内孔、同轴坐标系、轴向起点、槽宽、圆头总长度、径向槽深；局部 +Y 为开槽方位 |
| 77 | 轴用／孔用卡簧槽 | 外圆或内孔、同轴坐标系、轴向起点、槽宽和径向深度，生成 360 度矩形环槽 |
| 78 | 变半径圆角 | 一条边在原生参数起点和终点的两个不同半径；当前不含中间半径站位 |
| 79 | 相切边链圆角 | 从一条实体边自动追踪相切链，统一半径；读取并验证实际边链，最多 64 条边 |
| 80 | 不等距与角度倒角 | 一条实体边及真实相邻实体面，指定两个边距，或一个边距与 1–89 度角度 |

规格尺寸必须来自用户提供或确认的标准。键槽与卡簧槽当前不内置标准型号自动查表，不把任意槽尺寸声称为某项标准。螺纹使用 Creo 原生螺纹定义和标注，不建立完整螺旋牙形。其他螺纹系列、任意自由曲面入口和多实体加工不在本批范围。

线性尺寸使用毫米，角度使用度。槽沿同轴坐标系的正 Z 布置，完整位于所选圆柱的轴向范围内；槽深小于圆柱半径。孔径及圆角／倒角尺寸受实体包围尺寸检查，过大的工具尺寸先拒绝再进入内核。位置不明确时先补参数，不用旧聊天中的面、边 ID。

## 定位与示例

「读取高级加工参照」显示当前实体平面、边、圆柱和圆锥轴向数据。基准轴、点和坐标系通过本次参照读取。径向孔使用轴向与角度参照法向的叉积作为角度零方向，不能把输入角度当作全局方位角；加工前核对真实参照。

例如：「给当前轴的外圆开圆头键槽，使用同轴坐标系 SHAFT_CSYS，局部 +Y 方位，正 Z 起点 5 mm，宽 6 mm、总长 25 mm、径向深 3 mm，命名 KEY_A」。孔用槽需指定内孔面，槽底位于孔壁外侧。对卡簧槽可说「按已确认的标准槽宽 2 mm、槽深 1 mm，在正 Z 的 10 mm 处开轴用卡簧槽」。

倒角必须选实际相邻实体面，不能用与实体面同向的基准面替代。角度倒角在 Toolkit 内部把距离放在 LEG1、角度放在 LEG2；接口仍按“角度、距离”输入。斜孔与点平会补足入口反向清除距离，避免倾斜入口留下半圈材料，盲深仍从入口点沿指定轴量到孔底。
