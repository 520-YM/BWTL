# 连续建模与失败恢复

适用本机 BWTL 0.23.0-local.workflow.1。使用「然后」「接着」「再开」等表达步骤顺序。例如「在当前机箱上先开一个按钮孔，然后再开风扇安装孔组」。各步骤仍按现有工具支持的参照、尺寸和零件类型执行。任务正常结束时显示一条结果。

## 查看失败位置

从「插件功能 → 任务控制 → 查看执行明细」打开回执，也可以发送「执行明细」。每条回执记录步骤号、实际原生命令、模型和参照、成功或失败状态、Creo 返回码，以及原生阶段说明。较长记录保存在该会话的 data\last-native-details.txt。下次启动可查看上一次有原生步骤的记录。

一次失败后，只有活动模型、模型版本及工作目录仍可核实时，才允许结合最新参照换方案。已经成功的同一命令不会重放。同一模型版本中的重复失败尝试会被拦截，面板开孔只换特征名也视为重复。恢复状态无法核实时停止自动写入。

## 继续暂停的任务

在当前 Creo 会话中激活暂停时的同一零件，并保持工作目录和模型版本一致。点击「插件功能 → 任务控制 → 继续上次任务」，或在输入框发送「继续上次任务」。BWTL 保留原目标、已执行步骤及成功操作，从剩余工作继续。续跑会重新计自动失败额度，整个任务的 100 步上限继续计算。清除任务或退出 Creo 后，可通过明细查看回执。

范围覆盖现有连续建模协议，以及同一模型上明确串联的钣金与面板加工等操作。默认由用户保存。需回退时，在 BWTL 管理器选择 0.23.0-local.quickparts.1，保存自己的模型后正常重开 Creo。
