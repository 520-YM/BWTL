# 装配学习

在 Creo 打开总装 .asm 或引用总装的 Creo 工程图 .drw，选择「BWTL → 仿照模型 → 装配学习」，也可以在聊天中发送「学习当前装配」。插件读取可访问的总装和各级组件，学习完成后自动保存一个 UTF-8 的 .bwtlasm.txt 文件。

每个组件实例记录父装配、模型树次序、实测姿态、可读取的定位约束与参照。抑制状态、缺失的参照和扫描上限会列在回执里。打开「查看学习记忆」可以核对可读取的文件数量和路径。每个 BWTL 实例使用所选数据盘内自己的 data\装配方法库。

下次打开目标总装并准备组件，可以指定来源装配名或说「按上次学的装配方法，把当前总装里的组件定位」。插件优先匹配明确提到的总装或模块，再核对活动装配。执行时在新组件和总装上重查参照，使用目标模型的实际实例和约束。

「仿照模型 → 已验证的做法 → 装配坐标系定位」会填入可编辑的指令。公共案例 BWTL_DEMO_ASSEMBLY 示范以总装 AL_LOCATOR 和组件 AL_INTERFACE 建立重合约束。可在拥有同名稳定参照的目标中练习，或指定自己的案例。已有约束、缺失参照和多义实例以 Creo 回执为准。

请在对应的 BWTL 实例管理器回退上一版本。程序和学习文件分别保存，回退后可继续保留已写入的学习文件。
