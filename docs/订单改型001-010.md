
# 订单改型 001–010

入口为「插件功能 → 订单改型」。也可直接在聊天中发送「订单改型」，查看可用指令。TSV 使用 UTF-8，每列用 Tab 隔开，注释行以 # 开头。模型长度换算到毫米。

| 编号 | 指令与输入 |
| --- | --- |
| 001 | 推荐订单母型 订单号 "机型.tsv"。机型表六列，模型名、屏尺寸、安装方式、散热、开门方向、可能需改动的模块。先执行 002。 |
| 002 | 提取订单规格 订单号 "订单.txt"。格式为每行一个字段=值，也接受冒号、中文冒号和 Tab，保存原文值和行号。支持外宽、外高、外深、屏尺寸、板厚、屏型号、安装方式、散热方案、开门方向、交付格式及常见别名。PDF 或表格可先提取成 UTF-8 文本。 |
| 003 | 核对订单规格映射 订单号 "映射.tsv"。四列是订单字段、设计侧名称、测量参照、公差。设计侧可分别列整机外宽、骨架尺寸和零件尺寸，对照订单和当前 Creo 的实测数据。 |
| 004 | 记录改型保留项 订单号 "保留.tsv"，再用 核对改型保留项 订单号。三列是名称、测量参照、公差。保护值会成为 009 的验收条件。 |
| 005 | 核对尺寸冲突 "证据.tsv"。三列是统一后的尺寸名称、毫米值、出处。出处写 PDF 页码、订单行号或 Creo 特征。 |
| 006 | 试算参数边界 d12 30 45。对没有外部参照的单零件，在独立工作目录内分别建试算件，读回尺寸、再生状态和包络。 |
| 007 | 拆分改型任务 订单号 "任务.tsv"。六列是任务 ID、模块、类别、动作、前置 ID 列表、是否触发（0/1）。多条前置项用逗号，留空依赖用 -。 |
| 008 | 记录改型尺寸 订单号 "测量.tsv"，再用 比较改型尺寸 订单号。表格列与 004 相同。比对版显示改前后读数和变化量。 |
| 009 | 生成改型闭环单 订单号 "验收.tsv"。六列是任务 ID、要求、实际测量参照、目标值、公差、交付文件相对路径。目标模型需已保存，004 保留项全部通过，交付文件必须实际位于该订单的目录树。 |
| 010 | 绑定订单工作目录 订单号，再用 核对订单工作目录 订单号。在对应 Creo 工作目录打开已保存的目标模型后绑定。每个工作目录绑定一个订单，闭环单执行前同时核对目录、顶层模型和订单标识。 |

测量参照包括 BOX:X、BOX:Y、BOX:Z（包络），DIM:d12（驱动尺寸），DIAM:SURFACE:61（圆柱直径），HOLE_X:SURFACE:61（轴线在正交方向的坐标），PLANE_Z:PLANE:FRONT（平面在法向方向的坐标），GAP:PLANE:FRONT,PLANE:OUTER（平行面距离）。目标是当前装配内零件时，前面加完整实例路径和竖线，例如 ID:42/55|BOX:X。

工作文件保存在当前 BWTL 实例 data\订单改型\<订单号>。独立试算资料保存在同盘 data\订单试算。004 和 010 会约束本功能组的验收与出图流程，Creo 自带的保存按钮沿用 Creo 现有行为。各订单需要独立项目目录和实际表格。

开发验收使用独立 Creo 10 会话，按 13 项案例核对字段来源、母型得分、真实包络、尺寸试算、循环依赖、跨订单拒绝、保护项超差和交付文件。若需回退，使用对应 BWTL 实例的 BWTL-Manage.exe -Rollback。
