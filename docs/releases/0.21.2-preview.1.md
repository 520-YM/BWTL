# 霸威天龙 0.21.2-preview.1

本版提供完整的一键安装、升级、回退、诊断和卸载流程；卸载时可分别选择是否删除程序文件与聊天、记忆和备份数据。

主要更新：

- v21.2 原生 DLL 主动加载“霸威天龙”顶部菜单，不依赖原电脑的个人 UI 配置。
- 194 个功能实现文件独立保存，并由 227 文件冻结基线保护旧功能。
- 安装包包含源码、功能目录、文档、历史数据和本机模板迁移资料。
- 仓库 `chat` 目录保存截至 2026-11-04 的 Codex 完整问答网页、JSON 和用户图片附件。
- 7 组旧功能回归、22 项安装/升级/回退、44 项卸载和 18 项新增安装安全检查通过。

目标环境：Windows x64、Creo Parametric 10.0.0.0。首次启动时仍需按 Creo 自身提示确认插件来源；AI 功能使用安装电脑自己的 Codex 登录状态，不包含作者账号凭据。
