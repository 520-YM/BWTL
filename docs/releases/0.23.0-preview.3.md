# BWTL 0.23.0-preview.3

本版同步已在本机运行的 0.23.0-local.markup.53。Windows x64 安装包和仓库中的 bin/BWTL.dll 与本机验收的 Creo 10 二进制一致。

- **截图改图**增加整窗截图和随手圈改。最多 8 处，支持圈选、框选、箭头，单处显示文字贴注、已读尺寸和明确的目标值。提供建议、同图追问和修改回执。 [使用说明](../截图改图.md)
- **仿照模型**按原特征顺序重建可编辑模型，增加批量预检、方法学习及验收范围。100 项中有 99 项具备至少一种验收路径。多钣金体第 38 项需要 Creo 11 原生能力，待另验，其他变体见说明。 [仿照验收](../仿照模型.md)
- 同步装配后续更新、钣金工作流、功能列表、模块化源码、测试、界面和多实例管理。钣金及工艺操作以功能列表和各项原生验收范围为准。 [功能列表](../BWTL%20功能列表.txt)
- **E 盘存储**让安装、配置、缓存、临时目录及工作输出与旧桥接分开，适配本机已完成的迁移。迁移清单记录了主安装、各会话、源码和历史档案的去向。 [迁移说明](../E盘存储.md)

## 安装和验证

下载一键安装 EXE 或 Windows x64 ZIP，并核对随附的 SHA-256。需要本地 E 盘及 Creo Parametric 10.0.0.0。先保存并退出目标 Creo 会话。已有独立安装选原目录升级。安装后重开 Creo，点击顶部 BWTL。

截图改图在独立 Creo 中通过 3 套原生验收。仿照模型上一增量通过 21 套独立 Creo 原生回归。发布源码另运行了 11 套回归。其他电脑和 Creo 大版本仍需独立验证。 [安装与验证方法](../INSTALL.zh-CN.md)

如需恢复，在对应的 BWTL 安装管理选「回退上一版本」，然后重开 Creo。公开安装包附源码、资源、测试和用法，旧发布档案保留在原位置。
