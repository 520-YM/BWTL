# BWTL 0.23.0-preview.4

EXE 和 ZIP 安装版都提供「数据盘」选择。可从本机可用的固定盘符中选择，也可浏览指定文件夹。BWTL 程序、聊天、记忆、Creo 专用配置、缓存、日志、临时目录和备份均写到所选盘。启动与保存会核对该盘，截图改图和建模方法库也使用同一位置。

已有安装可在原目录升级并保留各会话的数据。换盘选择新目录会创建新的独立安装。本机原有的 E 盘迁移仍可按原目录运行。 [安装步骤](../INSTALL.zh-CN.md) · [本机迁移记录](../E盘存储.md)

使用 EXE 或解压 ZIP 后运行 install.cmd。点击「数据盘」选择盘符并确认文件夹，安装后从「Creo（BWTL）」打开，再在 BWTL 的「工作目录」核对实际路径。命令行安装可通过 -InstallRoot 指定所选盘内的目录。

验收覆盖非 E 盘的新装、所选盘保存、其他盘写入拦截、截图改图、建模方法库和 E 盘安装的升级回退。可通过 BWTL 安装管理回退到上一版，使用回退版本原有的盘符规则。
