# BWTL 0.23.0-preview.2

本版同步已在本机验收的 0.23.0-local.asmdelivery.1，包含第 1–340 项功能。与上一 GitHub 预发行版相比，增加高级建模、钣金加工和检验、常用零件自动生成、装配约束、机构、装配质量、配置、BOM 和装配交付。菜单和文本功能列表同步更新。后续改动仍按功能或相关功能组维护。

## 安装和验证

- 使用 Windows x64 安装程序，或解压 ZIP 后运行 install.cmd。需要已安装 Creo Parametric 10.0.0.0 和可用的 Codex。首次安装自动创建 BWTL 专用配置，可从开始菜单的「Creo（BWTL）」入口启动。已有独立桌面入口可继续使用。安装前保存模型，按需重开 Creo。
- 校验发布的 SHA256SUMS 文件。安装后打开 BWTL，在「插件功能 → 功能列表」中核对第 331–340 项。通过安装管理器可回退各会话的上一版。
- 本机验证包括 35 个第 331–340 项原生用例、4 个重开与聊天用例、11 套回归测试，以及同一 DLL 的隔离启动验证。其他电脑和 Creo 大版本须另行验收。
- 第 340 项使用当前已保存的配置装配及显式指定的 PDF、TXT 附件。依赖未核实时停止生成交付包。

## 档案与数据

BWTL 项目文字聊天和插件会话档案位于仓库独立目录。安装包含程序和功能指南。现有安装升级时保留各会话数据，备份恢复由所有者按需操作。
