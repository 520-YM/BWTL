# BWTL 0.23.0-preview.5

- Creo 原生零件按特征步骤重建、保存重开并通过验收后，自动生成学习文件。装配学习继续从原生总装读取多级组件及定位约束，并自动写入对应的实例库。
- 「仿照模型 → 查看学习记忆」核对存档。「已验证的做法」提供装配坐标系定位与钣金首壁、独立切口的可编辑指令。学习信息跨 Creo 进程可用。
- 方法库遵循所选数据盘。安装包提供两份可直接检索的通用方法示例，保留已有文件。聊天功能使用本机已登录的 Codex。
- 本版包含先前本机版的装配专项检查、钣金外参重建与连续凸缘改进，适用范围见插件功能列表及回溯风险文档。

安装时运行 Windows x64 安装程序并选择本地数据盘，随后进入 BWTL 的隔离 Creo 环境。用「查看学习记忆」检查两个示例。实际建模要核对当前 Creo 原生回执。本版目标和验收环境为 Creo Parametric 10.0。

独立 Creo 实测先学习单组件装配和 80 × 60 mm、厚 2 mm、孔径 Ø6 mm 的钣金件。退出后启动新进程，读取原数据目录，在另一总装给替换组件施加原生坐标系重合约束，并按 110 × 70 mm、厚 3 mm、孔径 Ø10 mm 完成新钣金。运行 11 套回归，并验证全新安装的样例和插件入口。

回退前保存并退出需要切换的 Creo 会话，再在 BWTL 管理入口选择上一版本。学习案例仍存放在各实例的数据目录。
