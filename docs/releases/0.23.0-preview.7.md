# BWTL 0.23.0-preview.7

- 同一条建模指令可跨装配和子件窗口继续执行。BWTL 先核对 Creo 实际打开的窗口、装配实例和工作目录，再读取新活动模型，供下一步使用。
- 支持按同一任务的父子关系回到原装配并继续。目标或参照仍有疑问时，保留已完成的操作并说明需要核对的内容。
- 恢复「插件功能」菜单，附件入口统一为「对话与附件」。

## 安装与核对

使用 Windows x64 安装 EXE，或解压 ZIP 后运行 `install.cmd`。选择本机数据盘及安装目录，已有安装选择原目录升级。保存工程并重新打开 Creo 10.0.0.0 后生效。

可在独立 Creo 会话中测试打开子钣金件、在子件上建模并回到父装配。核对 Creo 的活动模型、装配树和 BWTL 最终回执。出现版本问题时，在 BWTL 管理器中回退后重启对应的 Creo 会话。
