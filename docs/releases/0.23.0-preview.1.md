# BWTL 0.23.0-preview.1

本版汇总 0.21.2 之后的本机功能更新。支持多个 Creo 进程同时运行 BWTL，各会话分别保留聊天、记忆、工作目录、日志、源码和插件版本。

- 支持图片附件和智能协作，默认把同一轮的结果合并在一条回复中。
- 「插件功能」提供分类工具和可打开的功能列表，另有「公司标准」和「工作目录」入口。
- 新增独立通孔、平底盲孔、固定半径圆角、等距倒角、旋转切除及原点居中圆柱。
- 支持在窗口内提出功能开发需求，通过独立副本编译、回归和适用的 Creo 原生验收后再应用升级。

下载一键安装 EXE 或 Windows x64 ZIP，并用 `SHA256SUMS-0.23.0-preview.1.txt` 校验。目标环境为 Windows x64 和 Creo Parametric 10.0.0.0。新安装会创建独立的 Creo 配置；已有独立安装保留聊天和记忆。安装流程、旧版迁移和回退见[安装说明](../INSTALL.zh-CN.md)。

原生 DLL 与本机通过多会话验收的二进制一致。Windows 构建机已运行 11 组回归，并检查公开包的提取、校验和独立安装。其他电脑尚未实测。
