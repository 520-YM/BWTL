# BWTL 0.23.0-preview.6

- Creo 内的聊天使用常驻 Codex。普通对话和附件分析会带上近期上下文，已核对的新建模型回执可用于后续追问。支持 PDF、STEP、PRT、ASM、图片和文本附件，显示指令用时。
- 公司资料接口识别「公司库」等入口。受管理的多个 BWTL 会话可读取主库。标准文件菜单将紧固件按分类展开，库件可另存到当前 Creo 工作目录。
- 本机实测 BSO M3×6 从实际 Creo 族表读取、另存为独立 PRT，并按选中的贴合面和 Ø5.4 孔壁固定定位，批装四个实例。需要用户在自己的标准库提供对应母件。
- 集成装配命名、同号钣金子件、组件窗口切换、按进程归档聊天和装配经验写入。公司标准件及摄像头参考文件由安装者提供。安装包附带通用学习示例。

通过 Windows x64 安装程序选择本地数据盘和安装目录。ZIP 解压后运行 `install.cmd`。已有安装选择原目录升级，正常重开 Creo 后加载新版。适用环境为 Creo Parametric 10.0.0.0。

可在独立 Creo 中核对新建后的追问、附件解析、标准库读取及另存回执。紧固件验证用法见《BWTL 标准文件与紧固件》。遇到版本问题时，在 BWTL 管理器选择回退并重启对应 Creo 会话。各会话数据继续使用已选的数据目录。
