# 霸威天龙：普通零件功能开发计划（30项）

整理日期：2026-10-29。

用途：后续按编号逐项开发、测试和验收。**本表是待开发／待完善清单，不代表当前版本已经支持这30项。** 当前实际能力仍以《功能表.md》和当次原生执行回执为准。2026-10-29更新：01—10的基础范围已在v19实现并经本机测试，详见《v19基准与关联草绘.md》；11—15的本轮基础范围已在v21实现并经本机测试，详见《v21开发进度.md》；第16项旋转切除已在本机实现。第19、20、23、24项的首批能力也已提供，其他项目按计划开发。

范围：Creo 普通实体零件的建模操作。钣金专用操作、装配和二维工程图另列计划。

## 一、基准与参照

| 编号 | 功能 | 计划范围 |
|---|---|---|
| 01 | 创建基准面 | 按已有平面偏移、按角度等条件建立基准面；先实现偏移平面 |
| 02 | 创建基准轴 | 根据圆柱面、两平面等明确参照建立轴线 |
| 03 | 创建基准点 | 按坐标或几何参照建立基准点 |
| 04 | 创建坐标系 | 指定原点、方向及偏移建立坐标系 |
| 05 | 创建基准曲线 | 按明确点或参照创建曲线，作为后续路径等输入 |
| 06 | 选择建模参照 | 准确定位用户指定的面、边、基准面和轴；歧义时询问，不猜目标 |

## 二、草绘

| 编号 | 功能 | 计划范围 |
|---|---|---|
| 07 | 创建关联草绘 | 指定草绘平面、方向参照和视向，建立与模型关联的草绘 |
| 08 | 绘制基本图元 | 直线、矩形、圆、圆弧；先实现矩形和圆 |
| 09 | 添加草绘尺寸 | 长度、距离、角度、直径和半径等尺寸标注 |
| 10 | 添加几何约束 | 水平、垂直、重合、平行、相等、对称、相切等；分阶段扩展 |
| 11 | 编辑已有草绘 | 修改图元、尺寸及约束，检查轮廓闭合并重新求解 |
| 12 | 投影和引用几何 | 将已有边或曲线引用到草绘，保留可验证的参照关系 |

## 三、实体基础造型

| 编号 | 功能 | 计划范围 |
|---|---|---|
| 13 | 拉伸加料 | 在当前零件创建标准参照拉伸，支持首个实体及已有实体上的追加拉伸 |
| 14 | 拉伸切除 | 在指定面／基准面建立轮廓，按深度或贯穿方式去除材料 |
| 15 | 旋转加料 | 指定截面、旋转轴和角度建立旋转实体 |
| 16 | 旋转切除 | 按旋转截面去除材料，形成环槽等结构 |
| 17 | 扫描 | 沿指定路径扫描截面；先实现恒定截面 |
| 18 | 混合／放样 | 通过多个指定截面生成实体；先实现简单截面之间的混合 |

## 四、孔与边缘处理

| 编号 | 功能 | 计划范围 |
|---|---|---|
| 19 | 创建通孔 | 明确孔位和直径，创建独立的贯穿孔特征 |
| 20 | 创建盲孔 | 明确孔位、直径和深度，创建独立盲孔特征 |
| 21 | 创建沉孔／沉头孔 | 支持台阶沉孔或锥形沉头孔，分别提供所需尺寸 |
| 22 | 创建螺纹孔 | 按明确螺纹标准、规格及深度建立孔；依赖本机相应孔表 |
| 23 | 创建圆角 | 对明确选定的边创建圆角；先实现固定半径 |
| 24 | 创建倒角 | 对明确选定的边创建倒角；先实现等距离倒角 |

## 五、修形与特征复用

| 编号 | 功能 | 计划范围 |
|---|---|---|
| 25 | 抽壳 | 指定开口面和壁厚，形成空心实体 |
| 26 | 拔模 | 指定拔模面、方向／中性参照和角度 |
| 27 | 创建筋 | 按明确草绘、厚度和方向建立加强筋 |
| 28 | 镜像特征 | 指定待镜像特征和镜像基准面，建立对称结构 |
| 29 | 阵列特征 | 先实现线性和圆周阵列，指定数量及间距／角度 |

## 建议的第一条开发链

06 选择参照 → 07 关联草绘 → 08 基本图元 → 09 尺寸 → 10 必要约束 → 13 标准拉伸 → 14 拉伸切除 → 19 通孔 → 23 圆角 → 24 倒角。

已有模板通常已经具备默认基准面和坐标系，因此可以先利用这些参照打通整条建模链，再扩展新建基准和高级特征。

## 每项功能的验收要求

1. 在用户明确的当前零件中执行，不擅自另建零件替代；需要新零件时使用用户模板。
2. 参照、尺寸或方向有歧义时先询问；尺寸完整且目标明确后直接执行，不要求再点“执行建模”。
3. 使用原生接口，不截图或模拟鼠标键盘；草绘与特征参照须可检查。
4. 检查特征状态、重生成及适用的几何结果，失败如实报告，回滚结果也必须核验。
5. 没有要求时不自动保存。测试通过后再更新实际功能表、版本记录及发行资料。

后续可以直接按编号提出任务，例如：“先开发第13项标准拉伸”。一个编号可以分成若干小版本，不将其中尚未完成的变体列为已支持。
