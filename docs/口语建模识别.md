# 口语建模识别

适用本机 BWTL 0.23.0-local.intent.1。识别「画个」「做个」「做张」「做件」等口语中的具体制作请求。「尺寸自己给」「尺寸你定」「自己想象」可用于委托 BWTL 选择未指定的尺寸。空白 Creo 中可用已有原生协议建立独立新零件。明确针对当前零件的请求仍按活动模型核对。

说「先给方案」「只分析」「别建模」时仍走讨论。单纯引用聊天句子和询问做法也按讨论处理。对象、形态或关键尺寸缺少且用户未委托时，按实际需要澄清。

## 验证示例

从空白 Creo 发送「画个凳子，尺寸自己给，自己想象」。简式凳子采用矩形凳面与四条直方腿。生成后核对实际尺寸、实体数量、体积、四个腿位和凳面下的留空，默认由用户保存。实际验收选择凳面 320 × 320 mm，厚 25 mm，总高 450 mm，腿宽 35 mm、距边 25 mm。圆凳、折叠结构或带横撑的版本按用户指定的几何要求另行规划。

上一版本为 0.23.0-local.workflow.1。需要回退时，通过 BWTL 管理器切回上一版，保存个人模型后正常重开 Creo。聊天与长期记忆保留在各会话数据目录。
