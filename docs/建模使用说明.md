# 原生简单零件建模（v4，待 Creo 内实测）

已编译 codex_native_ai_v4.dll，并更新 protk.dat。下次重启 Creo 加载；本次未操作界面、未修改当前模型。

## 使用

在助手里输入，例如：

帮我新建一块100×80×2毫米的矩形板，中心一个直径10毫米通孔。

或：

新建直径50毫米、高100毫米的圆柱，不要孔。

AI 输出方案后，窗口显示“待执行方案”。检查尺寸后输入“执行建模”，或者输入“取消建模”。执行动作仅由本地固定命令触发，收到 AI 回答不会自动创建零件；不会执行 AI 生成的脚本或任意命令。再次向 AI 发送消息、关闭窗口或开始新对话会清除之前的待执行方案。待执行状态不跨重启恢复。

## 范围

- 新建矩形板、长方体、圆柱。
- 可以附带一个中心通孔，孔与外形一起通过闭合截面拉伸，不是单独的孔特征。
- 使用原生草绘拉伸、自动标注截面尺寸；不是导入网格或 STEP。
- 普通实体板，不是钣金特征，无折弯、展开或折弯扣除。
- 不支持任意孔位、多孔、盲孔、装配修改或二维工程图。
- 以毫米解释输入，通过原生单位 API 换算到新零件单位。几何尺寸物理含义为毫米，但零件显示单位沿用空白零件默认单位。

## 执行行为

新零件名按时间自动生成，形如 ai_261028_101500_1。新建独立零件，原有模型不作为修改目标，不自动保存 .prt 文件。用户需要按 Creo 正常方式保存新零件。

过程创建截面、拉伸、重新生成，并把实际体积与理论体积比较；只有 API 成功且体积符合，才报告成功。成功时创建新零件的窗口并显示模型，没有模拟鼠标或键盘，也不调用窗口激活 API。执行方案本身会改变 Creo 的显示内容；如希望完全不影响 Creo 当前工作，请暂不发送“执行建模”。

失败会显示原生 API 阶段和错误码，详细操作码记入 runtime.log，结果写入聊天记录。失败可能留下独立空白/不完整零件供诊断，不删除它，不改已有模型。禁用缺失元素时弹出交互补全界面的选项。
