# BWTL 第一批：独立孔、圆角和倒角

本机版本 `0.22.0-local.batch1.1`，2026-11-05。只在本机开发、安装和验证，没有推送代码或发布 GitHub release。

## 行为与范围

原版可以通过圆形草绘切除材料，但没有独立原生孔特征，也没有新建圆角和倒角。本版新增 `src/machining_plan.h`、`src/machining_tools.h`、`src/machining_prompt.h` 和 `src/功能/machining_tools/`，通过新的命令分支接入；原有基准、草绘、拉伸、旋转、尺寸修改等执行算法保持。

所有新增写入仅用于单独打开的普通单实体零件。仍使用已有活动模型、工作目录和模型版本绑定，拒绝钣金、装配及装配内组件。不会自动另建模型代替当前操作，不自动保存。

| 功能 | 支持范围 | 当前限制 |
|---|---|---|
| 独立通孔 | 真正 `PRO_FEAT_HOLE` 直孔，指定实际实体入口平面和两个正交定位平面 | 完整圆柱孔壁和去除体积须可核对，不支持曲面入口、破边、与已有空腔相交 |
| 独立盲孔 | 平底直孔，明确直径、深度和相同定位信息 | 不带钻尖，要求完整圆柱去料体积，不得穿透或破边 |
| 固定半径圆角 | 一个固定半径，1—8条明确直边，邻面为两正交平面 | 不自动扩展相切链，不支持圆边、非正交邻面、变半径或自定义过渡 |
| 等距离倒角 | 一个等距尺寸，1—8条相同范围的明确直边 | 不支持不等距或距离加角度模式 |
| 加工参照读取 | 平面解析原点/法向、边端点/中点/长度 | XYZ均为模型坐标系毫米，列表有上限；未列出的目标不可猜测 |

## 使用与协议

从桌面 **BWTL（独立运行）** 启动，读取当前模型后用中文说明入口面、孔位、直径和深度/贯穿，或指定边与圆角/倒角尺寸。缺失或歧义信息须先澄清。只有原生回执成功才表示完成，仍需用户自行保存模型。

底层单次只接受一条操作：

```text
CREO_OP MACHINING_INFO 模型名
CREO_OP HOLE 模型名 新孔名 SURFACE:入口ID 平面参照1 偏移1 平面参照2 偏移2 直径 THROUGH 0
CREO_OP HOLE 模型名 新孔名 SURFACE:入口ID 平面参照1 偏移1 平面参照2 偏移2 直径 BLIND 深度
CREO_OP EDGE_ROUND 模型名 新圆角名 半径 EDGE:实际ID [EDGE:实际ID ...]
CREO_OP EDGE_CHAMFER 模型名 新倒角名 等距距离 EDGE:实际ID [EDGE:实际ID ...]
```

平面参照可为 `SURFACE:实际ID` 或 `PLANE:实际基准名`。孔位偏移是沿对应参考平面几何法向的有符号距离，零值表示对齐，不能直接把全局X/Y坐标或距边尺寸当成偏移。入口必须是实际实体平面，定位平面须与入口及彼此正交。孔向实体内部钻入。原生请求中附带本次读取的几何，AI不能沿用旧聊天中的编号。

长度统一毫米，直径/深度/边缘处理尺寸范围 0.01—10000；定位偏移绝对值不超过1000000。尺寸还须通过几何与实体大小检查，范围内并不代表一定可实现。相同边不允许重复，最多8条，禁止组合多条写入协议。

## 核对与失败恢复

孔的类型、名称、父参照、孔径、深度模式及实际深度均读回；读取生成圆柱壁的实际半径、轴线位置、轴向、角度范围和面积，并与实体去料体积比对。Creo会把完整圆柱壁分成两个半圆柱面，因此按同轴同半径等长的实际面汇总角度，要求完整一周。平底盲孔还必须符合指定深度的完整圆柱去料体积。

圆角和倒角检查原生特征类型、名称、父参照、实际尺寸、实体数量、健康及体积变化。只加入用户指定边的逐边集合，不添加自动相切扩展指令。超过零件外形对角线的尺寸保守拒绝，不把复杂自动处理结果扩充为已支持范围。

失败时移除本次特征并重新核对特征ID集合、重生成、原体积和单实体。若恢复无法核实，则本次会话停止后续加工写入并明确报告，须人工检查模型后重启。不会删除已有约束或改用其他模型强行完成。

实现依据为本机 Creo 10 `ProHole.h`、`ProRound.h`、`ProChamfer.h`、`ProCrvcollection.h` 及 PTC SDK 的 `UgHoleCreate.c`、`UgEdgeRoundCreate.c`、`UgEdgeChamferCreate.c`。使用原生元素树和可取消失败的重生成标志，不使用界面点选或旧 Codex–Creo 桥接。[PTC 特征创建文档](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r13/usascii/creo_toolkit/user_guide/Feature_Creation.html)

## 验收

本机原生夹具、结果和日志保存在 `%USERPROFILE%\Documents\BWTL-batch1-20261105`。覆盖独立通孔、上下表面盲孔、正负及零偏移、单边/多边圆角和倒角、重复名称、空切、重合孔、穿透、破边、过大尺寸、失效边及失败恢复。原有94项实体回归和尺寸核心自检也重新执行。正式部署后的版本、DLL哈希、隔离进程和数据保留结果记录于安装根目录的 `batch1-update-status.json`；以完成记录为准，编译成功不代替实机结果。

源文件兼容基线只审查更新了新模块入口、提示词附加、新版本界面说明和回归入口；没有重置全部受保护文件。协议、聊天恢复和历史检索等非交互回归继续保留。

## 安装、数据与回退

安装前备份安装状态、专用配置和 data。使用完整带校验清单的包，安装器读取当前 `active.json` 和隔离配置，保留数据及上一版本。聊天、长期记忆和近期上下文位于版本目录外；仅更新内置功能索引，不把测试记录写入用户历史。

新版继续使用独立 HOME、配置、缓存、临时目录和数据会话互斥，并拒绝旧桥接共加载。原 Creo 入口、旧桥接DLL、MCP配置和注册保持，不使用其接口验证本版。

回退：保存并退出 BWTL 会话，使用安装管理的“回退上一版本”，再从独立入口启动。回退到 `0.21.3-local.foundation.1` 后本批新建命令不可用，原有隔离和尺寸修复保留；当前聊天数据保留。已经生成并保存的模型特征属于 Creo 原生特征，回退不会自动删除模型中的特征。不要恢复升级前的旧 data 覆盖新聊天。
