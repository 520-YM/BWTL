# BWTL 菜单与入口

- 仿照模型。顶部直接重建当前模型或选择模型文件。重建与试改、检查与比对、批量处理、学习与复用各有独立分组。点击底部的「已验收范围」查看已验证的操作。学习与复用内仍可查看学习记忆和已验证的做法。
- 插件功能。先选零件建模、钣金与机箱、装配与定位、修改与复用、检查与交付、公司标准与订单或对话与任务，再选小类和具体操作。顶部「功能列表」可打开完整清单。
- 工作目录。入口依次为创建新项目、切换工作目录和当前目录操作。当前目录组包含查看、打开和复制路径。
- 公司标准。可打开已验收标准件、浏览公司资料或技术文件，并归档上次结果或上次批量通过项。
- 截图改图。点击顶部按钮直接进入标注。圈选、箭头、框选归入标注方式，撤销和清空归入标注管理，发送并改图在下方提交区。

菜单沿用原功能指令。项目资料、聊天和学习数据保存在 E 盘的原配置目录。普通关闭或按 Esc 可退出菜单。

## 验证和回退

从独立 Creo 逐项核对分组、按钮和功能列表，缩窄窗口后检查菜单可导航和关闭。需要回退时在 BWTL 管理工具选择上一版 0.23.0-local.assemblycomplete.1，保存手头工作后重开 Creo。
