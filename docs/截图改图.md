# 截图改图

「随手圈改」从 BWTL 顶部「截图改图」打开。标注一处时，输入的要求会贴在截图对应位置旁。唯一定位的圆孔会显示 Creo 实测孔径。输入明确的绝对孔径后，底部显示「现有尺寸 → 目标尺寸」，点击「发送并改图」才写入。

1. 在 Creo 10.0 激活零件，选择 E 盘工作目录，转到能清楚看到目标的视角。
2. 点击 BWTL 顶部「截图改图」。截图包含 Creo 标题、功能区、模型树、图形区及状态栏。
3. 用圈选、框选或箭头标出要修改的位置。最多 8 处，可撤销或清空。只问截图里的问题时可以直接发送文字。
4. 按平常的说法描述要求，例如「1 号孔径再放大 2 毫米，2 号先保留原样」「把这个开口的短边缩小 20 毫米，长边保持」或「这个孔大一点，你帮我选个尺寸」。
5. 截图窗口显示最终回复，可滚动查看。明确的指令直接执行。需要澄清时可在同一张截图继续回答。提出建议时会显示原尺寸与建议值，输入「按建议改」可执行该建议，换截图或更改标注后需重新核对。模型改动经 Creo 再生和读回，回执列出特征和改前、改后尺寸。保存由你决定。

明确的单孔绝对孔径、明确指向所有标注的统一孔径及逐号指定所有孔径可在本机处理。其余表达由 Codex 结合截图、标注、当前模型实测数据及同图追问判断。当前可写范围包括可独立编辑的原生圆孔、独立草绘圆切口，以及可绑定独立线长尺寸的矩形拉伸贯穿开口。截取正视或接近正视的视角有助于识别。矩形 X/Y 指草绘方向，近水平或近竖直的方向会随截图视角变化。移动孔位、保持开口中心和联动阵列仍超出本次验收范围。

本机工作文件和 Codex 日志数据库在相应 BWTL 会话的 E 盘数据目录。分析期间可点「停止分析」。完成后临时截图、请求和结果文件清除，聊天保留最终回执。

## 验证与回退

在独立 Creo 10.0 验证编号选孔、相对增量、保留未选孔、同图追问、根据现有孔径提出建议并在确认后执行，以及钣金矩形贯穿开口横向缩小、另一尺寸不变和含糊指令澄清后继续执行。保存工作并重新打开 Creo 后载入新版。

本次更新为 0.23.0-local.markup.53。回退时先正常关闭对应 Creo 会话，再使用其 BWTL 管理入口切换到 0.23.0-local.imitation.52。会话继续使用原数据目录。
