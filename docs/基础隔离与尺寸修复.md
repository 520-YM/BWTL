# BWTL 基础更新：独立运行与尺寸修改

本机版本：`0.21.3-local.foundation.1`，2026-11-05。此更新只在本机部署，不向远程仓库发布。

## 修复内容和依据

原安装将 BWTL 与旧 Codex–Creo 桥接同时注册在用户 config.pro，两个 DLL 会进入同一 Creo 进程。现将 BWTL 自己的注册块迁移到 `%LOCALAPPDATA%\BWTL-Profile\home\config.pro`，使用专用启动器设置子进程的 HOME、备用配置目录、缓存、临时目录和日志目录。旧桥接的注册行、源码、二进制、MCP 配置均不修改。原 Creo 及原连接继续从原有入口使用。

Creo 会累计读取安装目录、个人目录、备用路径及启动目录的配置，因此仅新增一个工作目录不能保证隔离。独立启动器使用专用 HOME、空的备用目录及启动目录；DLL 还会核对独立会话标记并拒绝与 `creo_safe_resident` 模块共加载。BWTL 数据目录有会话互斥，避免多个 BWTL 进程同时改写同一份聊天。系统 Creo 安装文件及只读模板仍使用本机现有文件。

原尺寸修改自检返回 `-56`，对应官方 `PRO_TK_REGEN_AGAIN`（需要再次重生成）。原 `part_regenerate.inc` 将它直接返回，导致写入流程失败。本版最多进行3次重生成，仅对这一状态重试；其他错误立即保留，成功后仍检查特征健康、实际尺寸及体积。无效修改仍走原回滚路径，不把错误改写为成功。

依据：PTC 的 [启动配置读取顺序](https://support.ptc.com/help/creo/creo_pma/r12/usascii/fundamentals/fundamentals/About_Configuration_Files.html)、[ProSolidRegenerate 返回值](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r13/portuguese_br/creo_toolkit/3939.html)及本机 Creo 10 的 ProSolid.h、ProToolkitErrors.h。

## 启用和升级

1. 保存现有 Creo 工作，退出之前共同加载两套插件的会话。
2. 首次运行 `scripts/Enable-BWTLIsolation.ps1`。它先备份配置、安装状态和数据，仅移除原配置中的 BWTL BEGIN/END 块，原旧桥接注册保留。专用配置复制本机模板等标准设置，并移除副本里的其他 Toolkit 启动项。
3. 使用本版完整包的 `setup/Install-BWTL.ps1 -Silent` 更新原安装根目录，ConfigPath 使用隔离记录中的 Config。新版安装器拒绝写入其他配置，不再提供停用旧桥接的选项。
4. 从桌面 `BWTL（独立运行）` 或安装根目录的 `Start-BWTL.ps1` 启动。普通 Creo 原入口供旧连接使用。后续更新沿用专用配置和原 BWTL data。

`active.json` 保存当前/上一版本；`isolation.json` 保存专用目录和原配置备份位置；`data/isolation-session.txt` 记录实际 BWTL PID、程序、数据目录和桥接检查结果。启动器仅设置本次子进程环境，不改系统环境变量，不导出或复制登录凭据。AI 继续使用现有本机 Codex 引擎，并保留原有 `--ignore-user-config`、临时会话和只读限制。

## 验证

- 修改前，独立 Creo 测试会话复现核心自检 `-56`；测试日志确认没有旧桥接模块。
- 修改后，真实 Creo 核心自检通过：尺寸及体积变化、退化尺寸拒绝并恢复、中文参数修改、旧值不匹配拒绝、活动模型保持。
- 重生成策略单测通过：1/2/3次成功、3次仍未完成、其他错误、失败特征均按约定处理。
- 隔离脚本检查通过：计划无写入、迁移、原注册及聊天保留、备份、重复执行、启动预检及额外配置拒绝。
- 隔离保护单测通过：缺失/无效标记拒绝、真实加载一个无旧实现的同名测试 DLL 时拒绝、干净进程允许、会话日志和互斥正常。
- 7组现有非交互回归通过。94条原生建模回归：87成功、7预期拒绝，失败0。
- 原回归夹具写死原电脑的 PRT_CSYS 名称，在本机模板 PRT_CSYS_DEF 下出现9个连带失败；本版仅修正夹具，读取测试模板中唯一坐标系的真实名称。未修改模板或为测试改动建模算法。
- 部署后检查实际 Creo 模块：BWTL 会话中应只有 BWTL，不出现旧桥接；核对旧桥接二进制/MCP设置未改变，聊天、记忆、近期上下文与升级前哈希一致。

测试详情保留在本机 `BWTL-foundation-20261105` 目录。编译或文件哈希检查不能代替真实 Creo 验证，也不能证明所有外部模型都会成功。

## 回退

保存并退出 BWTL 的 Creo 会话，使用安装管理“回退上一版本”，再从独立启动入口启动。回退只切换程序版本，保留隔离配置和当前聊天。上一版尺寸自检可能仍返回 -56。隔离迁移前的共享配置、安装状态及数据备份在 isolation.json 的 Backup 中；只有用户明确要求撤销隔离时才恢复共享配置，不能在普通回退时重新共同加载。

## 功能文件和版本兼容

源码按函数/模块分别保存在 `src/功能/`，运行时统一编译成一个 BWTL.dll。本次新增隔离检查、会话开始、会话结束也各有独立 inc 文件。独立源码文件便于维护和冻结检查，但不代表每个功能能独立加载/卸载，也不保证新版绝不会回归。

更新必须保留全部旧模块和协议，检查受保护文件差异，完成相应回归并保留上一版。新功能通过增量文件接入；共享校验、重生成和事务改动要验证旧功能组合。禁止为了构建通过而自动重置基线。聊天和记忆始终位于版本目录外，不用旧版 data 覆盖当前数据。
