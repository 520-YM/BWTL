# 第 251–260 项 组件与子装配管理

在 Creo 10 打开顶层装配的主表示，退出动态定位。从「BWTL → 插件功能 → 组件与子装配管理」选择。先读取组件树和定位状态，使用实际实例 ID 及从 1 开始的约束序号。多个实例可共用一个模型名。

| 编号 | 功能 | 用法 |
| --- | --- | --- |
| 251 | 插入已有子装配 | 把已加载或工作目录中已有的子装配按初始坐标装入，保留下级结构。 |
| 252 | 在总装中新建子装配 | 使用配置的空装配模板创建并装入新子装配。 |
| 253 | 复制已定位组件 | 复制组件实例及简单约束，并把对应基准改绑到新位置。 |
| 254 | 替换组件并保留定位 | 先核对同名定位接口、姿态和约束，再移除旧实例，返回新实例 ID。 |
| 255 | 删除指定组件实例 | CHECK 只查依赖。DELETE 需用户明确写删除及该 ID，备份并试删后执行。 |
| 256 | 旋转未约束组件 | 绕过指定支点、平行于总装轴的直线旋转。角度按右手规则。 |
| 257 | 翻转组件安装方向 | 绕组件自身指定轴翻转 180 度，保持自身原点。 |
| 258 | 解除固定 | 移除单独的固定约束，保留组件当前的位置和方向。 |
| 259 | 编辑指定定位参照 | 仅改指定约束的一侧，核对其余约束保持。 |
| 260 | 修复失效的定位参照 | 可显式指定替代参照。AUTO 只采用与现有姿态和约束匹配的唯一候选，有歧义则列出。 |

模型文件从当前会话或当前工作目录读取。第 252 项使用 Creo 的模板复制功能，Creo 可在工作目录写入新子装配文件，顶层装配的改动仍待用户保存。第 253–260 项针对普通直接零件。替换限定可按同名且几何一致的基准面、轴、坐标系映射的简单定位。替换返回新实例 ID，有下游依赖时拒绝。旋转与翻转用于未约束组件。改绑或修复支持可读取约束记录中的平面、轴或圆柱参照。Creo 无法读取的复杂约束集需在 Creo 中处理。无唯一候选时提供候选，由用户指定。

删除和替换会在 BWTL 独立配置目录保留装配恢复副本。删除需要指定实例 ID 和实际模型名，不会删除零件文件。保存需要保留的工作并正常退出该 Creo 会话后，可用对应安装根目录的 `BWTL-Manage.exe -Rollback` 回退到 `0.23.0-local.placement.1`。

验收使用独立 Creo 10 会话，覆盖子装配层级、重复型号实例、连续替换、定位参照变更、转动及删除保护。反复调用组件特征重定义在本机 Creo 10 的连续替换测试中触发回溯，当前实现使用原生装配、约束读回和单实例删除。
