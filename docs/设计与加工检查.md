# 第201–210项 设计与加工检查

本机版本 **0.23.0-local.inspection.1**。在独立零件中打开 **BWTL → 插件功能 → 设计与加工检查**。这些检查只读当前模型。几何尺寸用毫米，角度用度，开孔率用百分比。阈值和配件规格使用用户确认的数值。

| 编号 | 功能 | 检查范围 |
| --- | --- | --- |
| 201 | 孔口螺钉头落位检查 | 完整圆孔口与平面支承。核对杆径余量、环形支承宽度和头缘至其他轮廓的净距。面边界支持直线及圆弧。 |
| 202 | 沉孔藏头检查 | 原生柱形或锥形沉孔，底孔贯穿。核对头部外径、沉入余量；锥头另外核对角度。 |
| 203 | 盲孔剩余底厚检查 | 原生平底直盲孔，报告九处轴向测点的最薄值。 |
| 204 | 孔与折弯距离检查 | 钣金同一平面上的完整圆孔与实际折弯切线直边，报告扣除孔半径后的净距。 |
| 205 | 折弯工具空间筛查 | 输入一个静态工具避让长方体，定位坐标系 X 轴平行实际折弯边。避让包络排除允许的接触区域。 |
| 206 | 散热开孔率检查 | 选择相对的两个平面，依据入口外轮廓面积及可追踪到出口的直通孔壁计算。支持直线及圆弧轮廓，盲腔和证据不足的轮廓单列。 |
| 207 | 设备安装净空检查 | 对当前单实体与指定姿态的长方体设备包络做静态筛查，输入单侧余量。 |
| 208 | 边缘尖角检查 | 一次核对最多八条直边，区分两平面构成的外凸角与内凹角。 |
| 209 | 深孔长径比检查 | 平底直盲孔的实测深度除以圆柱直径，与输入的最大值比较。 |
| 210 | 刀具最小直径检查 | 对内圆柱或平行相向槽壁核对局部宽度，扣除双侧余量后与最小可用刀径比较。 |

折弯工具和设备安装使用轴向尺寸明确的长方体包络。与实体保守范围完全分离时确认有净空。射线实际穿过包络内的实体时报告侵入。其余重叠情况列为待复核。弯曲运动、装配路径和具体刀路属于后续工艺验证。

开孔率用 Creo 实体边界与侧壁拓扑核对直通证据。回执中的已核实开孔率是可证实的下界。实际直通率可能受轮廓类型和可追踪侧壁限制。[PTC 实体边界与轮廓接口](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Visiting_Solid_Geometry.html)

## 回退

保存工作并正常退出对应 Creo 会话后，在该 BWTL 安装根目录运行 `BWTL-Manage.exe -Rollback`。上一版为 `0.23.0-local.revision.1`，各会话的聊天和记忆位于版本目录之外。
