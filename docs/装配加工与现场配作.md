# 装配加工与现场配作

BWTL `0.23.0-local.fieldwork.1`。入口是「BWTL → 插件功能 → 装配加工与现场配作」。先打开总装的主表示，再读取组件树与参照。各目标使用完整实例路径，例如 `ID:42` 或 `ID:30/42`，不使用零件名代替实例路径。

| 编号 | 功能 | 输入与限制 |
| --- | --- | --- |
| 301 | 创建装配切除 | 使用顶层装配的现有闭合草绘，指定切除方向、盲深或贯穿及目标实例。 |
| 302 | 创建装配通孔 | 在指定平面用总装 XYZ 定位圆孔，可同时选多个同轴层。 |
| 303 | 批量创建装配孔组 | 指定首孔、直径、行列与两个方向的节距。一次最多 16 个孔位，孔位之间须留有间隔。 |
| 304 | 从已有孔传递孔位 | 读取源孔的内圆柱轴线，把孔位传到垂直于该轴线的目标面。直径输入 0 时沿用源孔直径。 |
| 305 | 按连接层分别生成孔型 | 最多三层，可分别加工通孔、沉孔或螺纹底孔。底孔只创建指定直径的几何，螺纹另行处理。 |
| 306 | 按部件外形生成避让窗口 | 将源组件的实体包络投影到选定草绘面，增加每侧间隙并切出贯穿的矩形窗口。 |
| 307 | 按线束路径生成过线孔 | 用顶层装配单段直线与隔板平面的垂直交点定位孔，输入包含所需护套间隙的实际孔径。 |
| 308 | 按组件间隙生成垫片 | 两个实体面须为无孔、坐标系对齐的矩形且沿 +Z 相向。按 0.05～100 mm 实测间隙创建并固定独立垫片。 |
| 309 | 生成装配定位标记 | 在当前装配中只出现一次的直接零件上，按零件坐标系建立并复核定位直线。 |
| 310 | 核对装配加工影响范围 | 读取指定顶层特征的 Creo 相交记录、实际实例路径、可见层级及同模型的其他实例。 |

## 操作范围

301–307 使用毫米制总装和目标零件。操作生成可编辑的原生草绘、封闭曲面和装配去料特征。每个去料特征只绑定一个实例。多个目标或分层命令会生成多条有编号的加工特征，可用 310 逐条复核。去料前后核对指定实例的体积及相交层级，任一步失败则清理该命令新增的特征。默认只在当前顶层装配显示加工结果，原零件模型和文件保持原状。插件不自动保存修改。

贯穿的封闭工具按操作当时的目标实体范围加余量建立。日后明显移动目标或调整厚度，需复核实际是否仍贯穿。加工定位以总装草绘为准。位置不确定时先读取参照，确认孔中心或草绘方向。

本机 Creo 10.0 自带 AFX 的 `quilt_cut.gph`。BWTL 使用该模板在装配级限定实例，未复制或修改 Creo 安装中的模板。原生自动相交会在重生成时扩大范围，直接重定义已有相交的装配切除也曾触发本机 Creo 原生回溯。正式实现通过先生成封闭曲面、再用原生 UDF 放置限定单实例的去料特征避开了这两条路径。

## 验证与回退

用独立 Creo 会话运行 `tests/native_fieldwork_ops.c` 和 `tests/native_fieldwork.c`。验证实际去料量、同型号重叠实例、移入后重生成、保存重开、失败回滚、垫片尺寸及定位标记。软件回归使用 `tests/Run-Regression.ps1`，隔离检查使用 `tests/Test-Isolation.ps1`。

已打开的 Creo 会话保存后正常重启即可加载新版本。需要回退时，先保存并正常退出相关 Creo 会话，使用 BWTL 管理器的回退功能恢复到 `0.23.0-local.layout.1`。安装保留各会话数据和上一个版本。
