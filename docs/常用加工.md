# 第171–180项 常用加工

本机版本 **0.23.0-local.shop.1**。在独立的普通单实体零件窗口打开 **BWTL → 插件功能 → 常用加工**，选功能填模板，也可以在聊天中直接描述加工要求。

| 编号 | 功能 | 输入与处理范围 |
| --- | --- | --- |
| 171 | 多级台阶孔 | 同一孔心，3–5 级圆孔。直径逐级减小，深度从入口面累计，保留盲孔底。 |
| 172 | 交叉通道 | 两个垂直平面各开一条圆形盲通道，核对轴线交点、实际去料和孔底。 |
| 173 | 孔背面沉台 | 指定现有贯穿圆孔和背面，输入沉台直径、深度、最小底部留料。 |
| 174 | 批量孔口去毛刺倒角 | 选 1–6 个完整圆孔口，各给出相邻孔壁和端面，统一等边倒角尺寸 C。 |
| 175 | 带岛型腔 | 矩形盲腔，保留 1–4 个互不接触的矩形岛。 |
| 176 | 分层型腔 | 2–5 层同心矩形。宽和高逐层缩小，各层深度从同一加工面累计。 |
| 177 | 内角过切避让 | 以现有矩形型腔的四个直角为中心，按刀径和实际型腔深度切出圆形避让。 |
| 178 | 孔内方位平面 | 在现有贯穿圆孔壁上切出带直壁的止转缺口。输入缺口宽、径向加深量和相对局部 +X 的角度。 |
| 179 | 轴肩退刀槽 | 选现有实心外圆柱和同轴基准轴，沿轴向定位整周槽。输入槽宽、径向深度和两侧槽根圆角。 |
| 180 | 螺钉头工具让位 | 围绕现有贯穿圆孔创建让位圆沉台。让位直径等于工具外径加两倍单侧余量。 |

加工面使用实体平面。定位坐标系的 XY 平面与加工面重合，+Z 朝外。另选方向基准面以确定草绘方向。退刀槽使用原点在轴线上的坐标系，Z 轴沿轴向，草绘面过轴且包含坐标系 X、Z 轴。尺寸单位为毫米，角度单位为度。

例如可以发送「在当前零件的 SURFACE:96 上做 3 级台阶孔，坐标系 SHOP_AT，方向面 RIGHT，孔心 X40 Y30，直径 16、12、8，累计深度 4、8、12，命名 STEP_HOLE」。应以本轮读取的实际面编号为准。

宿主核对原生几何、去料体积、实体数量和重生成。孔深、留料与槽根等通过几何见证点核对。操作默认留在当前会话，保存由用户决定。

## 回退

保存当前 Creo 工作并正常退出对应会话后，在其 BWTL 安装目录运行 `BWTL-Manage.exe -Rollback`。上一版为 `0.23.0-local.fastener.1`，各会话的聊天和记忆存放在版本目录之外。
