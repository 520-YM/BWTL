# 常用零件快速生成（第 231–240 项）

在桌面打开 Creo，选择「BWTL → 插件功能 → 常用零件快速生成」。选择一项后填写新零件名和实际尺寸，或用自然语言提出完整的新建要求。单位为毫米，新名称使用英文字母、数字、下划线或短横线，最长 31 位。

生成前检查尺寸、孔槽间距、孔边余量和钣金折弯区域。已有零件继续保留，新零件以毫米单位、三个默认基准面和默认坐标系单独创建并显示。公司模板里的专用参数可按需另行填写。模型经过原生重生成、单实体和几何检查，默认停留在当前会话，确认后可用 Creo 保存。尺寸为建模输入，实际应用仍按对应设备和安装图核对。

| 编号 | 功能 | 结构与主要参数 |
| --- | --- | --- |
| 231 | L形角码 | 一道 90° 原生翻边，底面沿 X 两孔。输入底面宽深、板厚、折边高、内 R、孔距和孔径。 |
| 232 | U形安装支架 | 两道同向 90° 原生翻边，底面两孔。输入底面宽深、板厚、折边高、内 R、孔距和孔径。 |
| 233 | 电源安装托架 | 两侧 90° 原生翻边，底面四个矩形布置的孔。输入底面宽深、板厚、折边高、内 R、X/Y 孔距和孔径。 |
| 234 | 屏幕安装背板 | 平背板，中央矩形通窗、四个安装孔。输入板宽高厚、窗口宽高、X/Y 孔距和孔径。 |
| 235 | 铰链垫板 | 矩形垫板及四个对称通孔。输入板宽长厚、X/Y 孔距和孔径。 |
| 236 | 门锁挡片 | 负 X 边居中开口，另一端布置两个安装孔。输入板宽长厚、两孔 Y 间距和孔径、缺口 Y 宽和 X 深。 |
| 237 | 线束固定夹 | 开口 U 形钣金托夹，底面两孔，沿 X 走线。输入 X 长、底深、厚、壁高、内 R、孔距和孔径。线束固定方式由装配方案确定。 |
| 238 | 阶梯隔套 | 两段同轴外径、贯通孔。输入两个外径、两个轴向长度和孔径。 |
| 239 | 可调限位块 | 矩形实体，两条平行 X 的长圆调节槽。输入块长宽厚、槽总长、槽宽和两槽 Y 间距。 |
| 240 | 可拆检修盖板 | 平盖板，四角紧固孔，中央横向一对把手孔。输入板宽长厚、四角孔距两类边的偏移、四角孔径、把手孔距与孔径。 |

折边参数是 Creo 的翻边高度输入。原生折弯会影响成形外包络。线束夹为开口托夹，盖板输出把手安装孔。

示例：新建一个 L形角码，零件名 L_ANGLE_80，X宽 80、Y底深 60、厚 2、折边高 18、内 R2、底部两孔间距 44、孔径 6。

如需回退，在 BWTL 管理器选择上一版本 0.23.0-local.fabrication.1。确认并保存自己的模型后重开 Creo。各会话聊天、记忆以及已保存模型独立保留。
