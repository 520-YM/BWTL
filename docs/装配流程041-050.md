# 装配流程 041–050

入口为「插件功能 → 装配流程」。各命令使用当前 BWTL 会话的装配方法库和 Creo 活动模型。案例由「仿照模型 → 装配学习」生成，组件也可用完整的 Creo 实例路径 ID:编号/编号 指定。

| 编号 | 使用方式 |
| --- | --- |
| 041 | 发送 `按装配记忆 案例 把上方导向轮支架装上`。先用案例布局表区分上、下、左、右，再应用案例中该站位的 Creo 原生定位。应先在 Creo 打开目标组件所属的父装配。 |
| 042 | 发送 `规划跨层装配 案例 "护网" "部件名"`。结果列出各自的父装配、组件路径、优先定位的支撑和后续组件。此指令只读。 |
| 043 | 发送 `先补支撑再装 案例 "站位" [新组件名]`。先定位同一个父装配下缺少的支撑，再定位目标。已有支撑重名时给出具体阻塞。已完成的支撑保留在当前装配，可在 Creo 核对和保存。 |
| 044 | 发送 `按装配规则安装 案例 ID:目标源路径 新组件 ID:旧支撑1=ID:新支撑1,ID:旧支撑2=ID:新支撑2`。每一对的左侧是案例路径，右侧是当前父装配的实例路径。各原生约束读回通过后才算安装完成。 |
| 045 | `匹配装配孔组 原实例 原配合面 原孔列表 新实例 新配合面 新孔列表 公差 [对应首孔序号]`。每组孔以 `SURFACE:编号,SURFACE:编号` 填写。按实测孔径、两两孔距、配合面及相对方向匹配；候选对称时可指定原首孔对应新列表第几项（从 1 开始）。这项操作不改模型。 |
| 046 | `核对阵列站位 新支撑实例 配合面 紧固件模型 杆圆柱面 紧固件贴合面 新站位孔列表` 逐孔读回孔径、最近站位距离及已装数量；换用 `按新孔组补装` 只向空位加装并复查，存在重复件时保留当前装配。使用换型后实际孔的圆柱面，最多 12 处。 |
| 047 | 发送 `比较装配试装 案例 ID:源模块 新组件 方案一映射 方案二映射`。方案写成 044 的格式，或用 `-` 表示案例自动选参照。保存目标装配和组件后，在独立目录生成两份基线试件，分别验证定位和位置。失败参照和基线副本保存在相应会话的 data\装配试装。 |
| 048 | 发送 `建立装配续做任务 任务号 案例 "计划.tsv"`。UTF-8 计划每行三列，源组件路径或站位、新组件模型、044 的支撑映射（全自动写 `-`）。在工作目录中打开已保存的目标装配后，发送 `继续装配任务 任务号 [步数]`。每步通过定位读回后保存模型并写续做记录。重新打开时会核对同一目录、模型版本、规则时间及已完成实例。用 `查看装配任务 任务号` 查看进度。任务最多 32 步。 |
| 049 | 在有坐标系的案例中发送 `记录装配方向 案例 朝外 CSYS:机柜坐标名 -Z`。在新装配中发送 `读取装配方向 案例 朝外 ROOT` 或用实例路径代替 ROOT，插件输出换算到当前顶层的方向。 |
| 050 | 在案例装配中完成装配学习后发送 `记录装配学习修订 案例 "调整原因"`。使用 `查看装配学习历史 案例` 查看日期、Creo 版本、原因和定位规则完整性。每条说明保留独立规则快照，便于对比。 |

049 和 050 的文件在对应会话的 data\装配方法库。041 和 043 的安装结果默认待保存。用匹配当前父装配的案例和工作目录运行。独立 Creo 10 样件涵盖双支撑、三面约束、新型号支撑和再次调用学习记录。回退可使用对应 BWTL 实例的 BWTL-Manage.exe -Rollback。
