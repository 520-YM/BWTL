# BWTL 钣金四孔与任务续接

在已经打开的单实体矩形钣金平板上发送「在当前钣金平板居中打4个通孔，孔径4.2mm，横纵孔距各50mm」。也可在「插件功能 → 钣金与机箱 → 机箱与安装」选择「钣金平板居中四孔」填写孔径和沿板长、板宽的孔距。

BWTL 读取实际矩形边界、板中心和板厚。它核对四孔位置的板料，从板面沿板厚向内加工，随后核对原生钣金切口、四个圆柱孔的孔径与位置、贯穿情况和总去料体积。完成的加工待保存。

复现件为 200 × 150 × 2 mm。出错的两次 SMT_CUT 已生成并重生，但体积仍为 60,000 mm³。切向没有穿进板材，BWTL 的去料检查撤销了无效切口。修正版会给出实际的失败阶段、可测数值和撤销状态。只有在回退核对通过且目标模型与工作目录和特征状态一致时，才交回给本轮规划继续处理。
