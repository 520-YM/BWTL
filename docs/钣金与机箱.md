# 第151–160项 钣金与机箱

本机版 **0.23.0-local.cabinet.1**。单独打开原生钣金零件，选择 **BWTL → 插件功能 → 钣金与机箱**。各项可填写模板或在聊天中直接提出。长度单位毫米，角度单位度。模型修改默认留在当前会话，由用户保存。

| 编号 | 功能 | 本批范围 |
| --- | --- | --- |
| 151 | 同边多段翻边 | 一条自由直边的 2–5 个非重叠区间。共用翻边高度、角度、内半径和翻向。逐段核对平面段和折弯的实际长度。 |
| 152 | 四边翻边托盘 | 活动空钣金零件。矩形底板四边各折 90°，每段两端等量退让。退让量沿原板边测量。 |
| 153 | U 形机箱壳 | 活动空钣金零件。按纵深、内净宽、厚度、高度和内半径创建，核对两侧壁内侧间距。 |
| 154 | Z 形钣金错台 | 在已有自由直边延伸两道 90° 折弯，核对两平行驱动面高差。 |
| 155 | 相邻翻边留缝 | 以相邻翻边的指定平面为参照，通过局部法向切口增大平直段端部缝宽。填写要保留的折弯根部高度。 |
| 156 | 翻边端部避让 | 沿所选顶端直边，从起端或末端做局部直线缩短，保留指定高度的折弯根部。 |
| 157 | 门板回折边 | 从已翻起的自由直边追加一道 90° 折弯，回执提供与门板参考平面的间距。 |
| 158 | 板边挂耳 | 指定起止距离，创建 90° 折弯挂耳，可附中心圆形贯穿孔。 |
| 159 | 圆形翻孔 | 在已有贯穿圆孔的自由整圈上建立原生同轴翻边，核对中心仍通和翻边内径。 |
| 160 | 折弯改规格 | 一次指定 1–4 道普通角度折弯或普通附着直边翻边，逐项核对旧角度和内半径，重生成后读回实际折弯面。 |

板边距离沿 Creo 原生边方向从起点量取。端部留缝与避让适用于可确认厚度和边界的平直翻边。多步新建失败时会移除本次新增特征并核对原有实体。批量改折弯失败时按原定义恢复并核对实际参数。原生平面翻边采用 Creo 的附着平板和随边展开机制。[PTC 附着平板接口](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Feature_Element_Tree_for_the_Attached_Flat_Wall_Feature.html)

示例「在当前空钣金零件创建四边翻边托盘。底面 FRONT，方向面 RIGHT，底板 90 × 70 mm，板厚 2 mm，翻边高 20 mm，内半径 2 mm，各端退让 8 mm，方向 POS，命名 TRAY」。

## 回退

正常退出对应 Creo 会话后，在该会话安装根目录运行 `BWTL-Manage.exe -Rollback`。上一版为 `0.23.0-local.panel.1`。聊天和项目数据位于程序版本目录之外。
