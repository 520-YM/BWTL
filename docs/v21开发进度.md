# 霸威天龙 v21：11—15 功能与使用说明

版本：0.21.0-preview.1，2026-10-29。独立实现，未搬移第三方仓库代码。

| 编号 | 本版能力 | 中文指令示例 |
|---|---|---|
| 11 | 编辑独立关联草绘：增加图元、修改尺寸/约束，平移直线/圆/圆弧，明确删除图元/尺寸/约束 | 读取草绘 BASE_SK；把圆草绘 CIRCLE_SK 的图元0向X移动3毫米、Y移动4毫米 |
| 12 | 实际边或单段基准曲线关联投影到已有草绘 | 把当前读取的边82关联投影到 EDGE_PROJ；把基准曲线 PROJECT_SOURCE 引用到 PROJECT_SK |
| 13 | 引用已有闭合草绘建立首个或追加标准实体拉伸 | 使用 BASE_SK 沿草绘正法向拉伸加料20毫米，命名 ADD_20 |
| 14 | 已有单实体定深或单向贯穿切除 | 使用 HOLE_SK 沿草绘正法向切除4毫米，命名 CUT_4；使用 HOLE_SK 沿草绘正法向贯穿切除，命名 CUT_ALL |
| 15 | 闭合草绘和实际基准轴旋转加料 | 使用 REV_SK 绕基准轴 REV_AXIS 正向旋转360度加料，命名 REV_ADD |

先读取当前零件及所需草绘/参照。名称、图元编号、尺寸编号、边编号以本次原生读回为准，示例编号不能直接套用。一次发送一项操作；创建草绘和创建实体分开发送。方向不明确时助手会询问。原生回执成功才算完成，无须再点“执行建模”。

限制：本批新增写入限独立普通实体零件，最多一个活动实体；不支持装配内部组件、钣金专用操作或多实体合并。编辑对象是独立关联草绘，不泛化为任意导入/嵌入式草绘。移动受已有尺寸约束限制，不会自动删约束；禁止删除最后图元。投影源必须先于草绘建立以免循环引用；单段曲线可引用，多段曲线尚未开放。标准实体特征要求闭合有效轮廓；空切或切空整个零件会拒绝。15仅旋转加料，旋转切除属16仍待开发。本批不自动保存，不另建模型代替当前操作。

## 本机实测

Creo Parametric 10.0.0.0独立会话：94条操作中87条成功、7条预期拒绝，回归失败数0。包含01—10回归。完整记录在 tests/reports/v21-native-result.log 与 v21-native-cases.log。

- 80×60×10首个拉伸体积48000 mm³；同草绘追加至深度20后体积96000 mm³。
- 半径5、深度4切除及贯穿切除体积符合解析值；修改原草绘尺寸能驱动下游实体更新。
- 原生参照读回匹配投影源，源曲线改变后投影同步改变；长度统计排除复合曲线容器重复计数。
- 圆、直线、圆弧平移后重新提取草绘核对坐标；删除图元、尺寸与约束经实际读回检查。
- 360度与负向90度旋转加料体积符合解析值，草绘/轴父参照和单实体状态有效。
- 开放轮廓、无交集切除、删除最后图元等拒绝路径检查特征集合、重生成健康和体积保持。

使用SDK正确草绘模式转换，解决修改后被重生成恢复的问题。失败会尝试回退并如实报告，不保证任意外部模型均可恢复。以上不代表跨机器或任意模型测试通过。

## 安装与版本管理

使用 dist/BWTL-Setup-0.21.0-preview.1.exe。安装、升级和回退沿用《v20安装与数据迁移.md》，保留版本目录、共享聊天数据与配置备份。已有Creo会话需保存工作后重启才能加载新DLL，不自动重启用户会话。

包含程序、源码、资源、完整聊天/记忆和历史工程快照。工程快照排除dist旧安装包和build编译中间目录，避免递归膨胀；原生工程和数据另行完整归档。历史仅供检索上下文，不训练模型、不重放旧指令。公开分享即分享其中聊天记录；登录凭据、Creo和PTC SDK不随包分发。
