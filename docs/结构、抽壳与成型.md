# 第 81–90 项结构、抽壳与成型

本机版本 `0.23.0-local.structural.1`，目标为 Creo Parametric 10.0.0.0。入口为「插件功能 → 结构、抽壳与成型」，也可直接在统一输入框描述任务。菜单填入需求模板，需要补齐实际参照、定位与尺寸。默认不保存模型。

| 编号 | 功能 | 当前范围 |
| --- | --- | --- |
| 81 | 多面开口抽壳 | 2–8 个实际实体开口面，统一向内壁厚 |
| 82 | 局部变壁厚抽壳 | 一个开口面、全局壁厚，另选 1–5 个不同壁面分别设置厚度 |
| 83 | 多面同步拔模 | 1–8 个实际平面，一次原生拔模，共用中性平面、方向和角度 |
| 84 | 分割拔模 | 以中间中性平面分割，分别给两侧角度；当前不含分模曲线分割 |
| 85 | 可变角拔模 | 在待拔平面与中性面的交线上指定两个不同站位点及角度，原生连续可变角定义 |
| 86 | 带拔模的直线轨迹筋 | 基面上的一条直线路径、底宽、高度和两侧拔模角；当前不含圆弧及多段路径 |
| 87 | 螺钉柱 | 平面上的圆柱凸台，可无孔、柱顶盲底孔或贯穿柱体的底孔 |
| 88 | 卡扣结构 | 悬臂斜坡钩；另有配合窗口入口，按单侧间隙生成矩形窗口 |
| 89 | 密封圈槽 | 端面、轴外圆或轮毂内孔的矩形环槽；由截面、压缩率及槽宽推导深度 |
| 90 | 毛坯加工余量 | 复制为独立毛坯，对 1–8 个指定实体面做正向偏置；核对原零件未变 |

本批面向已有正体积的普通单实体零件。尺寸毫米、角度度；拔模角绝对值为 0.1–30 度。拔模方向面与中性面平行，待拔面与拔模方向正交，不自动扩展相切面。筋沿所选基面法向长高，顶部宽为 `底宽 − 2 × 高度 × tan(拔模角)`，必须为正，筋需完全落在支承区域并连接原实体。第 86 项以路径起点和路径法向平面关联梯形截面，再沿直线长度拉伸，保留关联辅助参照。

螺钉柱的定位坐标系原点须在实际支承平面内，+Z 指向面外。底孔从柱顶沿 −Z 加工，深度不大于柱高；无孔填直径和深度 0。它不是自动螺纹，可在明确规格后调用已有原生螺纹孔功能。卡扣的 +X 指向支承面外，+Y 为宽度，+Z 为板厚和钩高；窗口从配合板面沿 −X 切除。卡扣功能创建零件几何，不自动进行装配配合或强度判断。

密封槽深为 `密封圈截面直径 × (1 − 压缩百分数 / 100)`，压缩率 0–40%，槽宽至少等于截面直径。径向槽沿同轴坐标系正 Z 定位。截面、压缩率及标准尺寸由用户或经确认的技术文件提供，本批不内置密封标准自动选型。

毛坯副本留在当前 Creo 会话中，未自动保存、未切换当前窗口；需要从会话列表选择并自行保存。副本为独立复制，不自动跟随原件后续修改。目标名称已在会话或磁盘存在时拒绝覆盖；失败的副本会清除。不要把原零件当作毛坯继续加工。

## 示例

- 「对当前零件顶面和底面同时开口，统一向内抽壳 2 mm，命名 SHELL_A。」
- 「在当前零件的中间基准面 MID_Z 两侧拔模，角度分别 5 度和 3 度，使用指定侧壁，命名 DRAFT_A。」
- 「沿基面上的直线 RIB_PATH 加筋，底宽 4 mm、高 8 mm、两侧拔模 3 度，命名 RIB_A。」
- 「在端面坐标系 SEAL_AT 开密封环槽，中心线直径 30 mm，截面 3 mm，压缩 20%，槽宽 4 mm。」
- 「把当前零件复制为 STOCK_A，对顶面和指定侧面增加 2 mm 加工余量，保留原零件。」

先读取本轮参照，面和边的编号只在当前模型版本有效。未知定位、方向或工艺尺寸时补齐必要参数；不从历史记录猜测旧编号。
