# 第211–220项 读模型与整理模型

本机版本 **0.23.0-local.organize.1**。在独立零件中打开 **BWTL → 插件功能 → 读模型与整理模型**。只有批量重命名会修改当前模型，修改留在会话内，由用户保存。

| 编号 | 功能 | 当前范围 |
| --- | --- | --- |
| 211 | 孔位坐标表 | 从单实体内圆柱孔壁读取每个完整孔段的轴线端点、直径和端型。可选模型默认 XYZ 或指定坐标系，单位毫米。 |
| 212 | 自动归类孔规格 | 按端型、实测孔径和轴向跨度分组。按输入公差控制每组的范围；台阶孔按孔段统计。 |
| 213 | 导入件槽口识别 | 选导入特征的相对入口和出口平面，识别矩形或圆端槽。用两面轮廓配对及九点轴向射线验证，列出未核实轮廓。 |
| 214 | 自动提取安装平面 | 筛选单实体的实际平面，按面积排序。可选方向和最小面积，返回面 ID、外法向及一个面内见证点。 |
| 215 | 批量重命名特征 | 一次最多八个活动特征，按 ID、旧名和新名确认。支持互换和循环改名，冲突拒绝并核对失败后的整组恢复。 |
| 216 | 查找未被引用的基准 | 找当前零件原生父子树中未查到下游引用的活动基准面、轴、点和坐标系。 |
| 217 | 查找失败与抑制特征 | 读取失败、受上游影响、未重生成和各种抑制状态。存在失败特征时也可读取。 |
| 218 | 识别重复或重叠孔位 | 从原生直孔定义查找重复候选，并筛查实际平行内圆柱孔段的投影及轴向重叠。同轴孔段另计。 |
| 219 | 模型版本参数对照 | 选同一 Creo 会话中以不同名称载入的另一版零件。比较模型级参数的类型和值，兼容单位按物理量换算。 |
| 220 | 改模影响预检 | 选择拟编辑、抑制或删除的特征，列出直接依赖并沿原生树追踪 1–5 层。 |

孔位表和孔规格统计针对可核实的完整圆柱孔段。交叉、部分圆柱壁、螺纹等复杂孔型可能缺少足够的端型证据。重复或重叠结果用于定位待核查项。基准和改模影响的检查范围是当前零件原生父子树，外部装配、跨模型参照和关系式需要单独核对。[PTC 特征查询接口](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r12/german/creo_toolkit/user_guide/Feature_Inquiry.html)

## 回退

保存工作并正常退出对应 Creo 会话后，在该 BWTL 安装根目录运行 `BWTL-Manage.exe -Rollback`。上一版为 `0.23.0-local.inspection.1`，各会话的聊天与记忆位于程序版本目录之外。
