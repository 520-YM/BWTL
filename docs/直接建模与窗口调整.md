# 直接建模与窗口调整

本机版本 0.23.0-local.modelroute.1 统一处理新建和加工的组合请求。发送「画一个圆柱，抽壳。数据自己给」时，BWTL 先新建独立圆柱，再按新零件的实际端面执行抽壳。需要操作已打开的零件时，可以明确说「对当前零件抽壳」。旧版分别检查新建用词和加工用词，后续的「抽壳」可能覆盖开头的新建意图。

该版本从空白 Creo 使用真实 Codex 和原生 Creo 接口重放上述指令，核对新零件绑定、抽壳特征、实体体积和单条回复。上一版为 0.23.0-local.directchat.1，可在保存退出 Creo 后通过安装管理回退。

本机版本 0.23.0-local.directchat.1 采用统一输入框。明确说「在当前零件创建三点基准面」或「把刚新增的功能演示给我看」，BWTL 会核对参照、调用 Creo 并按实际回执汇报。演示可先建临时示例件。只看方案可说「只分析」或「不要修改模型」。

旧版的模式选择和写入判断相互独立。“演示给我看”没有匹配旧版的执行词，智能协作中的本轮请求仍可能被拦截。新版按本条消息识别执行意图，明确的分析要求仍限制写入。生成的答复误用历史权限时会自动重试一次，完成后显示一条结果。

窗口取消模式下拉框、功能开发和应用升级入口。后续升级在 Codex 中处理。顶部仍提供插件功能、公司标准和工作目录。

验证包括隐藏原生控件检查、意图与连续任务回归、独立 Creo 中从空白会话执行三维样条演示，以及显式分析请求的写入拦截。已打开的 Creo 窗口在保存后正常关闭，重新打开即可载入新版。需要回退时，通过 BWTL 安装管理选择上一版 0.23.0-local.advdatum.1。
