# 第111–120项 零件检测与分析

本机版 **0.23.0-local.quality.1**。打开零件后进入 **BWTL → 插件功能 → 零件检测与分析**。选取模板并补上实际参照和阈值，也可以直接用中文描述检查要求。检查读取 Creo 模型并在 BWTL 聊天中返回实测结果。

| 编号 | 功能 | 使用范围 |
|---|---|---|
| 111 | 精确测量 | 指定边长、修剪面面积、圆柱直径、两参照最近距离及最近点、两直边支撑线的锐夹角。 |
| 112 | 最小壁厚检查 | 指定最多六组相对平行实体面。沿法线验证连续材料，并返回已测面组的最小值和逐组结果。 |
| 113 | 孔边距与孔间距 | 读取凹入圆柱孔面。两个平行孔轴输出中心距和投影净距，指定一个孔与一条边时输出该边至孔轴的最短投影距离及净距。 |
| 114 | 拔模角分析 | 按模型坐标的 ±X、±Y、±Z 给出有符号角。平面角度恒定，曲面使用有效面内采样。 |
| 115 | 曲面连续性分析 | 指定公共边，读取两侧邻面并在边内取11点，检查位置偏差 G0 和切平面夹角 G1。 |
| 116 | 质量属性报告 | 报告体积、表面积、均匀密度形心。按 Creo 模型当前密度设置读取质量、质量重心和主惯量。 |
| 117 | 零件对称性检查 | 指定平面，比较单实体镜像前后的原生射线穿透和形心。 |
| 118 | 两版本几何对比 | 同一 Creo 会话中加载不同名称的单实体版本。按同一模型坐标比较体积、面积、包围盒、形心和截线。 |
| 119 | 特征依赖追踪 | 按特征名或 ID 沿原生父子链向上、向下追踪1至5层，列出实际关联和状态。范围是当前零件内部。 |
| 120 | 公司设计规则检查 | 按明确提供的规则组合检查体积上下限、必填模型参数、指定壁厚、孔净距、边净距及正向拔模角。每项给出符合、不符合或未判定。 |

壁厚用平行面间距作为数值，并要求找到由这两个面围成的连续材料穿透。对面之间有空气时，该组不计入壁厚。检查结论适用于指定面组。

孔净距按孔轴投影。平行孔的净距等于中心距减去两孔半径。孔到边的净距等于孔轴至指定修剪边的最短距离减去半径。

对称与版本比较每个坐标方向使用 7×7 至 25×25 的射线网格，并列出有效、未判定及有差异的射线数。结论为实际检测到的差异或采样范围内的一致性。细小局部变化可能位于射线之间。两版本需事先使用同一坐标框架。曲面拔模和连续性也按实际采样范围报告。

公司规则需要输入明确阈值和相关面、边或参数。可从公司标准中把适用条款粘贴进请求。公司资料通过「公司标准」入口管理。此版规则引擎使用七类明确规则，未判定项目会单独列出。

## 指令示例

模型名、面 ID、边 ID、阈值均为示例。使用前读取活动零件的实际参照。距离、面积、体积统一换算为毫米、平方毫米、立方毫米。质量与惯量附 Creo 原生单位。

```text
CREO_OP QA_MEASURE PART_A DISTANCE SURFACE:96 SURFACE:91
CREO_OP QA_WALL PART_A 2 SURFACE:96 SURFACE:91
CREO_OP QA_HOLES PART_A PAIR SURFACE:125 SURFACE:153 6
CREO_OP QA_HOLES PART_A EDGE SURFACE:125 EDGE:100 4
CREO_OP QA_DRAFT PART_A SURFACE:96 Z POS 2
CREO_OP QA_CONTINUITY PART_A EDGE:142 0.1 0.01
CREO_OP QA_MASS PART_A
CREO_OP QA_SYMMETRY PART_A PLANE:MID_X 0.01 15
CREO_OP QA_COMPARE PART_A PART_B 0.01 17
CREO_OP QA_DEPS PART_A HOLE_A BOTH 3
CREO_OP QA_RULES PART_A MIN_VOLUME 100 MAX_VOLUME 200000 REQUIRE_PARAM PART_CODE MIN_WALL SURFACE:96 SURFACE:91 2
```

## 验证与回退

功能分别保存在 `src/功能/quality`，通用几何读取和射线验证由同一目录内的共享模块提供。协议、菜单、提示和权限判断通过原有 BWTL 入口，所有检查协议均归为模型读取。

Creo 10 原生验收使用独立测试件，检查已知边长、面面积和壁厚、空气间隙、孔轴距离、拔模角、尖角与相切边、质量属性、镜像、等体积异孔位、父子依赖及混合规则。测试同时核对活动模型、模型版本标记和实体体积。用例次数及版本加载证据见本机的 quality-update-status.json。测量和射线依据 PTC Toolkit 接口。[测量文档](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Measurement.html) · [射线文档](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Ray_Tracing.html)

正常重开 Creo 可加载新版本。回退时先保存当前模型，正常退出要回退的会话，然后在该会话安装根目录运行 `BWTL-Manage.exe -Rollback`。本次保留 `0.23.0-local.reuse.1` 作为前一版本，聊天、记忆和工作文件独立于程序版本。
