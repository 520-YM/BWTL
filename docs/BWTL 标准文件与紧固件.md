# BWTL 标准文件与紧固件

顶部「标准文件」菜单包含「打开已验收标准件」「紧固件」「建模规则」「资料」和「归档」。打开「紧固件」后，侧栏先列出 8 个分类。

| 分类 | 内容 |
| --- | --- |
| 螺丝装配 | 沉头、扁圆头、内外六角等螺丝及配套装配 |
| 螺栓 | 螺栓与马车螺丝 |
| 螺母 | 六角、方形、法兰、蝶形与滚花等螺母 |
| 销 | 销类 |
| 压铆件 | 压铆螺丝、盲孔与通孔压铆螺母、铜柱等 |
| 铆钉 | 铆钉类 |
| 自攻螺丝 | 自攻螺丝、大扁圆头螺丝与异形螺丝 |
| 垫圈 | 垫圈类 |

点击分类或右侧箭头即可在侧栏原位展开或收起。多个分类可同时展开，滚动查看 Creo 型号与已有中文说明。键盘可用方向键选择分类，向右方向键展开、向左方向键收起，Enter 或空格切换展开状态。相同目录中的同名模型只列一次，选中时使用数字修订最高的实际文件。族表中的规格实例随对应型号管理，清单以磁盘上的零件和装配模型为单位。

点击型号会在 Creo 中打开该紧固件，并把原生文件保存到当前工作目录，读回核对后回复实际文件路径。工作目录中的同名不同内容文件需要先确定处理方式；同内容文件可直接复用。装配型紧固件连同 Creo 备份生成的依赖文件一起复制。临时备份保留在 BWTL 的 所选数据盘会话目录。BWTL 先查本实例的分类，受管理的次实例缺少该分类时读取本机主 BWTL 的对应分类。

聊天中可发送「查找紧固件 BSOS_3_5M3XX」「读取紧固件 BSOS_3_5M3XX」或「打开紧固件 BSOS_3_5M3XX」。自然说法「BSOS_3_5M3XX我要调这个出来」也可直接在活动 Creo 进程中打开。读取会回报模型信息，打开会确认实际活动窗口和源文件版本。限定范围是本机配置的 8 个紧固件分类及该分类下的模型，受管理的其他 BWTL 实例沿用分类回退。型号唯一时使用该路径下数字修订最高的版本，有同名候选时可在菜单按分类选定。对已经在 Creo 里打开且有待保存修改的同名模型，先保留当前修改，再由用户确定是否需要换版本。

## BSO M3×6 查找、另存和装配

聊天输入「查找 BSO M3×6」读取标准库族表里的实际实例。输入「我要 BSO M3×6」或「另存 BSO M3×6」会从该实例另存原生独立零件到当前 所选数据盘 Creo 工作目录，文件基名为 `BSO_3_5M3X6_BWTL`。后缀区分项目独立件与库里的族表实例。源文件只读，已存在的项目件要通过原生几何核对才复用。

在目标装配中同时选中同一块板的压铆头贴合面和 1–12 个 Ø5.4 圆孔的孔壁，发送「装配 BSO M3×6 到选中的孔位」。BWTL 会核对孔径、接触面、方向和重复件，在当前顶层用固定定位批量装入并回读。装配默认未保存。适用范围为本机已验证的这一库件；BSOS、其他规格和未选定的孔位不会借用该流程。

调用资料工具时，「公司库」「公司标准库」等入口解析为 所选数据盘已登记的公司资料目录。受管理的次实例共用主库的读权限，菜单和聊天仍可按当前实例读取已登记的紧固件分类。明确提交的其他目录仍按用户授权范围检查。下次正常重开 Creo 后使用新版本，可用 BWTL 管理器恢复上一版本。

本机曾从 0.23.0-local.fasteneraccordion.1 更新到 0.23.0-local.fastenerauth.1。正常重启 Creo 后，可以在聊天中用型号读取或打开，并通过回执核对文件名。需要回退时恢复 0.23.0-local.fasteneraccordion.1，再正常重启。
