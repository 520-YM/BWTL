# Creo 默认装配

发送「默认装配 零件名」可把零件装入当前活动装配，名称填写 Creo 零件名。要从当前零件一步生成装配，可先激活源件并发送「创建一个空装配，把这个零件默认装配到里面」。插件在切换窗口前绑定会话里的真实零件，源件可以尚未保存。装配结果由用户保存。

默认定位对齐零件和装配的默认坐标系。插件回读组件实例和原生约束。在取用之前确认源件仍在会话中。装配学习可复用特定安装面的定位方法。空装配中的这项操作直接使用 Creo 默认定位。

此版本在独立 Creo 验证已加载未保存的源件、组合指令、实际组件实例和原生约束。如需回退，使用对应实例的 BWTL-Manage.exe -Rollback。
