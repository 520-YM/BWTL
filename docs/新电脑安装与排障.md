# 霸威天龙：新电脑安装与排障

安装包：0.21.2-preview.1。目标：64位Windows、Creo Parametric 10.0.0.0。
插件运行核心为 v21.2；菜单由插件主动加载，不依赖原电脑的个人界面配置。

## 第一次安装

1. 将 `BWTL-Setup-0.21.2-preview.1.exe` 复制到另一台电脑并双击，不需要手动解压。
2. 检查所选 `config.pro` 是这台Creo启动时实际读取的配置。路径不是所有电脑都相同；不知道时在Creo的配置编辑器核对配置来源。
3. 默认按当前Windows用户安装到 `%LOCALAPPDATA%\BWTL`。公司配置只读时需由管理员允许修改该配置，安装器不会悄悄改另一份文件。
4. Codex路径可留空按本机查找；要使用AI，本机需安装并登录可用Codex。不导入作者登录凭据。
5. 如果明确不再使用旧 `CreoSafeResident` 桥接，可勾选停用旧桥接。此选项默认关闭，只注释所选config.pro中该桥接的注册，保留备份，不删除旧程序。
6. 点击“一键安装 / 升级”。安装器检查完整性、注册插件、导入已有聊天和记忆、创建管理入口。
7. 保存工作，退出并重启Creo。首次出现插件来源确认时核对名称BWTL并允许。顶部查找“霸威天龙”，按钮打开原生助手；备用入口是在图形区依次按c、d、x。

菜单使用插件自带 `toolkitribbonui.rbn`，涵盖无模型、零件和装配上下文。不复制原电脑完整个人UI、不覆盖WJT或第三方菜单，不依赖 `load_ui_customization_run_dir yes`。
数据历史作为检索/记忆输入，不代表重新训练AI模型。新电脑仍使用自己的Creo模板。

## 升级与回退

双击新版安装包，保持原安装目录与原config.pro，点击升级。安装者自己的后续聊天保留，记录上一版本及数据备份；安装包版本不同才能更新文件。
需要回退时点击安装窗口“回退上一版”，或开始菜单相应入口，然后重启Creo。回退保留数据。回退至0.21.1会恢复旧版缺少独立菜单资源的状态，备用cdx入口仍取决于DLL是否成功启动。

## 卸载

直接运行安装包，点击“卸载 / 数据清理”；也可用开始菜单“霸威天龙 → 卸载霸威天龙”，或安装目录的 `BWTL-Uninstall.exe`。
两个独立选项：删除程序文件与历史版本（默认勾选）；删除聊天、记忆、备份数据和内置历史副本（默认不勾选）。
四种组合都移除所选配置中的BWTL启动注册；删除数据不可通过插件恢复。程序被Creo占用时拒绝删除，先保存并退出Creo后再卸载。
仅清理本插件管理的安装目录，不删除Creo、模型、模板、其他插件或下载的EXE/ZIP。只删除程序时保留小型清理入口，便于以后清理数据。下载包中仍含作者历史，重新安装时会按导入规则恢复这些作者资料。

## 没有顶部菜单或助手打不开

不要仅凭“安装完成”判断已加载。点击安装窗口“导出诊断”，将生成的TXT文件发给维护人员。报告默认放在安装目录 `diagnostics`，包含安装版本、配置注册、DLL校验、菜单资源、运行日志末尾及Codex程序发现结果，不导出聊天正文或登录凭据。

| 检查结果 | 下一步 |
|---|---|
| 没有active.json | 检查当前Windows用户、安装是否完成、安装目录是否改变 |
| 没有runtime.log | 未确认DLL启动；检查实际配置来源、信任确认、DLL依赖 |
| 日志比安装时间早 | 旧日志不能证明本次安装成功启动，重启后再导出 |
| ProCmdActionAdd / ProCmdDesignate非0 | 检查消息资源或命令注册错误，提供报告 |
| DLL校验不一致 | 重新运行相同发行安装包核对，勿混用其他版本DLL |
| cdx能打开但顶部无菜单 | 菜单资源/上下文问题，提供报告及当前Creo模式 |
| 旧桥接重复注册警告 | 只停用确认不再使用的旧桥接；其他配置中重复注册需另核对 |
| 原生窗口能开但AI失败 | 与菜单不同；检查本机Codex登录和网络，勿反复改Creo配置 |

## 验证范围

构建前检查旧功能冻结基线，打包前运行非交互回归。安装器覆盖首次安装、升级、回退、数据保留、卸载四种组合、占用/越界/联接点拒绝和新增诊断场景。
发布报告列出实际完成的检查；本机验证不能代替每台电脑的Creo补丁版本、授权、企业启动脚本和安全策略验证。不能承诺所有环境零故障。
