# Creo 原生 AI 助手

原生 Creo TOOLKIT 对话窗口，后台调用本机已登录的官方 Codex CLI。不使用浏览器、MCP 或 CREOSON。AI 引擎是后台独立进程，不是把整个 Codex 桌面应用嵌入 Creo。

## 启用

新版 codex_native_ai.dll 已编译，protk.dat 已指向新版；现有 Creo 会话仍使用原 DLL。保存自己的工作后，下次重新启动 Creo 即可加载新版。此次没有关闭、重载或操控正在运行的 Creo。

入口是全局“Codex助手 → Codex Native”，零件与装配均可用；快捷命令 cdx。原生窗口最下方的输入框用于输入，点击“发送给 AI”。上方大区域为回复记录。model / 读取模型 / 当前模型仍是本地命令。

## 当前能力与限制

支持中文对话、建模建议、当前活动模型名称作为上下文，以及当前窗口会话的近期对话。暂未接入尺寸、几何、特征修改或保存操作。不能据此声称 AI 已执行建模。

使用现有 Codex ChatGPT 登录，消耗对应账号的可用额度。没有复制或显示登录令牌。启动忽略用户 Codex 配置，使用 read-only sandbox、ephemeral 和 no-daemon；请求要求只回答、不使用工具。插件代码不包含截图、鼠标或键盘控制。网络等待通过 Creo 官方 UI 定时器轮询，不在按钮回调中阻塞等待。当前回复为整段显示，尚无逐字流式输出。

用户发送的文字、近期对话和当前模型名称会发送给 AI，未上传模型文件或几何。最近请求、回复及引擎日志位于 Windows 临时目录 CreoCodex-进程号 文件夹；会覆盖最近请求文件，对话也保留在插件内存。关闭窗口取消正在等待的后台进程，180 秒超时。窗口对话记录在卸载或退出后不保留，临时文件不会自动删除。

Codex 引擎路径当前固定为本机已验证的安装版本；升级或移除 Codex 后可能需要更新 src/assistant.c 中路径并重新编译。
