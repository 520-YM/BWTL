# 钣金车间第 391–470 项

本机发布版本为 `0.23.0-local.smy.5`。第 391–470 项中，62 项已接入「插件功能」菜单和聊天，18 项仍在开发台账中。

## 打开与使用

打开钣金零件，在 BWTL 的「插件功能」中找到对应的「钣金车间」子菜单。选中功能会填写操作草稿，补上实际参照、尺寸或工作目录文件后发送。也可直接在聊天里说出编号和需求。文件输入使用当前工作目录的基名。需要供应商或公司批准参数的功能会按规则表读取，测试数据仅供验收。

例如打开可完整展开的钣金件后，发送「执行钣金车间第 451 项，按这个零件的固定面展开，材料密度 7850 kg/m³，给出净料、毛坯面积和单件重量」，并指定已确认的固定面。功能列表包含各项输入字段。

## 回退

保存手头模型并退出需要回退的 BWTL Creo 会话。主实例可用安装目录内的 `BWTL-Manage.exe -Rollback` 切回上一版本。各独立实例使用各自安装目录内的管理程序，或用该目录的 `Install-BWTL.ps1 -InstallRoot <实例目录> -Rollback -Silent -NoShortcuts`。检查各自的 `active.json` 和 `protk.dat` 后重新打开 Creo。

## 数据、产物与验收口径

- 工作清单使用 UTF-8，字段以空格或制表符分隔。模型和几何参照须取自当前 Creo 快照。CSV 导出先生成同级临时目录，回读及核验通过后才提交到新目录。
- 排样清单字段为零件、DXF 基名、材料、板厚、纹向、覆膜、数量、左右件标记及允许旋转。纹向为 FREE、X、Y，覆膜为 UP、DOWN、NONE，左右件为 L、R、N，旋转为 TURN 或 LOCK。X 或 Y 纹向禁止转 90°，所有零件禁止镜像。方案按轮廓包络保守摆放，不做凹部套排。余料自动匹配当前仅支持完整矩形。
- 折弯工艺表中每道弯使用 SURFACE:编号、模具、挡料基准、首件检查项目。可额外用 BEFORE 前序弯面 后序弯面 记录依赖。候选顺序按真实折弯长度和换模次数排序，模具运动及中间状态属于另行验收项。
- 折弯负荷规则表字段为牌号、模具、设备、板厚、角度、单位长度负荷 kN/m、设备限值 kN、模具单位长度限值 kN/m、最大加工长度 mm、版本。数值应来自公司批准的设备和模具资料。
- 本批用测试材料表、供应商规格格式和 Creo 自带工程图样板验收。成形库当前只做规则查询，未放置真实公司冲模。工程图样板已创建三个绑定模型的视图，仍需核对公司视图布局。两版对比当前覆盖板厚、包络、折弯及展开图元，立体拼缝仍需对应面测量。交付包校验文件内容和当前模型状态，已签发 PDF 和工艺文件的业务对应关系由输入记录提供。
- 验收入口为 tests/native_workshop_stock.c。使用本机 BWTL-Fieldwork/Run-ProbeHidden.ps1 的 Custom 模式，以新工作目录启动独立 Creo，工程图验收另设 BWTL_SMY_DRAWING_FIXTURE 为模板路径。原生回执在 workspace/workshop-stock.log，结果计数在 workspace/machining-result.log。测试包括有效模型、错误输入拒绝、回滚、命名冲突及交付后篡改检测。

## 续做验收范围

- 成形展平（400）第一次使用显式参照收集器时，独立测试 Creo 在原生创建调用中触发访问冲突。回溯保存在 `continuation-form1/workspace/traceback.log`。现改用原生自动收集器，并预查副本中仅有一个活动成形。单成形的开、关切口投影模式通过，无成形与多成形输入被拒绝。该命令按模型版本复核源件，只交付副本展开的下料 DXF。
- 紧固与焊接（402–403、405–408）覆盖压铆螺柱底孔与安装侧标记、双向压铆工具、对应装配坐标系下的孔轴对位、螺钉工具通路、点焊坐标表、实际贯穿塞焊孔与胶囊形定位槽。圆柱工具净空使用射线取样，结果不替代碰撞仿真。点焊布置验证第一块板和电极落点，贴合和第二侧工装另验。
- 紧固与焊接工艺表（410）读取当前工作目录的工序清单。紧固行依次为 PRESS/STUD/RIVET、型号、材料、安装面、孔壁、四个 0。焊接行依次为 WELD、方法、材料、边、CONT/STITCH、首端余量、末端余量、段长、节距，连续焊的最后两项用 0。使用实测孔和边复核，任一条不合格时整表不交付。
- 左右件（429）在显式指定的 X 或 Y 镜像基准下比较原生展开、板厚与孔槽。测试件在 X=40 mm 互为镜像，X=41 mm 被识别为错配。折后朝向与装配基准仍需另验。
- 护边（418）使用 `BWTL_SMT_CABLE_TRIM.tsv`。每行依次为型号、材料、开孔直径、承托外径、装后净径、最小板厚、最大板厚、版本。验证夹持区和通线间隙后才创建孔。
- 挡料和检具（425、467）覆盖指定自由直边的居中夹口，以及圆孔塞规的轴向插入。夹口或工具空间以指定区域的板厚、实体射线取样给出结论。
- 展开坐标（434–435）覆盖固定板及移动翻边的圆孔、单折弯及正反双折弯。通过 Creo 的折弯子面关系确认新旧编号对应，并核对折弯区长度及展开弧长。方向按展开读取侧处于弯内侧还是外侧分类，裁切文件与折弯标记文件共用坐标。
- 设备与模具库（445）使用 `BWTL_SMT_BEND_TOOLS.tsv`。每行依次为上模、下模、设备、V 口宽、上模尖 R、板厚下限、板厚上限、角度下限、角度上限、有效长度、版本。根据原生弯长、板厚、角度和内 R 初筛。

## 门板、安装接口与工艺检查

- 第 413–414 项要求两件使用方向及位置一致的安装坐标系。齐平以门板面减箱体面报告有符号高差。压缩率按自由高度与槽底至承压面的净距计算，核对矩形内九处实际修剪面。适用于成对平行板面。
- 第 416 项读取公司批准的 `BWTL_SMT_VENT_INTERFACES.tsv`。每行字段依次为类别、型号、开口宽或圆孔直径、开口高（FAN 填 0）、安装孔 X 中心距、安装孔 Y 中心距、安装孔径、承托宽、承托高、最小板厚、最大板厚、版本。FAN 生成圆形开口，FILTER、HOOD 生成矩形开口。定位坐标以板面坐标系为准，安装孔分布在四角。通过承托区、料桥、原生去料体积及穿透检查后保留新特征，默认未保存。
- 第 419 项读取公司批准的 `BWTL_SMT_MOUNT_CHECKS.tsv`。每行依次为类别、模板、孔中心 X、孔中心 Y、最小孔径、最大孔径、最大中心偏差、最小料桥、版本。类别为 WALL、HANG 或 SUPPORT。按表内顺序指定 2–12 个实际圆孔壁。安装坐标系原点须在安装面上，Z 轴沿外法向。逐孔报告实际坐标、孔径、最小料桥和超限项。结果用于安装几何核对，支承强度单独验算。
- 第 423 项计算当前实体的指定成形与折弯净距。Creo 精确测距不可用时以曲面网格估算距离范围，区间跨越限值时提示复核。
- 第 426 项对指定坐标系 Z 向直线退出作实体射线检查，分别汇报工位、退出终点和完整行程。结果覆盖取样区域。
- 第 427 项检查指定保护垫的净边和垫厚。矩形的净距下界基于外接圆，并考虑孔、外轮廓等面边界。第 428 项读取指定圆孔，按遮蔽塞直径过盈或挂钩直径余量检查，同时报告最小料桥。挂点承载由工艺人员另行核对。

`0.23.0-local.smy.3` 在独立 Creo 10 中通过 40 个检查。当前版用 `tests/native_workshop_continuation.c` 合并复测这些功能和第 356 项，覆盖安装孔顺序颠倒、重复参照、缺规格和实际孔位合格。回退到 `0.23.0-local.smy.4` 按本页「回退」操作。
