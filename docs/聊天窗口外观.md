# BWTL 聊天窗口 C 款

`0.23.0-local.chat.2` 采用深蓝标题与工具栏、暖白聊天区、角色色条和青绿色发送按钮。控件尺寸和间距按窗口创建时读取的 DPI 缩放，顶部五个按钮和底部操作沿用原有位置与含义。消息排版沿用原生 RichEdit。

保存 Creo 中的工作并正常重开，打开 BWTL 即可看到新版。可拖动窗口边缘检查消息宽度和按钮布局，发送前可检查输入、图片预览和历史滚动。

在独立 Creo 10.0 会话核对窗口外观、九个按钮及聊天文本。Windows 控件回归覆盖历史滚动、输入、发送和停止。需要回退时，使用对应会话的 BWTL 管理器回退到 `0.23.0-local.chat.1`，然后正常重开 Creo。
