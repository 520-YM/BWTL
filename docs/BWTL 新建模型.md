# BWTL 新建独立模型

「新建」「另建」明确指向独立的零件或顶层装配时，BWTL 开始新的任务。新模型生成后，后续建模绑定到新模型。明确要求在装配内创建子零件或子装配时，按指定父装配执行。

「创建一个钣金平面500*200*1mm」使用默认钣金模板，按长、宽、板厚创建矩形轮廓和平面首壁。完成后打开新的钣金零件，Creo 读回实际尺寸。「另外给我创建一个钣金件」直接打开独立空钣金模板。插件中的两种创建均由用户决定何时保存。

可在打开装配的独立 Creo 会话中分别输入这两句，检查新模型类型、平板尺寸及原装配版本。需要回退时在 BWTL 管理工具选择 0.23.0-local.menuorganized.1，保存手头工作后重开 Creo。
