# 第181–190项 散热、防水与走线

本机版本 **0.23.0-local.vent.1**。单独打开要操作的零件，在 **BWTL → 插件功能 → 散热、防水与走线** 选择功能模板。

| 编号 | 功能 | 参数与范围 |
| --- | --- | --- |
| 181 | 圆孔散热区 | 1–8 行、1–8 列，支持直排和交错。输入组中心、X/Y 孔距、孔径，回执列出总开孔面积与孔间留料下界。 |
| 182 | 长槽散热区 | 1–8 行、1–8 列圆端槽，槽长沿局部 X。输入组中心、槽总长、槽宽及 X/Y 槽距。 |
| 183 | 百叶通风口 | 普通单实体上开 1–4 道通风口，建立与零件连接的一体斜叶并保留通风缝。输入开口宽和长、片数、节距、斜叶角度、叶片垂直厚度和根部连接宽。当前几何采用实体切除和实体加料，钣金冲压成形及其展开属于不同工艺。 |
| 184 | 冲孔网格区 | 1–8 行、1–8 列矩形贯穿孔。输入组中心、矩形孔宽高及 X/Y 孔距。 |
| 185 | 面板底部排水孔 | 沿所选实际外直底边开圆端排水槽。底边平行局部 X，局部 +Y 朝板内。输入槽中心 X、孔至底边净距、槽总长和槽宽。 |
| 186 | 线缆防水接头孔 | 按配件规格加工圆孔或 D 形孔。D 形平边朝 +X，输入平边到孔心的距离。核对实际板厚与配件允许范围。 |
| 187 | 护线圈安装口 | 按配件规格加工圆孔或圆角矩形口，并核对实际板厚与配件允许范围。 |
| 188 | 挡水台阶 | 普通单实体上创建矩形一体凸台。输入中心、X 向宽度、Y 向长度和凸起高度。 |
| 189 | 矩形密封槽 | 普通单实体上加工闭合矩形盲槽。输入槽外框宽高、槽宽、槽深和最小底部留料。 |
| 190 | 线束转弯空间检查 | 只读检查当前单实体。输入 90° 圆弧中心 XYZ、线束中心线半径、线束外径和单侧净距。圆弧沿定位坐标系的局部 XY 由 +X 转向 +Y。 |

第 181、182、184–187 项可在普通单实体平板区或钣金平面区使用，钣金生成原生法向切口。加工坐标系的 XY 平面与加工面重合，+Z 朝外。尺寸单位为毫米，角度单位为度。操作默认留在当前会话，保存由用户决定。接头孔和密封槽的规格使用已确认的配件或密封件尺寸。

线束检查用保守包络与实体包围盒筛查。两者完全分离时报告计入所需余量的净距下界。发现实际中心线取样点进入实体时报告相交。其余重叠情况报告待复核。检查范围是当前零件与指定 90° 圆弧。[PTC 实体包围盒接口](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/api/dita/3930.html)

## 回退

保存工作并正常退出对应 Creo 会话后，在该 BWTL 安装根目录运行 `BWTL-Manage.exe -Rollback`。上一版为 `0.23.0-local.shop.1`，各会话的聊天和记忆保存在程序版本目录之外。
