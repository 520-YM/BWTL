# 霸威天龙 v20：完整安装包与数据迁移

版本：0.20.0-preview.1。

## 对应你的四项要求

| 要求 | 本版做法 |
|---|---|
| 便捷安装 | 单个 EXE，解出安装向导；自动寻找常见 Creo 配置，选定后点击安装。默认按用户安装，不写 Creo 主程序目录 |
| 同样界面和全部工具 | 使用同一份原生窗口源码、消息底色、中文输入、回车发送和全部现有 CAD 工具；标题增加 v20。包含完整 src/resources，而不是另一套功能简化版 |
| 定期更新和版本管理 | VERSION、CHANGELOG、SHA-256 清单；程序按版本并存，稳定入口切换；同版本不同内容拒绝覆盖；升级备份、回退和卸载入口 |
| 全部数据及聊天 | 完整历史、长期记忆、近期上下文、功能表、运行记录随包保存；额外保存原工程完整快照。首次自动导入，升级保留安装者后续聊天，并增量导入作者新增历史 |

程序包也包含聊天内容和偏好，转发这个完整安装包相当于向接收者提供这些内容。这是按所有者要求制作的完整数据版。

## 给别人安装

1. 发送 `BWTL-Setup-0.20.0-preview.1.exe`，对方双击。
2. 确认自动检测到的 `config.pro` 是 Creo 启动时实际读取的配置；不确定时选择启动目录使用的配置。多个配置不会假装能自动判断哪一个生效。
3. 安装目录默认 `%LOCALAPPDATA%\BWTL`，一般不用管理员权限；如果所选配置受保护，需要对该配置有写入权限。
4. Codex 路径可留空，程序按既有发现规则寻找本机引擎。对方需安装并登录自己的 Codex；安装包不复制所有者的登录凭据。
5. 保存工作后手动重启 Creo。依次按 `c`、`d`、`x` 打开原生助手，标题为“霸威天龙 v20”。

现有助手内部界面保留。工具命令随 DLL 注册；别人电脑没有原来手动定制的 Creo 功能区页时，`cdx` 仍是统一入口。完整历史布局文件已保存在工程快照，不自动覆盖对方整个 Creo 功能区或其他插件的布局；因此不承诺复制对方电脑未安装的外部工具栏。

本版仍面向 Windows x64、Creo Parametric 10.0.0.0。安装器依赖 Windows PowerShell 5.1 和 .NET Framework 4.5 以上。其他 Creo 版本尚未完成实机验收；Windows 或 Creo 首次信任提示由安装者处理。本安装程序未使用商业代码签名证书。

## 数据怎么“学习”

当前数据实际是 Markdown/TXT 文件，并没有另一个隐藏的数据库需要遗漏。

- `chat-history.md`：完整历史，首次按原文件复制。
- `memory.txt`：长期偏好，升级按完整行去重合并。
- `recent-context.txt`：首次导入，升级保留使用者已有近期上下文。
- `feature-guide.md`：安装器自动导入的完整功能索引，随版本更新。
- 其他说明和运行记录：保留在安装版本的 `seed` 与完整快照中；运行日志在新电脑独立生成。
- `pending-plan.txt`：原文件保存在包内，但不把另一台电脑的待执行 CAD 命令设为活动任务。

每次请求会读取功能索引，并从完整历史中按当前问题检索最多四段相关行。读取量有上限，不把全部历史塞进每次请求。旧 `CREO_OP` / `CREO_PLAN` 协议行不会进入历史摘录。历史只作为参考，不能覆盖当前工具协议、当前模型 API 快照或本次指令。

这是自动导入与本地检索，不是重新训练模型，也不会从文字聊天中自动编译出未开发的 CAD 功能。现有的所有 CAD 能力仍来自安装的同版原生程序。

## 新电脑如何适配

安装器按目标电脑生成 DLL 路径、资源路径及数据目录，不直接使用工程快照里的旧绝对路径。建模继续读取目标 Creo 当前配置的默认模板；不会把作者电脑的模板路径写进对方配置。其他插件配置和配置文件原有中文编码保留。

目录结构：

```text
BWTL/
  active.json                 当前版本及上一个版本
  protk.dat                   稳定的 Creo 注册入口
  versions/0.20.0-preview.1/   同版 DLL、源码、资源、历史快照和初始数据
  data/                       安装者后续聊天、记忆与索引
  backups/                    升级前配置和数据备份
```

## 更新、回退和卸载

- 新版提高 VERSION，更新 CHANGELOG 后重新构建安装包；对方运行新 EXE，选择原配置和原安装目录即可升级。
- 同版本重复安装用于修复，不重复导入相同历史；同版本不同文件会拒绝覆盖，避免版本号失真。
- 开始菜单“霸威天龙”提供安装管理、回退上一版本、卸载入口。也可运行安装目录里的 `Manage.cmd`。
- 回退切换旧版程序，保留聊天数据，不承诺旧版可以使用新版才新增的功能。
- 卸载只移除本安装器添加的启动注册，保留全部聊天、记忆和版本文件。对 Creo 的生效时机都是下一次手动重启。

## 验证范围

安装流程22项检查已在隔离目录以 Windows PowerShell 5.1 测试首次安装、中文路径、GBK 中文配置保留、其他插件保留、完整历史导入、偏好导入、重复安装、升级增量历史、回退、卸载与篡改拒绝。历史检索有单独的本地测试。

CAD 后端沿用 v19 已通过的 61 条原生用例，本版没有修改这些 CAD 算法。真实的新电脑与账号登录仍需要在目标环境验收；安装器测试不能冒充另一台电脑已经运行成功。

真实加载检查：独立隐藏Creo10会话成功从中文目录的8.3短路径加载最终DLL，四个原生命令注册返回0，数据存储初始化成功。中文/空格安装路径优先转为系统短路径；系统关闭短路径且目录无法兼容时，会提示选择纯英文无空格目录。

开发者重复构建：提高VERSION并更新CHANGELOG，执行 setup/Build-Setup.ps1，传入 -DataSource（完整当前数据）、-LegacyRoot（历史工程，可选）及位于源码目录外的 -WorkDirectory。旧版本安装包不覆盖。
