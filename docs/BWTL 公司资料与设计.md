# BWTL 公司资料与设计

在聊天中说「在公司标准库查 BSO-M2-6L，核对标准件尺寸和安装孔」，BWTL 会先找文件，再按实际路径调用 Creo 读取模型。也可以说「在目录『E:\项目资料\紧固件』里找 M3 螺母柱」，使用自己指定的现有目录。默认公司资料来源与本 BWTL 会话的「公司标准」菜单一致，包含公司标准、标准件和技术文件。查找按文件名、目录名或型号关键词进行。

- 资料正文支持 PDF、DOCX、XLSX 和 TXT、CSV 等文本。PDF 默认读前 4 页，可用「PDF 第 5–8 页」指定页段。Word 提供正文和表格文字，Excel 提供已保存的单元格值，范围见实际回执。旧版 DOC/XLS 可查找，阅读前请另存为支持的格式。
- Creo PRT、ASM 及版本文件可以读取保存后的外形、尺寸、特征顺序、坐标系、可验证的圆孔和候选安装面。ASM 还会读取组件树。能否解析所有组件取决于原装配引用是否齐全。原生孔位和面参照以回执为准。STEP 可在聊天中作为附件做几何分析。
- 在同一条装配指令中，先读取所选库件，再按原生 Creo 名称装入。BWTL 核对该路径和版本，若找到了同名不同来源、源文件已改变或 Creo 内存加载的是别的版本，会要求明确来源或清理冲突。默认定位、坐标系、平面和轴孔约束取决于用户要求及实际可用参照。
- 建模、再生检查、尺寸和干涉校核、原生保存、STEP 和适用钣金的 DXF 输出使用现有 Creo 功能。可以在指令开始时指定已存在的数据盘项目目录。明确要求导出当前工程图的 PDF 时，先在 Creo 激活原生 DRW，PDF 写入项目工作目录，若同名文件已存在则保留它。当前工程图 PDF 的输出名由字母、数字、下划线或连字符组成，例如 `M26A01_V00`。
- 文件内容与模型参数作为参考资料，BWTL 常驻聊天会接收本轮核对需要的数据。不会浏览未指定的目录或目录链接。用户选择的库模型原件保持原样，建模和导出按实际请求操作。

安装 `0.23.0-local.companydesign.1` 后正常重启 Creo。可用合成样件验证浏览目录、找件、模型读取、按路径装配、再生和导出。使用库件时可同时给出文件名和目标装配，定位时说明按默认方式还是用实际安装面、孔轴或坐标系。查看报告中实际读到的内容和产出路径。

需回退时通过 BWTL 管理功能恢复 `0.23.0-local.filechat.1`，再正常重启 Creo。聊天资料、配置备份和版本文件保存在数据盘。PDF 工程图导出由 [PTC 原生 PDF 接口](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r12/usascii/creo_toolkit/user_guide/Exporting_to_PDF_and_U3D.html) 完成，并在本机 Creo 10 验证。
