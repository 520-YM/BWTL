# v17 默认基本信息

“读取当前模型”按钮以及“读取模型”“读取基本信息”“读取尺寸”“读取质量”默认只显示名称、类型、毫米外形尺寸、材料和重量。装配同样默认使用简短摘要。

外形尺寸按当前模型几何包络换算毫米，不直接采用可能陈旧的 OUTLINE/规格等字符串参数。材料仅从几个指定材料参数读取；未读到有效名称显示“未指定”，ASSY 和系统材料占位文字不当作材料名称。重量采用 Creo 质量属性返回值及其质量单位，没有结果则显示“暂未获取”。

基本读取不再遍历特征、尺寸、全部参数及边面，也不显示工作目录、FID/TYPE/FLAGS、完整参数或几何列表。执行模型修改时的内部校验数据保留。

需要完整数据时输入“读取详细信息”；也可明确输入“读取详细尺寸”“读取特征”“读取参数”“读取几何”。AI 的 READ 回执默认也改成简短摘要。

v17 已编译链接通过；运行中的旧 DLL 需重启 Creo 后换为 v17，未自动关闭或操控 Creo。当前显示效果仍待实际加载验证。之前的聊天记录未删除。
