# BWTL 指令计时

发送文字或图片指令后，窗口标题区右侧实时显示“运行中”，每 0.1 秒刷新。结束后保留“用时”，下一条指令重新从零开始。完成、失败、停止都会结束本次计时；AI 等待、原生 Creo 操作以及同一指令中的自动续接和重试均计入总用时。

采用 Windows 单调时钟 GetTickCount64，计时状态只由 BWTL 窗口线程更新，独立 Creo 进程分别计时。更新由窗口消息定时器驱动，不改动建模权限、任务超时或失败次数限制。缩放窗口后状态仍固定在标题右侧，不占聊天内容和输入区。它显示本条指令的总耗时，不代表单独模型推理时间。

## 启用和验证

安装 0.23.0-local.requesttimer.1 后正常重启 Creo，在插件中发送指令。运行期间应持续变化，结束后冻结；下一条重新开始；点击停止也应冻结。持续自动执行多个步骤时不得逐步归零。空消息不会启动新的指令。当前指令的计时仅在标题状态中显示，聊天存档格式保持不变。

独立 Creo 验收记录位于 request-timer-native/workspace/request-timer-native.log，覆盖实时刷新、续接不重置、完成、失败、停止、下一条重置、本地同步指令、窄窗口和 DPI 布局。安装二进制另行做加载验收。

## 回退

通过 BWTL 管理脚本回到 0.23.0-local.processchats.1，再正常重启 Creo。更新前版本及配置备份保留在各安装目录的 versions 和 backups；聊天、学习记忆以及模型不受计时开关影响。所有开发、构建、测试与安装资料保存在 E 盘。
