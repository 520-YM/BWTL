# 公司标准接口

从「插件功能 → 公司标准接口」发起操作。标准库保存在相应 BWTL 实例的数据盘，目录为 `data\标准接口库`。

| 编号 | 用法 |
| --- | --- |
| 051 | `查找标准接口 孔距 方向 最大X 最大Y 最大Z 公差`。例如 `查找标准接口 70 +Z 160 120 11 0.05`。按已登记实际孔组、配合面朝向和坐标系中的包络筛选。 |
| 052 | 保存单实体 Creo 零件后，发送 `登记标准接口 标准编号 修订 SURFACE:安装面 CSYS:坐标系 SURFACE:孔1,SURFACE:孔2`。每个孔指定一个内圆柱面。插件读回配合面朝向、孔心和孔径，保留 Creo 模型版本和坐标系。用 `查找等同标准接口 编号 修订 公差` 匹配孔定位相同的其他记录。 |
| 053 | `登记标准件别名 编号 修订 供应商号`、`查询标准件别名 供应商号`。内部编号、历史名与供应商号用已有标准件条目关联。 |
| 054 | `标准件规格试改 编号 修订 "规格矩阵.tsv"`。每行两列为规格名和驱动尺寸组合，例如 `d1=8,d3=100`。在已登记且已保存的零件上运行，2–8 组规格分别在独立试算目录保存、重开、复测孔组，并试改一个驱动尺寸后恢复。结果保存在 `data\标准件规格试改`。 |
| 055 | `登记方法适用范围 登记名 装配 案例图号 "范围表.tsv"`。零件用 `零件 方法文件名.bwtlmethod.txt`。表格七列为样件名、尺寸指标、下限、上限、所需参照、已知失败条件、E 盘验收证据路径。用 `查询方法适用范围 登记名 指标 尺寸` 查询由用户登记的验收范围。 |
| 056 | `导入公司工艺规则 "工艺规则.tsv"`。全量表八列依次为机型、供应商、规则名、修订号、生效日、截止日、毫米值、依据。机型或供应商可用 `*` 表示通用，截止日用 `-` 表示无明确截止。用 `查询公司工艺规则 机型 供应商 规则 YYYY-MM-DD` 按日期匹配。同范围重叠的表格会被拒绝。 |
| 057 | `比较标准件接口 原编号 原修订 新编号 新修订 公差`。列材料、三个方向的外形差值、定位面夹角和最邻近孔的实测偏差。等同候选需在真实装配里核对空间。 |
| 058 | `追踪标准件引用 编号 修订 "订单总装清单.tsv"`。UTF-8 表每行三列为机型、订单号、Creo 总装的 E 盘完整版本文件路径，如 `E:\项目\主装配.asm.3`。报告列出准确的版本匹配及同名待核对项，并提供实例、父装配及迁移清单。使用完整表示。 |
| 059 | `登记公司标准件 编号 修订 范围名称 "054验收回执" "Creo工程图.drw.版本"`。先保存关联的原生零件和工程图，再登记接口版本。入库检查验证编号、参数范围、同版规格回执、实际关联的原生工程图和范围证据。通过后把该修订的记录写入标准接口库。 |
| 060 | `登记标准件来源 编号 修订 原生建模 "E盘路径" "说明"`、`查询标准件来源 编号 修订`。来源类型包括供应商图纸、原生建模、扫描、历史样件、公司图纸。源文件保留在原目录，记录保存地址、登记日期和说明。 |

验收用在独立 Creo 10 创建的三件四孔板，验证同规格、改孔距、反向、占用空间超限、料号冲突和素材来源。每项安装版本与证据见开发进度表。若需退回，使用相应 BWTL 实例的 BWTL-Manage.exe -Rollback。
