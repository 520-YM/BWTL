# 第191–200项 改尺寸与改规格

本机版本 **0.23.0-local.revision.1**。单独打开目标零件，在 **BWTL → 插件功能 → 改尺寸与改规格** 选择模板。长度使用毫米，角度使用度。操作留在当前会话，保存由用户决定。

| 编号 | 功能 | 当前支持范围 |
| --- | --- | --- |
| 191 | 按最终外形改长宽高 | 输入当前与目标的模型默认 X/Y/Z 外形尺寸，以及已核实的驱动尺寸符号、旧值、新值。以重生成后的实体包围盒验收。 |
| 192 | 孔组整体平移 | 选 1–8 个原生直孔。孔组共用入口面与两组正交定位参照，偏移量按原孔的第一、第二参照方向输入。 |
| 193 | 孔组换孔距 | 选四个呈矩形分布的原生直孔，输入两向新孔距，保持孔组中心。 |
| 194 | 开口换规格 | 修改关联单圆或轴向矩形草绘的盲拉伸切除。输入实际草绘和驱动符号，核对新轮廓尺寸与实际孔腔底面。 |
| 195 | 同规格孔批量改径 | 一次修改 1–8 个等径原生直孔，支持贯穿或平底盲孔，核对实际圆柱壁。 |
| 196 | 盲孔批量改深 | 一次修改 1–8 个同深的原生平底直盲孔，核对实际孔底位置。 |
| 197 | 沉孔批量换规格 | 一次修改 1–8 个同类原生沉孔。底孔为贯穿孔，保持原底孔直径。柱形沉孔改外径和深度，锥形沉孔改外径和角度。 |
| 198 | 圆角半径批量统一 | 一次修改 1–8 个原生单组等半径圆角，输入每个旧半径及统一新半径。当前验收使用实际圆柱过渡面。 |
| 199 | 钣金换板厚 | 输入旧板厚和目标板厚。支持带可核对平面板壁的独立单实体钣金零件，回读板厚定义并测量相对平面间距。 |
| 200 | 一键生成改型副本 | 按新名称创建会话内副本，可同时只在副本上按第191项改外形。保持当前原件，在 Creo 的「在会话中」可以打开副本。 |

第192、193项的两个定位尺寸需要是独立且为正值的驱动尺寸。位置、孔径、孔底和沉台均按当前原生特征验收。批量写入前先校验整组，提交后重生成并读回。失败后核对原尺寸、实体外形、体积和表面积；恢复状态无法确认时，本会话停止这类写入。钣金板厚根据模型中的板厚参数或驱动尺寸修改。[PTC 钣金板厚接口](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Geometry_Analysis.html)

例如可发送「把当前零件 H1 和 H2 两个原生直孔的直径从 6 改为 8 mm」。已有特征名称和旧值应以当前模型为准。

## 回退

保存工作并正常退出对应 Creo 会话后，在该 BWTL 安装根目录运行 `BWTL-Manage.exe -Rollback`。上一版为 `0.23.0-local.vent.1`。各会话的聊天和记忆存放在版本目录之外。
