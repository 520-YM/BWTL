# 第 31–40 项高级基准与参照

适用本机 BWTL 0.23.0-local.advdatum.1 和 Creo Parametric 10.0.0.0。在独立打开的普通实体零件中使用。菜单位于「插件功能 → 高级基准与参照」。选择一项并填完参数，或在智能协作中直接描述。先读取实际基准、曲线名称或几何编号。长度以毫米输入，角度以度输入，成功后由用户自行保存。

| 编号 | 功能 | 参照与参数 |
| --- | --- | --- |
| 31 | 角度基准面 | 已有平面、其中的基准轴或直边、有符号角度。角度绝对值至少 0.1 度且小于 180 度，方向遵循参照线原生方向的右手规则 |
| 32 | 三点基准面 | 三个不共线的已有基准点 |
| 33 | 两平面中分面 | 两个不重合的平行平面，两个参照均参与重生成 |
| 34 | 相切基准面 | 圆柱面或圆锥面，以及该实际面有效范围内的基准点 |
| 35 | 路径法向基准面 | 一条单段曲线和曲线上的基准点，平面法向取该处路径切线 |
| 36 | 两点基准轴 | 两个不同位置的已有基准点 |
| 37 | 曲线定位点 | 单段曲线的起点、终点、从起点累计的弧长或弧长百分比 |
| 38 | 曲面交线 | 两个实际相交的曲面或平面，Creo 保留两者的原生参照 |
| 39 | 三维样条曲线 | 相对指定坐标系的 3–8 组不同 XYZ 数值，按顺序插值生成开口样条 |
| 40 | 对称基准坐标系 | 三个两两垂直的平面。以三面交点为原点，以对称面和第二个平面的法向定义 X、Y，支持各自反向，Z 由右手系确定 |

例如发送「在路径 ARC_ROUTE 的弧长 40% 处创建定位点 ARC_POINT，再创建通过此点的路径法向基准面 ARC_NORMAL」。第 39 项通过原生 IBL 插值导入，使用坐标值作为输入。生成的 IBL 保存在该 Creo 会话独立配置的 `datum-inputs` 下。

每项原生建模分别维护在 `src/功能/advanced_datum`。`src/advanced_datum_plan.h` 负责参数检查，`src/advanced_datum_tools.h` 负责公用几何读取。中分面使用 PTC 文档规定的中分与平行约束组合。样条通过 Creo 支持的 IBL 导入创建。[PTC 中分面元素树](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Example_9_Midplane_to_a_Plane_and_Parallel_to_Another_Plane.html) · [PTC 基准曲线导入](https://support.ptc.com/help/creo/creo_pma/r13/usascii/part_modeling/part_modeling/About_Imported_Datum_Curves.html)

原生验收用独立 Creo 配置和临时零件运行 `tests/native_advanced_datum.c`，覆盖几何、重生成、实体体积、无效参照和错误回退。回退版本为 `0.23.0-local.refinement.1`。保存工作后正常退出对应的 Creo 会话，再通过 BWTL 安装管理切回上一版本。
