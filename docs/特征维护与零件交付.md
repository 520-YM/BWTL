# 第121–130项 特征维护与零件交付

本机版 **0.23.0-local.delivery.1**。入口为 **BWTL → 插件功能 → 特征维护与零件交付**。可选菜单模板并补齐参照、名称和文件名，也可直接在聊天中描述操作。结果来自 Creo 原生回执。

| 编号 | 功能 | 本版支持范围 |
|---|---|---|
| 121 | 修复断开的特征参照 | 单参照偏移基准面。替换失效的平面参照，核对重生成和实际面位置。替换仍有效的参照时核对旧面 ID。 |
| 122 | 特征顺序调整 | 将独立基准面、轴、点、坐标系或基准曲线移动到指定特征前后，按原生父子依赖预检和读回。 |
| 123 | 重定义已有特征 | 修改偏移基准面的偏移量或简单单侧盲拉伸的深度。写入前核对旧值，保留原特征 ID。 |
| 124 | 导入 STEP／IGES 为零件 | 使用当前工作目录中的中性文件，创建并打开独立零件。支持空白 Creo 会话。 |
| 125 | 修复导入几何 | 从明确指定的原 STEP／IGES 重新缝合并尝试实体化。在独立副本中得到有效单实体时交付。 |
| 126 | 识别导入件加工特征 | 从指定导入特征读取内凹圆柱面，合并共轴面片并报告直径、轴向跨度和孔候选。 |
| 127 | 批量填写零件属性 | 对当前件及明确指定的已加载零件批量填写缺失或空白的字符串参数。最多6件、6种属性，检查整批冲突并回滚部分失败的写入。 |
| 128 | 批量导出三维文件 | 当前件及明确指定的已加载零件，最多6件。支持 STEP、IGES 或两种格式，完整批次输出到新目录。 |
| 129 | 生成零件加工信息表 | UTF-8 CSV，含实体外形尺寸、体积、面积、可读料号和材料等属性、特征和孔候选。 |
| 130 | 打包零件交付文件 | 对单实体独立零件交付 Creo 原生副本、STEP、加工表和含 SHA-256 的清单。输出形式为一个新目录。 |

参照、顺序、重定义和属性修改留在当前 Creo 会话，保存时使用 Creo 的保存命令。重新定义失败时核对原特征参数和可用的原几何数据。若无法核实恢复，交付模块停止后续写入。顺序调整支持独立基准类特征。模型树中的组、阵列、嵌入特征以及存在不安全父子依赖的移动会被拒绝。

导入和修复的输入为当前工作目录中的文件名，含空格用双引号。修复用 Creo 的原生缝合和实体化能力。原始导入件保留在会话中。只有缝合结果通过健康状态、单实体和正体积检查才报告修复成功。缺失曲面或其他无法闭合的几何可能仍需要 Import DataDoctor。原生转换器可生成导入诊断日志。[PTC 导入说明](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Importing_3D_Models.html)

孔候选来自几何分析。周向检查使用24个角度样本，贯通或平底的候选判断还依据孔轴射线。无足够几何证据时，会报告为圆柱孔候选或局部圆柱内凹面。该结果用于核对几何，刀具、工艺顺序及螺纹仍由实际工艺要求确定。

导出、加工表和交付包先写入新建暂存目录。成功核对文件后再发布到指定的新目录，重名时拒绝。交付包的原生副本采用 `_DELIVERY` 后缀。检测到外部父参照或非空族表时拒绝打包。清单逐项列出源模型名、文件名、字节数与 SHA-256。[PTC 导出说明](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r11.0/german/creo_toolkit/api/dita/1712.html)

## 指令示例

模型名、特征名和参照 ID 均为示例，使用前从当前模型核对。

```text
CREO_OP DV_REF PART_A OFFSET_A MISSING PLANE:RIGHT
CREO_OP DV_REORDER PART_A DATUM_A BEFORE DATUM_B
CREO_OP DV_REDEFINE PART_A BOSS DEPTH 8 12
CREO_OP DV_IMPORT NEW_PART "bracket body.step"
CREO_OP DV_HEAL IMPORTED_QUILT REPAIRED_PART source.igs
CREO_OP DV_RECOGNIZE IMPORTED_PART ID:90
CREO_OP DV_ATTR PART_A 1 PART_B PART_CODE A-100 REVISION B
CREO_OP DV_EXPORT PART_A EXPORT_OUT BOTH PART_B
CREO_OP DV_REPORT PART_A MACHINING_OUT
CREO_OP DV_PACKAGE PART_A DELIVERY_OUT
```

## 验证与回退

原生实现保存在 `src/功能/delivery`，各功能通过原有 BWTL 对话、绑定与菜单入口调用。Creo 10 独立测试覆盖真实断开参照的恢复、依赖顺序拒绝、重定义读回、STEP 和 IGES 导入、空白会话导入、曲面修复、孔径和轴向跨度、批量属性回滚、文件碰撞拒绝、原生副本重开及清单核验。验收记录见本机的 delivery-update-status.json。

保存现有工作并正常重开 Creo 后加载新版本。回退时正常退出对应 Creo 会话，在该会话安装根目录运行 `BWTL-Manage.exe -Rollback`。本次保留 `0.23.0-local.quality.1`。聊天、记忆和项目输出分别存放在程序版本目录之外。
