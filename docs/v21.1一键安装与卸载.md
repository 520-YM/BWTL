# 霸威天龙 v21.1 一键安装与卸载

版本：0.21.1-preview.1；2026-11-04。包含11—15工具、紧凑消息卡片、灰色背景、响应优化和UTF8请求修复。

## 安装或升级

1. 双击 BWTL-Setup-0.21.1-preview.1.exe。
2. 首次检查自动检测的config.pro是否为Creo实际启动配置。默认安装在当前用户LocalAppData下的BWTL；Codex路径可留空自动检测。
3. 点击“一键安装 / 升级”，自动校验、注册和导入完整作者历史/记忆/功能索引。升级保留安装者后续聊天并记录备份和上一版本。
4. 保存工作后重启Creo，打开霸威天龙v21.1；或在图形区依次按c、d、x。

目标环境Creo Parametric 10.0.0.0。AI需使用者本机有可用Codex登录；包内不包含Creo、公司模板、PTC SDK或登录凭据。其他电脑仍需实际验证。

## 卸载

开始菜单选择“霸威天龙 → 卸载霸威天龙”，或双击安装目录 BWTL-Uninstall.exe。

| 独立选项 | 默认 | 范围 |
|---|---|---|
| 删除插件程序文件和历史版本 | 勾选 | 安装目录的版本程序、资源、源码及快捷方式 |
| 删除聊天记录、记忆、数据备份和内置历史副本 | 不勾选 | data、备份中的data、保留版本内的seed/archive副本 |

点击“执行卸载”按选择处理，取消不修改。四种组合都会移除插件的Creo启动注册。

- 仅删除程序：保留聊天/记忆/备份，以及一个小型清理入口和卸载记录，便于日后清理数据。
- 两项都勾选：删除插件管理的安装文件和数据；无关文件保留，目录为空时才移除目录。
- 仅删除数据：保留程序，清除数据及内置副本；重新安装完整包会再次导入包内作者数据。
- 两项都不勾：只取消启动注册，保留文件。

文件占用时请先保存并退出使用该插件的Creo后重试，卸载器不会强行结束Creo。其他清理错误会报告未完成，可通过保留的入口重试。

清理限此安装目录；下载的EXE/ZIP、源码工作目录、其他软件、Creo和用户模型不自动删除。异常状态路径或链接/联接点会拒绝清理。勾选删除数据后无法通过插件恢复。

## 版本与验证

旧发行文件保持不变。建模代码保留v21原生回归证据，本轮验证安装/升级/卸载，未重新宣称任意模型和跨机器均通过。AI耗时以实际分段日志为准。

静默卸载默认保留文件；部署人员需显式传入 -Uninstall -DeleteProgramFiles 和/或 -DeleteData 才执行对应清理。普通用户使用图形入口。
