# 对话理解与原生上下文

BWTL 聊天先理解最新一句要实现的目标，再接上此前确认的尺寸、模型或装配。原生任务会提供当前 Creo 模型和工作目录，诊断上一步时提供最近的原生回执。上次日志和历史对话可作为参考。单独的建模新任务以最新要求为准。

## 常见用法

- 讨论设计时，可接着上一条方案追问尺寸和用途。用户要求执行且有足够依据时，插件提交原生操作。
- 在同一个 Creo 进程里，普通对话和附件分析都会带上最近对话。说「按刚才的方法看这份 PDF」时，可以沿用之前确定的分析口径。
- 新建后通过 Creo 活动窗口和工作目录核对的模型会留下原生回执。后续追问会根据当前模型和工作目录匹配该回执，沿用已确定的尺寸和步骤。当前消息决定本轮操作范围。
- 每个新开的 Creo 进程仍从空白聊天开始，旧聊天继续分别归档，长期建模规则仍可读取。
- 引用上次出现的“只分析”或“不要执行”提示后，可直接说明这次要做的操作。本次仍明确要求只看方案时，保持模型。
- 任务暂停后，在活动模型、版本和工作目录仍对应同一任务时，发送「接着上一步做」可续做。问失败原因时，可引用本次会话的最近原生回执。
- 询问当前版本、功能总数或完整清单，可直接得到插件回读。清单统计当前可选菜单操作，同一编号下的不同操作各计 1 项。「插件功能 → 功能列表」在记事本显示同源清单和命令用法。清单保存在当前 BWTL 配置的数据目录，标记项附 Creo 回溯风险说明。

## 验收与回退

通过独立 Creo 与回归测试核对普通对话、模型上下文追问、写入意图、只分析、已有回执以及功能清单。运行中的 Creo 重新打开后加载新 DLL。需要回退时，使用当前实例的 `BWTL-Manage.exe -Rollback`，再重新打开 Creo。
