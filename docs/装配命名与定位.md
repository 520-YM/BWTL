# 装配命名与定位

## 新建、改名和建件

- 发送「创建总装，图号 01」，按当前年份、公司识别码 A、两位年度流水、总装号 00000 和初版 V00 创建空装配。也可输入完整图号，例如「创建 M26A0100000V00 总装」。正式出图采用工程已分配流水。
- 发送「把当前装配改成 M26A0100000V01」，BWTL 先检查新名与现有 ASM 是否冲突，再执行 Creo 原生改名并读回。已保存装配会备份旧修订后写出新名，保留旧名供未打开的引用继续读取。有已加载的上级装配或工程图引用时，回执会指出引用者，待引用关系明确后再改名。
- 发送「在里面建同号钣金件」，用当前装配的实际名称创建同名 PRT。通过文件类型区分 ASM 和 PRT，各自检查重名。
- 建子装配或子零件前可用「读取当前装配的组件树」选择父装配。在 Creo 模型树选中唯一父子装配后，可说「在选中的子装配里建同号钣金件」；也可按实测 ID:父实例/下一层实例 指定建件位置。空子零件有实体和钣金两个类型。

## 装入、定位与核对

- 装入已有零件或子装配时，可使用会话模型、当前工作目录的模型，或公司标准件库中的 Creo 模型。按实际图号和类型解析。
- 可默认定位、按 XYZ 和转角摆放、固定已放置组件，或按两侧实际坐标系、平面、孔和轴添加原生约束。平面角度可由同轴的基准轴和两侧通过该轴的基准面指定。
- 约束写入前读取当前实例和实际参照。完成后读取所在层级、约束、位置和欠约束状态。

## 环境摄像头

在本机安装目录的「公司资料/公司标准/公司标准件/环境摄像头」放置已验收的原始参考样件及电子件、螺母柱和压铆螺母模型。选择 E 盘工作目录，发送「画一个我们公司标准的环境摄像头，图号 M26A0100000V00」。

依次创建空装配、同号原生空钣金件，预定位实际标准电子件，按原件特征树重新建立板壁、折边和切口，然后按实际孔和贴合面写入定位约束。参考样件用于读尺寸、特征与参照。边法兰附加壁未完整生成或失败回滚时曾触发 Creo 回溯，详见《Creo回溯风险重点提醒》。

## 回退

在 BWTL 管理工具中选择上一个已安装版本 0.23.0-local.projectcreate.2，正常保存 Creo 工作并重开。项目文件保存在独立的 E 盘工作目录。
### 参考模型配置

在「公司标准件/环境摄像头」目录放置 `camera-models.ini`，并把所有参考模型及其依赖放在这个目录里。以下是示例文件名，实际值应与 Creo 装配引用及对应修订一致。

```ini
[Models]
Bracket=CAMERA_BRACKET.prt.1
Electronics=CAMERA_BOARD.prt.1
Standoff=BSO-M2-6L.prt.1
Nut=S-M3-1ZI.prt.1
Assembly=CAMERA_BRACKET.asm.1

[Instances]
Electronics=54
Standoff1=40
Standoff2=41
Nut1=43
Nut2=46
```
