# BWTL 创建零件（同号装配与钣金件）

在 BWTL 发送「创建一个零件」，或在「插件功能 → 零件建模 → 新建零件」选「创建零件（同号装配与钣金件）」后发送。也可以用「新建零件」等直接命令。

1. 从 Creo 默认装配模板创建空装配。
2. 在新装配内创建图号相同的空钣金子件，采用 Creo 默认定位。
3. 打开并激活子件的独立窗口，读回活动窗口和模型身份。

有图号时可发送「创建一个零件，图号 M26A0181001V03」或「创建一个零件，图号 M26A0181001，版本号 V03」。两种都创建同号的装配和空钣金子件，再打开子件。只给基础图号时使用初版 V00。图号已带版本并另给不同版本时，请先核对版本。若当前会话或工作目录已有同号的装配或零件，会先提示冲突。

省略图号时，BWTL 自动分配同一个基本名称，分别用于 `.ASM` 和 `.PRT`。三个步骤均核实后，聊天才会给出一条完成回执。失败时会指出卡住的步骤，保留在会话中已完成的模型。Creo 从模板创建模型时会在工作目录生成初始版本文件。需要写入完整装配关系时，在 Creo 中保存装配。显式命令「创建实体空零件」「新建钣金空零件」仍可单独创建对应模板的零件。

验收使用隔离的 Creo 10.0 会话和空白聊天，发送含图号和版本号的命令，核实名称、默认定位、同号钣金子件、活动窗口和最终回执。升级到 `0.23.0-local.defaultpart.2` 后重启 Creo。如果需要回退，切换回 `0.23.0-local.defaultpart.1` 后正常重启。
