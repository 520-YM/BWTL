# 功能拆分与旧版保护

生效日期：2026-11-04。对应已发布运行版：0.21.1-preview.1。
本次是源码组织修订，不覆盖已发布安装包、不修改当前Creo注册、不替换运行中的DLL。

## 文件规则

所有原生功能实现放在 `src/功能/`，按原模块分类，每个C函数一个独立 `.inc` 文件；原头文件只保留类型、状态、宏和按顺序包含功能文件的目录。
大型事务内的独立操作另拆文件，例如基准面、轴、点、坐标系、曲线、草绘尺寸/约束/平移/投影/删除、拉伸、旋转、保存、复制、改名和导出。
`.inc` 是真正参与编译的C源码片段，不是说明书或空壳；保留共享事务作用域中的错误返回和清理路径。不要单独编译它，统一通过 `build.cmd` 构建。

## 旧功能保护

1. `compatibility/legacy-v21.1.json` 固定227个源码、协议、测试及构建检查文件的SHA256。旧命令格式、模型绑定检查、参数校验和回滚路径均在保护范围内。
2. `build.cmd` 编译前执行 `tests/Test-LegacyCompatibility.ps1`。缺文件或任一受保护文件变化，立即拒绝构建。
3. `setup/Build-Setup.ps1` 打包前执行 `tests/Run-Regression.ps1`，检查旧基线并运行7组指令、编码、聊天持久化与历史测试；失败不生成新安装包。
4. 基线禁止构建时自动重建。确需修旧功能时，先明确变更、保留上一版、完成针对性回归，再人工审查更新基线。不能为了让检查变绿而直接批量刷新哈希。
5. 新增功能采用新文件、新命令标识；接入旧调度入口属于受保护修改，必须经过上一步审查。共享事务、结构布局和线程模型不随意更改。
6. 改动真实建模行为，除协议测试外还必须在隔离Creo 10会话验证创建、修改、失败回滚、旧功能组合；通过后才替换默认生产DLL、官方解锁和发布。
7. 已发布安装包和DLL保留，新增发行使用新版本号。安装器继续保留前一版本及数据备份，可回退。

## 本次兼容证据与边界

本次拆分只搬动代码。展开新增 `.inc` 后，全部19个原始源码文件的C词法内容（包括字符串、语句顺序和操作符）与拆分前一致；未改建模算法或命令语义。候选DLL编译通过，7组非交互回归通过。

这是源码级拆分，不是进程隔离，也不是每项功能一个DLL。单DLL内仍共享Creo SDK和状态，不能从“分文件”推导绝对不会报错或闪退。此次未重新执行真实Creo建模；运行中的已验证版本保持原样。后续行为改动必须补做真实建模回归。
