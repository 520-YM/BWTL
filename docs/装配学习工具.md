
# 装配学习工具

在 Creo 打开样件总装，选择「BWTL → 仿照模型 → 装配学习」。BWTL 保留以往可阅读的装配记录，同时在该会话的数据盘写入按来源图号命名的 `.bwtlrules.txt`。其中每张规则卡对应一个实例路径，保存父装配、约束类型与顺序、参照属主、实测姿态及阵列状态。实例路径用来指定来源案例。打开新总装后，执行端会重新读取目标参照。

## 从样件学习与执行

- `查看装配规则 样件总装名 ID:路径` 显示该件安装方向和支撑。先核对样件路径和目标父装配。装配树反映 Creo 的参考依赖，实际车间顺序还可通过示范记录。
- `按装配规则安装 样件总装名 ID:路径 新组件名` 向当前目标装配建立新的 Creo 原生配合。按需可以在组件名后写目标支撑实例路径，例如 `ID:45`。若多条约束涉及不同支撑，则在目标中先装齐对应的支撑。默认留待保存。末尾加 `保存` 会写当前数据盘工作目录。
- 组件名可填 `自动` 或 `自动换件`。插件筛查当前会话中可以对应全部接口的候选，后者排除学习案例的同型号。目标接口按名称、几何类型、法向或孔轴、圆柱半径和轴向范围复核。任意命名缺失时，多个同等但位置不同的候选需要给出明确支撑或组件。
- 规则复用原来的配合方式、必要偏距和局部方向，在目标模型实测参照。对原阵列中继承种子定位的普通平面阵列成员，按实际站位建立各自的配合偏距并避免重复安装。目标已有对应安装面时可以用显式目标支撑路径确定该站位。旧项目的方向、间距或编号与新项目不同，需要按新项目已有设计参照复核。
- `批量按装配规则安装 样件总装名 "E:\路径\批量表.tsv"` 读取三列 UTF-8 文件，使用 Tab 隔开「来源编号或实例路径」「新组件名或自动」「目标支撑实例路径或 -」。支撑缺失时先装本轮可完成项，再复查依赖。未通过的新实例会撤回，其他已完成项保留。批量默认留待保存。

## 示范、PDF 对照和验收

- 在要记录的当前总装发送 `记录装配示范`，进行操作，再发送 `结束装配示范`。记录该父装配成功的组件创建和重定义事件，以及 Creo 回调可读取的约束、参照侧和偏距。结束时另外保存最终可复用规则。可以发送 `取消装配示范`。
- `导入装配图纸对照 样件总装名 "PDF 路径" "对照表.tsv"` 读取本机 PDF 的 SHA-256，用已有规则交叉核对 UTF-8 表中的四列「图纸编号」「用途」「Creo 零件号」「源实例路径」。待核对项可以填 `-`。表从 PDF 的明细或版面读得，不带表的 PDF 尚需人或 Codex 标出对应表项。用 `对照装配图纸 样件总装名` 查看结果。以图纸编号、唯一用途或源实例路径调用规则。重复编号应细分为上、下等站位。
- 插入后立即回读原生约束和放置状态，检查重复位姿。`检查装配学习结果` 检查当前总装的定位状态和重复位姿。加两个零件的路径和净空毫米，可测该对零件的当前间隙。
- `检查装配学习轨迹 移动件ID 障碍件ID AXIS:名称 ROTATE 起点 终点 样本数 净空毫米` 按所给转轴验证开门轨迹。把 `ROTATE` 改为 `SLIDE`，输入拆装行程，可测检修抽拉空间。运动检查在临时装配中采样，报告针对所给零件、边界和采样点。
- 单件重用传入 `保存` 后，关闭并在另一 Creo 会话打开目标，再发送 `验收装配规则 样件总装名 来源编号或路径`。插件检查模型版本、目标组件、原生约束数及实际位姿，写下 `REOPENED` 证据。需要使用不同零件号来验证换件。

本版适用于可读取的平面贴合、对齐、偏距、同轴、平行及命名坐标系约束。复杂机构连接、多义参照、只有固定位置或抑制的实例可显示现有学习记录。活动装配和其组件模型使用一致长度单位。回退时运行所用实例的 `BWTL-Manage.exe -Rollback`。现有装配学习文件、规则和对照表保存在实例自己的装配方法库中。
