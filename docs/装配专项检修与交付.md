# 装配专项功能第三次本机更新

版本 0.23.0-local.assemblyworkbench.57。Creo 的「BWTL → 插件功能」按定位配置、紧固工艺、机柜检修、线束端口、机架现场和检查交付分类放置专项功能。功能列表保留用户清单原序号。

- 17、20、24、30。核对指定订单装配中的共享零件、给定导轨范围里的占用与空段、紧固件的实际杆向与承压面，以及带 FASTENER、SPEC、BWTL_LENGTH 标记的相邻混长螺钉。
- 27、39、42、44、45、50、55、73、84。在独立临时装配中，按给定的包络、各阶段轴线、范围与障碍采样。对工具、闭门、接线、插拔、抽换、装入及焊接工具分别使用明确的阶段。装入步骤可续接上一阶段的姿态。实际碰撞和最小间隙按 Creo 回执报告。
- 38、41、64、65、69、70。计算铰链站位垫片及矩形电气排布建议。依据真实端点、轴和线中心线，量测门线理论长度、直板边磨线以及指定强弱电直段的夹角、重叠和间距。端口连接核对读取真实坐标系和 BWTL_WIRE_FROM、BWTL_WIRE_TO。
- 71、83、89、94、97。根据直接 Creo 依赖及明确工艺排序。焊缝检查使用实建几何包络。搬运检查覆盖直线和矩形原地转向区。按报告实例及可选面号高亮。返工表按同源实例路径比较两版的拆、装、换和位姿，可导出 CSV。
- 100。记录实际成功的装配坐标系及第一次尝试的 Creo 状态。案例留在本实例的 E 盘数据目录。下次可按类别读取，确认当前真实参照和预估移动范围后再使用。适用于已验收的主备坐标系定位流程。

采样的检查覆盖给定的路径、零件和姿态。公司工艺、外部现场测量和制造商规格通过明确输入或模型属性提供。默认保留 Creo 当前模型的保存状态，装配写入由用户保存。

可用同实例 BWTL 管理器回退到 0.23.0-local.assemblyworkbench.56。先保存手头工作，回退后重开 Creo。
