# 第141–150项 面板开孔

本机版 **0.23.0-local.panel.1**。在 Creo 中单独打开要加工的零件，从 **BWTL → 插件功能 → 面板开孔** 选择对应功能。可填写模板，也可直接描述要求。

| 编号 | 功能 | 输入与结果 |
| --- | --- | --- |
| 141 | 按钮开孔 | 圆孔直径。可带单侧防转缺口，指定缺口宽度及超出圆孔最外点的深度。 |
| 142 | 急停按钮开孔 | 圆形主孔、定位缺口宽和深。 |
| 143 | 电源插座开孔 | 矩形开口宽高、两固定孔孔距与孔径。两孔沿定位坐标系 X 排列。 |
| 144 | USB／网口开孔 | 指定含安装间隙的最终开口宽高。四角可设相同半径，零值保留直角。 |
| 145 | 风扇安装孔组 | 中央圆形通风口、固定孔的 X/Y 孔距和孔径。 |
| 146 | 显示屏窗口 | 按窗口宽高开孔。给出同心外框宽高和最小单侧遮边，核对板面与遮边。 |
| 147 | 透明面板沉位 | 普通实体板件的内窗宽高、外沉位宽高和定深。回执列出台阶剩余厚度。 |
| 148 | 把手安装孔组 | 按中心和 X 孔距布两孔。提供 Y 孔距时布四孔。 |
| 149 | 锁具安装孔 | 圆孔带单个防转平边，填写平边到圆心的距离，可加两固定孔。 |
| 150 | 走线梳齿口 | 沿真实直板边开 2–12 个等距矩形槽，输入槽宽、槽距及切入深度。 |

## 定位与验证

用实际实体平面定位。定位坐标系的 XY 面与所选面重合，+Z 朝板外。另指定一个与加工面不平行的方向基准面。输入的尺寸单位为毫米。缺口和平边位于局部 +X 侧。梳齿的 X 填板边位置，Y 填槽组中心，板料在 +X 一侧。

例如发送「在当前零件的 SURFACE:96 上做风扇安装孔组，定位坐标系 PANEL、方向基准面 RIGHT，中心 X40 Y30，板厚 2，通风口直径 20，X/Y 孔距各 26，固定孔直径 4」。孔位、孔距和板厚按配件或实际模型填写。

支持单实体等厚平面加工区。贯穿功能可用于普通实体板件和满足同样条件的钣金平面区。钣金使用原生法向切口。附近有夹层或空腔、选面或板厚不符、固定孔相互重叠等情况会拒绝。常规开口需要留在面内，梳齿按板边开口。操作核对切除体积和代表位置的贯穿结果，沉位同时核对台阶。原生特征默认留在当前会话，由用户保存。[PTC 草绘图元接口](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r12/chinese_cn/creo_toolkit/user_guide/Adding_Section_Entities.html)

## 回退

正常退出对应 Creo 会话后，在该会话安装根目录运行 `BWTL-Manage.exe -Rollback`，上一版为 `0.23.0-local.assembly.1`。聊天、记忆与项目文件保留在程序版本目录之外。
