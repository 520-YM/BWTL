# 第 271–280 项 机箱与设备安装

打开顶层装配的主表示，退出动态定位。通过「BWTL → 插件功能 → 机箱与设备安装」填入参数，或直接在聊天中说明。先读取组件树和几何参照，按实际实例路径选择零件。零件模型应已打开或位于当前工作目录。尺寸用毫米，方向以命令指定的坐标系为准。

| 编号 | 功能 | 范围 |
| --- | --- | --- |
| 271 | 屏幕与窗口定位 | 四侧实际直壁确定矩形窗口，按显示面居中并核对最小边缘余量。 |
| 272 | 玻璃与面框定位 | 按开口正侧和指定胶层厚度放置玻璃，核对左右及上下压边。 |
| 273 | 电源与安装板定位 | 按两孔和承接面定位，核对接线端朝总装 +X/-X/+Y/-Y/+Z/-Z。 |
| 274 | PCB 与支撑柱定位 | 匹配两支撑柱和板孔，核对 PCB 最低实体与指定底面的距离。 |
| 275 | 风扇与风口定位 | 核对两安装孔、实际风道中心和直径、所选出风面方向。 |
| 276 | 滤网与风扇护罩安装 | 一次定位一个矩形滤网或护罩；相对框坐标系检查抽出包络及指定障碍。 |
| 277 | 导轨与电气模块安装 | 对齐安装坐标系，沿导轨 +X 放置，核对模块投影宽度与轨道可用长度。 |
| 278 | 门锁与锁扣配对定位 | 在已关闭的装配姿态中用矩形直槽核对锁舌插入及侧隙；入口原点 Z=0，+Z 向槽内。 |
| 279 | 铰链与门板安装 | 按柜体上的 1–3 个站位布置，核对所有铰链轴共线和闭门两侧安装面。 |
| 280 | 密封条与压合检查 | 只读。每段直边取三点核对投影、闭门间隙及设计压缩率。 |

矩形开口使用朝内的左、右、下、上四个侧壁，且其跨度能够组成同一个直壁开口。设备显示面、玻璃、滤网或舌端必须提供实际矩形平面。需要读取实体包络的工序使用单实体零件。玻璃胶厚从矩形开口正侧量起。滤网检修采用包络与一个指定障碍件比较，覆盖设计阶段的净空筛查。风扇的空气方向以提供的实际出风面为准。

安装使用固定定位，并检查指定接合件的实体干涉。写入目标是新放入的组件，保留原组件；安装结果不自动保存。铰链检查使用闭门姿态，密封条使用直边采样和设计压缩率，适用平行的压合面。动态启闭、曲线密封条和整机全路径干涉需要另行验收。

本机用 Creo 10 验收定位、尺寸读回、净空和冲突保护。回退时保存需要保留的工作，退出对应会话，在其安装根目录运行 `BWTL-Manage.exe -Rollback`，上一版为 `0.23.0-local.hardware.1`。
