# 第131–140项 装配定位与检查

本机版 **0.23.0-local.assembly.1**。在 Creo 中打开顶层装配，然后选择 **BWTL → 插件功能 → 装配定位与检查**。可填菜单模板，也可直接描述要求。

| 编号 | 功能 | 支持范围 |
| --- | --- | --- |
| 131 | 读取组件树 | 读取各层组件实例路径、状态与顶层坐标原点。 |
| 132 | 放入已有零件 | 使用已载入模型，或从工作目录读取同名最新原生零件文件。与顶层装配采用相同长度单位，在给定 XYZ 建立未约束实例。 |
| 133 | 坐标系重合约束 | 给尚无约束的普通直接零件新增一个重合约束，核对两个原点与三轴。 |
| 134 | 平移组件 | 核对旧 XYZ 后平移普通、未约束的直接零件，保持原旋转。 |
| 135 | 抑制与恢复组件 | 处理没有下游特征依赖的普通直接零件。 |
| 136 | 最小间隙 | 测量指定两个活动实体零件实例的距离及顶层坐标中的最近点，可判断是否满足给定间隙。 |
| 137 | 实体干涉检查 | 检查指定两个实例，或检查活动零件实例数为 2–16 的整个装配。返回正体积干涉。 |
| 138 | 装配质量属性 | 读取组件实体体积合计。Creo 能计算材料质量时同时返回质量、重心和主惯量。重叠的零件体积仍按各组件分别计入。 |
| 139 | 装配 BOM | 递归汇总活动零件的数量、料号、图号和材料，写入新目录中的 `bom.csv`。 |
| 140 | 装配 STEP | 按当前 Creo 导出配置生成单个装配 STEP，用于几何交换。目标为工作目录中的新目录。 |

在组件树中查实际实例路径。同一零件放入多次会显示不同路径，例如 `ID:42` 和 `ID:43`，子装配内部可显示 `ID:44/42`。间隙和干涉支持读取嵌套实例。第132–140项使用活动顶层装配的主表示，动态定位需关闭。位置和间隙单位为毫米，放入、约束、平移和抑制操作默认留在当前会话，由用户保存。

例如发送「检查当前装配中 ID:42 和 ID:44/42 的最小间隙，要求至少 2 mm」，或「导出当前装配 BOM 到新目录 BOM_OUT」。BOM 与 STEP 均在新建暂存目录内生成并核对文件，重名时拒绝写入。BOM 的料号读取 `PART_CODE` 或 `零件号`，图号读取 `DRAWING_NO` 或 `图号`，材料读取模型材料参数。缺少属性时留空。

## 本机验证与回退

原生验收使用独立 Creo 10 会话，包含重复实例、嵌套组件、已知间隙和重叠体积、BOM 数量及空会话 STEP 重开。保存现有工作并正常重开 Creo，即可加载当前版。回退时正常退出对应会话，在其安装根目录运行 `BWTL-Manage.exe -Rollback`，上一版为 `0.23.0-local.delivery.1`。聊天、记忆与项目输出位于程序版本目录之外。
