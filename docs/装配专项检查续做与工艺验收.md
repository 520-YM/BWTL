# 装配专项功能第二次本机更新

版本 0.23.0-local.assemblyworkbench.56。在当前装配选择「插件功能 → 装配专项检查」，也可以说明要检查或调整的实例。原有功能和本版新增功能均走 BWTL 的独立 Creo 入口。

- 清单 6–8、10。为未定位的直接零件提供两组可互换的坐标系、允许位移和旋转。第一组失败时核对装配树、原有位姿及恢复状态，再试第二组。支持多站位及重发续做，实际已约束且姿态匹配的站位会跳过。装配快照可比较新增、移除和变位。聊天以单条回复交代实际结果，原生步骤写入执行明细。装配写入默认未保存。
- 15、16、29、43。读取同父装配的站位标签、明确给出的必配规则、紧固件工艺属性、端子附件类别及需求数量。BWTL 源模型或实例可使用 BWTL_SLOT、BWTL_KIND、BWTL_TORQUE、BWTL_LOCKING 和 BWTL_TORQUE_MARK。样件只用虚拟数据，生产工艺取公司给定值。
- 25。选定压入侧的孔口和直线外轮廓，核对板厚、孔径、孔外边距及给定的背面净空。
- 31、47、51、54、58、59。按矩形窗口估算直视或斜视遮挡。高低压间距由 Creo 实测，指定隔板可检查几何分区。风道按指定深度扣除经体积核对的实心方盒障碍，滤网矩形边可查旁路间隙。核对矩形水平挡雨罩的四向外伸。直线密封环按顺序检查每个接头，再读闭门压缩率。
- 62、63、67。按实际中心线路径核对线束下料长度和连续性。半径量测覆盖独立直线和圆弧，其他曲线和段间转角需要进一步核对。矩形槽依据内壁、盖板占高和已知线外径核算有效截面与面积利用率。
- 81、82、86、87。使用指定角点坐标系、工位坐标系、脚底面和孔中心点，对照公差核对方正度、错位、调平量、旋入长度和现场地脚孔残差。现场坐标或螺纹要求由项目输入。
- 91、96、98。按同一料号核对实际设计用量和生产清单。用 BWTL_BUILD_STATUS 和 BWTL_BUILD_NOTE 报告代用、临时或待采购零件。按 BWTL_STATION 汇总物料，明确要求时从 Creo 当前工作目录导出 CSV。

在独立 Creo 10.0 验证真实几何、站位参照、失败后撤回和续做，并从聊天框实测一次自然语言定位。验证报告在 E 盘发布工作目录。回退时先保存手头模型，再通过所用实例的 BWTL 管理器回退到 0.23.0-local.assemblyworkbench.55，随后正常重开 Creo。
