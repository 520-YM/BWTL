# 第 261–270 项 阵列与紧固件

打开顶层装配的主表示，退出动态定位。从「BWTL → 插件功能 → 阵列与紧固件」选择，或在聊天中描述任务。先用组件树和定位参照功能找到实际实例、安装面和圆柱面。

| 编号 | 功能 | 范围 |
| --- | --- | --- |
| 261 | 直线组件阵列 | 沿总装轴等距复制；数量含原件，2–24。 |
| 262 | 矩形组件阵列 | 按平面内两个总装轴放置，含原件最多 24 个。 |
| 263 | 圆周组件阵列 | 绕指定总装轴转动组件位置和方向，按右手规则；总数含原件。 |
| 264 | 按孔阵列安装组件 | 对选定同一板面上最多 12 个实际圆柱孔放置紧固件。 |
| 265 | 镜像布置组件 | 镜像安装位置和方向。只有确认零件可关于指定局部坐标面复用时用 SAME；左右手件使用已有对侧模型及明确的局部反射轴。 |
| 266 | 安装螺栓垫圈螺母组合 | 在板两侧放置螺栓、垫圈和螺母，核对轴向、几何适配及有效长度。 |
| 267 | 批量安装压铆件 | 按选定孔位布置已有压铆件模型，超过指定直径过盈时拒绝。 |
| 268 | 核对紧固件规格 | 只读。测孔径、杆径和实际夹持厚度；用输入的螺纹参数计算有效啮合长度，螺纹起点从螺栓承压面沿穿入方向计算。 |
| 269 | 批量更换同规格紧固件 | 只替换列明的实例，核对杆径和安装接口，保留位置及可验证的约束，返回新 ID。 |
| 270 | 检查漏装和重复安装 | 只读。统计指定型号的同轴杆段是否实际进入各选定孔口，列出漏装和重复。 |

第 261–263 项生成独立组件实例。源件移动时，副本需另行调整。第 265 项使用用户指定的对侧模型，或者复用已确认关于指定局部坐标面可镜像的零件。第 264、266、267 项使用实际几何计算位置后固定。底板可来自已解析的实例路径，采用与总装一致的长度单位。孔列表最多 12 个，拆分成两个半圆柱面的同一孔只填写一次。

第 266 项以一个可识别的贯通孔连接同一板件的两侧，使用已有的螺栓、一个垫圈和螺母模型。按选定的光滑圆柱定位表面核对几何；第 268 项使用用户提供的螺纹区间、螺母有效深度及最低要求计算啮合。第 270 项只核对指定型号及所列孔位。

批量替换先保存恢复副本，再核对所有新实例，最后批量移除旧实例。支持未约束、单固定约束，或可按同名且几何一致的参照重建的简单定位。选中件须为无下游依赖的普通直接零件，替换后实例 ID 会变化。装配改动默认未保存。

本机用 Creo 10 验收四孔板、三件组合、正负检查、批量回滚和实例选择。回退时保存需要保留的装配，退出对应 Creo 会话并在对应安装根目录运行 `BWTL-Manage.exe -Rollback`，上一版为 `0.23.0-local.components.1`。
