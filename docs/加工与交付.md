# 加工与交付（第 221–230 项）

入口为「BWTL → 插件功能 → 加工与交付」。选一项后补齐实际参数再发送。输出位于当前 Creo 工作目录下新建的子目录，同名目录会被拒绝。完成前先在临时目录生成并检查。建模源文件不需要保存。第 226、230 项只检查结果，无须填写输出目录。

| 编号 | 功能 | 使用条件与输出 |
| --- | --- | --- |
| 221 | 板料下料尺寸表 | 指定单实体钣金的驱动侧固定平面。输出 blank-sizes.csv，记录板厚和展开外轮廓的 X、Y 包络尺寸。包络按实际展开坐标计算。 |
| 222 | 折弯工序表 | 读取单实体钣金当前成形的圆柱折弯，按模型特征顺序输出 bend-sequence.csv。列出内 R、角度、轴向长度和展开弧长。机床折弯顺序、方向与模具需由工艺人员确认。 |
| 223 | 孔加工清单 | 支持模型默认 XYZ 或指定坐标系。hole-operations.csv 列出完整圆柱孔段的直径、轴向跨度、两端坐标及孔段类别。螺纹、刀具和深度需结合图纸核对。 |
| 224 | 喷涂面积清单 | paint-areas.csv 支持全部实体边界（含内壁），或合计最多 16 个明确指定的实体面，单位为 mm²、m²。 |
| 225 | 批量生成平板下料 DXF | 最多六个已加载钣金模型，各自指定驱动侧固定面。全部生成且逐份回读通过后，才发布整批 DXF。 |
| 226 | 下料 DXF 出图前检查 | 对临时展开结果检查毫米单位、图层、受支持图元、重复线或曲线、端点闭合及外形包络。 |
| 227 | 二维孔位模板 | 选择实际孔口平面与原点在该平面、+Z 朝外的坐标系。hole-template.dxf 输出面外轮廓和完整圆孔口，hole-centers.csv 输出孔中心和直径。适用解析直线、圆弧、圆，非圆内环单独计数。 |
| 228 | 关键尺寸检验表 | 每次最多七个驱动尺寸符号或默认轴向包络 X/Y/Z。给出名义值、下偏差绝对值、上偏差绝对值。inspection-dimensions.csv 按模型值判断，超差也会记录。实际制件需另行测量。 |
| 229 | 按料号与版本整理输出 | 最多六个已加载单实体零件。读取字符串 PART_CODE，缺少时取 DRAWING_NO，版本取 REVISION。每组输出 STEP 和加工信息表，release-index.csv 记录相对目录、STEP 文件及 SHA-256。 |
| 230 | 导出后回读检查 | 将导出目录设为工作目录，提供其中的 STEP 或 DXF 文件名和毫米容差。STEP 临时导入后比较包络、体积、表面积及三向各 7×7 条射线。DXF 与当前原生展开按图层逐图元匹配，需要同一固定平面。 |

DXF 采用 ASCII 和毫米插入单位，切割图层为 OUTLINE、HOLES，折弯中线为 BEND。支持 LINE、ARC、CIRCLE。轮廓检查覆盖端点连接和重复项，套料、刀路补偿、轮廓自交与机床可加工性仍需用工艺软件核对。STEP 的射线比较属于几何抽样，特征树与制件检验另行核对。含自由曲线、无法核实的复杂展开或多实体模型可能被拒绝。
