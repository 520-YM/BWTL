# BWTL 装配专项检查

适用本机版 0.23.0-local.assemblyworkbench.55。在 Creo 激活顶层装配，从「BWTL → 插件功能 → 装配专项检查」选功能，也可在聊天中直接说明要检查的组件。按最新装配树里的 ID 定位实例。排序定位使用总装坐标，零件方向以实际安装坐标系为准。输入尺寸按毫米，角度按度。

| 清单序号 | 检查范围 |
| --- | --- |
| 1、9 | 搜索模型名并按总装 XYZ 排序。重复或位置相近时提示补参照。完整路径能逐层核对模型和位姿。 |
| 2 | 对两个活动零件扫描可读取的基准轴、圆柱和平面，列出满足当前距离和夹角公差的候选。接触范围、孔杆用途和接触侧需要核对。 |
| 3、53 | 根据给定的局部方向和总装方向测角度，检查单个组件或一组风扇。 |
| 4、5 | 检查缺失参照及同类型同参照重复或不一致的约束，说明封装件、单同轴和单平面约束的自由度。组合约束返回 Creo 状态及读回明细。 |
| 21–23 | 读取两个平行实体面的实际间距。用给定的同螺纹和头型候选选螺钉长度，按供货方尺寸检查盲孔顶底或沉头齐平。 |
| 25 | 已实现首侧孔口、孔径和板厚检查。安装边距和背面突出量仍须根据压铆件规范核对。 |
| 26 | 实测夹层厚度并按输入的制造商夹持范围、所需成形空间和可用净空判断。 |
| 34 | 读矩形窗口和玻璃实际外形。给定均匀温差和两种膨胀系数，按玻璃中心随框体、玻璃向四边自由膨胀计算四周余量。 |
| 37 | 读有共同投影范围的相向实体平面，按所选门缝逐对输出范围和差值。 |
| 57 | 在指定重力坐标系 +Z 量测所选底面与排水口壁面最低点的高差。 |
| 92 | 按明确批准料号和版本核对 Creo 属性，分别列出不符、未覆盖及缺属性的实例。 |
| 95 | 比较 Creo 两平行面的距离、给定的图纸名义和样机实测，按图纸公差判断。 |

这些专项检查不会写入 CAD 模型，也不会保存模型。独立验证使用同模型重复部署、嵌套子装配、圆柱孔、相向面、窗口和玻璃样件，并核对原装配版本标记以及工作目录。BWTL 与旧 Codex–Creo 桥接分开加载。

回退时，先保存自己的 Creo 模型，再通过该实例安装目录下的 BWTL 管理器回退到 0.23.0-local.recovery.54，随后正常启动 Creo。
