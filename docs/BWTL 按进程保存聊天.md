# BWTL 按 Creo 进程保存聊天

每次启动新的 Creo 进程，BWTL 从空白聊天开始。本进程内关闭再打开聊天窗口会保留本次内容。

聊天按进程保存到当前 BWTL 数据目录下的「聊天记录」文件夹。每份文件夹名称包含 Creo 的启动日期、时间和进程号，包含以下内容。

- chat-history.md 保存本进程的完整对话，每条发送和回复后立即写入。
- recent-context.txt 保存本进程的近期上下文。
- last-native-details.txt 保存本进程的执行明细，在发生原生操作后生成。
- attachments 保存本进程的图片附件。

首次升级后，「历史记录_升级前」保存旧版累计聊天、近期上下文、执行明细和导入历史的完整副本。旧版附件仍可在原数据目录的 attachments 文件夹找到。原始历史文件继续保留。

本机主配置的归档目录为 E:\BWTL-Data\AppData\Local\BWTL\data\聊天记录。其他独立配置分别保存在 BWTL-Instances\2–8\data\聊天记录。长期记忆、建模方法库和装配方法库按原数据目录继续保存。

归档失败时，启动会说明无法保存的原因并保留旧文件。每条聊天实时保存，正常退出或意外退出后的新进程都会创建新的一份。

可以在独立配置输入一条聊天，关闭 Creo 后再次启动，核对窗口为空白且上一份 chat-history.md 完整。需要回退时，在 BWTL 管理工具中选择 0.23.0-local.residentchat.1，保存工作后重开 Creo。旧版会读取数据根目录中的旧上下文，按进程生成的归档文件仍可直接查看。
