# 版本管理

- `VERSION` 是当前唯一发行版本号：`0.18.0-preview.1`。窗口 v18 是原界面版本，两者在此首个发行版本对应。
- `main` 保存当前开发状态；每次有意义的修改保留 Git 提交说明。
- 正式发行需同时更新 VERSION、CHANGELOG 和对应发行说明，不修改已发行版本的包。
- 使用 `v<VERSION>` 标签指向实际发行提交，Release 附 Windows x64 ZIP 和校验和；当前是预发布版。
- `SHA256SUMS.txt` 校验公开程序、数据备份和完整历史快照，`owner-backup/manifest.json` 逐项校验原始109个文件。
- 历史 v1～v18 的已有文件保存在 archive 快照及 docs；没有完整原始源码的历史版本不伪造 Git 标签或源代码时间线。
- 版本变更约定：补丁版本用于缺陷修复；次版本用于兼容功能增加；主版本用于不兼容变更。预发布先经过读取、聊天、自检和测试模型验收。
- 发布工作流只发布仓库中已经准备的包，不在 GitHub 公共运行器上分发/安装 PTC SDK 或取得开发许可。
