# 第 61–70 项曲面与多实体

本机版本 `0.23.0-local.surfaces.1`，验收环境为 Creo Parametric 10.0.0.0。在「插件功能 → 曲面与多实体」选取功能，或直接发送明确的建模要求。尺寸使用毫米、角度使用度；默认不保存。曲面特征保留草绘、曲线、轴或曲面参照。建模前读取当前有效参照，修改后重新读取，不沿用历史 ID。

| 编号 | 功能 | 当前支持范围 |
| --- | --- | --- |
| 61 | 拉伸曲面 | 单开放链或单闭环关联草绘、深度及正反方向 |
| 62 | 旋转曲面 | 关联草绘、同平面基准轴、角度和方向 |
| 63 | 边界混合曲面 | 一个方向的两条连续开放曲线特征，自由边界；四边网络和切向条件尚未开放 |
| 64 | 闭合边界补面 | 单闭合平面草绘补面；不能代替非平面孔洞修补 |
| 65 | 曲面等距偏移 | 按曲面法向指定正负距离，绝对值 0.001–10000；复杂自交偏移由 Creo 拒绝 |
| 66 | 曲面裁剪 | 平面、曲面组或面上的开放曲线作为工具，保留一侧；必须实际减少面积 |
| 67 | 曲面延伸 | 选曲面组的一条外边界边按距离自然延伸；拒绝内部共边和不属于该组的边 |
| 68 | 曲面缝合与实体化 | 2–7 个相邻曲面组连接；封闭后单独执行实体化，当前要求零件无已有实体 |
| 69 | 曲面加厚 | 单侧或总厚度居中分配；当前要求零件无已有实体 |
| 70 | 多实体布尔运算 | 恰好两个活动实体的合并、相减、求交，消耗工具体；附带独立实体拉伸入口 |

「读取曲面与实体参照」返回当前 `QUILT`、`SURFACE`、`EDGE`、`BODY` 编号、面积、边端点和体积。曲面组也可用其原始创建特征名引用。裁剪、延伸、缝合特征修改原曲面组，原始创建名继续作为该组入口。独立实体拉伸最多允许八个活动体，布尔运算当前一次处理恰好两个体。

例如：「用草绘 SK_A 沿正向拉伸曲面 20 mm，命名 WALL_A」；「将 WALL_A 沿法向偏移 3 mm，命名 OFFSET_A」；「读取当前两个实体的编号，对目标体减去工具体」。缺少指向或方向时先补足参数；只讨论能力不会修改模型。曲面生成与实体生成分别验收，不能将曲面面积当作实体完成证明。

## 实现与验证

各功能的执行文件在 `src/功能/surface_tools/`，协议在 `src/surface_plan.h`，AI 协议说明在 `src/surface_prompt.h`，菜单在 `src/native_feature_catalog.h`，文件索引在 `docs/feature-files.json`。原生模块随 DLL 编译，新增文件需要编译、回归和安装，不能仅放进文件夹就生效。

大部分功能使用本机 Toolkit 的原生元素树。Creo 10 无法导出本次原生边界混合的完整元素树，因此第 63 项使用 `resources/udf/bwtl_boundary.gph.1` 原生模板，通过 Toolkit 绑定本次两条曲线参照、独立放置并解组。结果不依赖外部模板文件继续存在。模板源为本机独立诊断模型；`tests/native_surface_seed.c` 记录生成过程，`FIRST_CURVE`、`SECOND_CURVE` 是两个特征参照。产品执行过程不使用录制鼠标或任意宏。

原生验收为 `tests/native_surfaces.c`：在独立临时 Creo 会话核对实际面积、正负偏移距离、厚度体积、封闭组实体化体积、布尔结果、父参照、重生成及失败后的特征清单和原曲面。测试证据和本机安装记录位于 `C:\Users\Administrator\Documents\BWTL-61-70`。其他 Creo 版本及其他电脑未通过本轮验收。

## 启用与回退

安装后新开的 Creo 窗口加载此版，已经运行的窗口仍使用原先 DLL，不强制退出或重启。聊天、记忆、旧版本和各会话独立数据保留。BWTL 自己的配置、注册、原生接口、诊断和运行进程继续与旧 Codex–Creo 桥隔离。

回退时先保存自己的模型并正常退出对应 Creo 窗口，再用本机 BWTL 安装管理切回 `0.23.0-local.advsolid.1`。安装备份及 `active.json` 保存原版本路径；不要覆盖运行中 DLL。用户数据目录不随程序版本切换。
