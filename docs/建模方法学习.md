# 学习建模方法

在「仿照模型」选择「按原步骤重建当前模型」或「按原步骤重建并试改尺寸」。实体件和钣金件通过原生特征、几何和保存重开验收后，插件自动保存 UTF-8 的 .bwtlmethod.txt。批量按原特征重建的通过项也会自动存档。使用「保存最近的建模方法」可以查看本会话最近一次成功记录，或在写盘恢复后重试。部分完成、临时改型和仅依据中性几何推断的结果未通过这套原特征验收。

记忆文件记录特征顺序、草绘归属、父特征、阵列及实际读取到的驱动尺寸和约束。数据保存在所选数据盘的实例 data\建模方法库。「查看学习记忆」会按磁盘实查显示零件与装配的可用案例。多个 Creo 实例各使用自己的方法库。

后续直接说用途、尺寸和想沿用的做法。例如「按学过的钣金首壁与独立切口方法，画一块 110 × 70 mm、厚 3 mm 的钣金板，在中间开一个 Ø10 的通孔」。BWTL 挑选相关案例，按新尺寸和当前实际参照编排可编辑的原生操作。也可以从「已验证的做法」菜单填入钣金首壁与独立切口指令。公共示例的首壁和圆形切口各有独立关联草绘。

本地学到的行业方法由用户管理。公共安装包内置独立验收时生成的通用示例，不嵌入私有会话、模型或方法数据。

需回退时，保存手头模型并退出对应 Creo，再使用 BWTL 管理入口回退上一版本。可直接备份本实例 data 下的两类方法库目录。
