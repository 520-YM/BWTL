# v18 消息分区

原生 RichEdit 中按消息类型分成带底色的区块，标题加粗，消息之间留白：

- 你：浅蓝色。
- AI：浅绿色。
- 执行结果（包括失败回执）：浅紫色，不用绿色暗示成功。
- 模型信息：浅黄色。
- 提示：浅灰色。

采用原生 RTF 表格单元格铺设消息区底色，正文的反斜杠、花括号及 Unicode 均转义处理。聊天记录保存格式不变；既有“用户：”“助手：”“原生执行结果：”记录按相应类型识别。

缩放窗口时重新计算消息宽度，并清除旧按钮位置的背景残影。自动跟随末尾、翻阅历史保留位置、中文输入及后台回复定时器保留。

隐藏原生控件测试通过：五类消息实际背景色、中文及 emoji、RTF 字面文本、长记录完整性、窄窗口重排、滚动位置和输入不变。测试没有显示窗口、截图或操作桌面输入。正式 DLL 编译通过；Creo 内显示仍需加载新版确认。

protk.dat 指向 codex_native_ai_v18.dll；重启 Creo 后加载。此前注册配置保存在 protk.before-v18.dat，旧 DLL 保留。
