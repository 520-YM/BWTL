# BWTL 第 26–30 项

本机版本 `0.23.0-local.refinement.1`，验收平台为 Creo Parametric 10.0.0.0。在独立普通单实体零件中使用「智能协作」。第 26–29 项位于「插件功能 → 实体造型与加工」，删除位于「插件功能 → 修改、文件与装配」。当前零件由用户保存。

| 项目 | 输入与范围 |
|---|---|
| 26 单面定角拔模 | 指定一个实际平面、中性面、方向参照平面及正反向。角度 0.1°–30°，方向垂直于中性面。 |
| 27 开放草绘轮廓筋 | 指定单一开放轮廓、材料填充侧、筋厚及厚度放置。开放草绘须能和现有实体形成封闭的筋轮廓。生成 Creo 原生轮廓筋并保持草绘关联。 |
| 28 特征几何镜像 | 指定已有孔、标准拉伸凸台或切口及镜像平面。用 Creo 柔性建模镜像源特征的最终实体表面，保留与源特征和镜像面的关联。 |
| 29 线性与圆周阵列 | 指定一个活动源特征、方向、2–20 个总实例。线性用平面法向和毫米间距，圆周用基准轴和每步角度。总数含源特征。首批源类型是独立孔、切除及拉伸／旋转等实体加料，实际生成须通过单实体和每项有效几何检查。 |
| 30 删除指定叶子特征 | 明确说“删除”并写出精确特征名，插件从当前快照核对 ID。先检查可见依赖、分组、阵列、嵌入和只读状态，保留单实体后才执行。 |

删除前在对应 Creo 会话的 `deletion-backups` 目录中保存独立副本，并在副本中试删。确认副本仍有健康实体、其余特征 ID 完整后，才对当前零件执行。需要恢复时，在 Creo 中打开回执给出的副本文件。备份名含进程和时间标识，原文件由 Creo 的正常保存流程管理。

原生验收使用 `tests/Run-NativeFoundation.ps1 -Suite Custom`，加载 `tests/native_refinement.c`，核对拔模增减料体积、轮廓筋体积、镜像孔位及凸台／切口体积、线性与圆周实例的实际位置，以及拒绝操作后的原特征和体积。曲面集合按 PTC SDK 要求使用专用引用句柄，并由所属集合释放。[PTC 柔性建模镜像接口](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/user_guide/Mirror_Feature.html)

回退前先保存并正常退出目标会话，再从对应 BWTL 安装管理回退至 `0.23.0-local.holeshell.1`。
