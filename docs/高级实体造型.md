# 第 51–60 项高级拉伸、扫描与放样

适用本机 BWTL 0.23.0-local.advsolid.1 和 Creo Parametric 10.0.0.0。打开普通实体零件，从「插件功能 → 高级拉伸、扫描与放样」选功能，填写参数并发送。也可直接描述要执行的操作。尺寸用毫米，结果默认留在当前模型中，由用户保存。

| 编号 | 功能 | 输入与范围 |
| --- | --- | --- |
| 51 | 对称拉伸 | 闭合草绘、加料或切除、每侧深度。总深度等于每侧深度的两倍 |
| 52 | 拉伸到指定参照 | 指定平面或基准面。选择「下一面」时，适用由平面构成的单实体和单圆或直线闭环草绘。轮廓及中心的检测点须沿指定方向命中同一实际面，生成关联该面的特征 |
| 53 | 双侧不同深度拉伸 | 闭合草绘、加料或切除、第一侧方向及两个独立深度 |
| 54 | 薄壁拉伸 | 单个开放草绘、拉伸方向与深度、壁厚和厚度所在侧。可将壁厚居中 |
| 55 | 多段路径扫描 | 同一特征内 1–16 段首尾连续的开放路径，使用恒定圆截面。分叉或断开的路径会被拒绝 |
| 56 | 非圆截面扫描 | 选择矩形、椭圆或单闭环自定义草绘，也可用圆截面。自定义轮廓复制到扫描的内部截面。扫描保留路径关联，后续修改源草绘需重新指定截面 |
| 57 | 直线路径变截面 | 空实体零件、单段直线和两个不同的圆截面直径。使用两端法向截面的关联混合实现线性变径。曲线路径和任意截面变化规律尚待支持 |
| 58 | 扫描切除 | 现有单实体、开放路径和恒定截面。沿能生成截面坐标框架的路径去料，直线路径可用关联草绘。空切会被拒绝 |
| 59 | 多截面实体放样 | 依次选择 3–7 个位于不同平行平面的单闭环草绘。相邻截面分别生成原生混合并合成单实体。矩形与长圆槽的混合已经验收 |
| 60 | 螺旋扫描 | 选择基准坐标系，沿正 Z 给出直径、螺距、圈数和左旋或右旋。支持圆、矩形、椭圆截面和加料、切除。螺距和轨迹直径均须大于截面包络尺寸 |

例如「在当前零件，用闭合草绘 SK_A 对称加料，每侧 6 mm，命名 SYM_A」。制作弹簧可发送「沿 PRT_CSYS_DEF 的正 Z 轴做右旋螺旋扫描加料，轨迹直径 30 mm，螺距 12 mm，两圈，圆截面直径 3 mm，命名 SPRING」。

执行模块在 `src/功能/advanced_solid`。拉伸使用原生深度和参照元素。扫描使用原生恒定截面，螺旋的轨迹是可编辑的方程基准曲线。Creo Toolkit 的扫描建树接口支持恒定截面，第 57 项采用平行混合实现已经验证的直线变径范围。 [PTC 拉伸元素](https://support.ptc.com/help/creo_toolkit/protoolkit_plus/usascii/creo_toolkit/api/dita/proextrude_h.html) · [PTC Toolkit 扫描](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r12/usascii/creo_toolkit/user_guide/Sweeps_in_Creo_Toolkit.html)

原生验收入口为 `tests/native_advanced_solid.c`，在独立 Creo 临时工作目录验证几何尺寸、体积、参照、重生成和错误恢复。打开新的 Creo 窗口即可加载当前安装。回退时先保存模型并正常退出相关窗口，再用 BWTL 安装管理切回 0.23.0-local.advsketch.1。
