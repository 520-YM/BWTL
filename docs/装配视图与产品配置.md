# 装配视图与产品配置（第 321–330 项）

本机版本 0.23.0-local.asmviews.1。在 Creo 10.0 顶层装配中打开「BWTL → 插件功能 → 装配视图与产品配置」。在 BWTL 中说明操作对象和所需结果。需要指定组件时，从当前组件树读取实例 ID。同一零件的不同实例有不同 ID。

| 编号 | 功能 | 使用说明 |
|---|---|---|
| 321 | 建立简化表示 | 按明确的顶层模块建立原生简化表示。 |
| 322 | 按模块隔离显示 | 只显示指定顶层模块，可切回主表示。 |
| 323 | 保存装配视图 | 记录或恢复命名视角。 |
| 324 | 建立装配剖切视图 | 按顶层基准面和偏距建立或恢复剖切。 |
| 325 | 创建装配爆炸视图 | 按实例与三轴位移显示原生爆炸状态，可恢复装配显示。 |
| 326 | 生成装配顺序图 | 按指定组件顺序输出 SVG 包络示意图。 |
| 327 | 建立产品配置表 | 记录多个零件型号组合并核对同名安装坐标系。 |
| 328 | 按配置切换组件型号 | 应用选定配置并核对装配约束和位置。 |
| 329 | 比较不同配置的零件和位置 | 对比两个装配的零件型号、实例与位姿。 |
| 330 | 生成订单专用装配副本 | 按配置在新目录保存不同名的订单装配。 |

## 视图

- 321 创建命名简化表示，保留指定的顶层零件或子装配。322 可创建并激活隔离表示，也可恢复命名表示或切回主表示。继续编辑装配之前先切回主表示。
- 323 保存当前视角，之后可按名称恢复。324 支持顶层基准面及沿法向的毫米偏距，0 表示直接用基准面。
- 325 为最多 7 个顶层组件分别指定沿装配 X、Y、Z 的毫米偏移。可以按名称重用，也可以恢复装配显示。实际组件定位不会随爆炸显示改变。
- 326 按输入顺序逐步突出新加入的组件，输出为 Creo 当前工作目录下新文件夹中的 `sequence.svg`。图形使用装配 XY 投影包络，适合说明加入顺序。
- 命名视图、简化表示、剖切与爆炸状态随装配保存。BWTL 默认保留在当前会话，按需在 Creo 中手动保存。

## 产品配置

- 327 在工作目录的新文件夹写出 `config.txt`，一张表最多 5 条替换规则。同名配置下的规则一起应用。每条规则填写配置名、顶层实例 ID、原零件、新零件、安装坐标系。新旧零件的单位和同名坐标系的原点、方向须一致。
- 328 应用前检查旧型号、安装坐标系、定位约束和下游依赖，保留恢复副本。一次替换一组选项并回读组件位置，成功后由用户决定是否保存。Creo 会给新实例分配新 ID，原配置表绑定到替换前的模板实例。试另一种配置时从原模板或恢复副本开始。
- 329 对比不同名的两个实际装配。先以实例路径比对，报告型号和位置变化。对有限规模的装配，编号不同的顶层实例只有在两边位姿唯一对应时才配对，并在报告标明。无法对应的实例列入新增和移除。
- 330 从当前模板和选定配置生成不同名的订单装配。订单装配文件单独保存，仍引用已有标准组件文件。打开副本的 Creo 会话需要能找到这些组件。订单输出前请保存参与的组件零件，BWTL 会拦截有未保存修改的组件。配置和交付输出都使用新目录，重名时保留已有文件。

## 验证与回退

使用 `tests/native_assembly_views.c` 在独立 Creo 10.0 中运行。验收覆盖各入口、显示复原、重复名称、错误接口、多个实例替换、订单文件回读、原装配版本与工作目录保护。另运行 `tests/Run-Regression.ps1` 和 `tests/Test-Isolation.ps1`。

安装保留上一版 `0.23.0-local.asmquality.1`。需要回退时使用 BWTL 管理程序选择上一版，每个独立会话按各自安装根目录回退。保存当前工作后重新打开对应 Creo 会话。聊天和记忆由各会话独立的数据目录保留。
