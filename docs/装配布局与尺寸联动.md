# 装配布局与尺寸联动

在 Creo 10 的「BWTL → 插件功能 → 装配布局与尺寸联动」选择功能。写操作须在活动顶层装配中执行。先读取装配树和定位参照，使用本轮的实例 ID 和基准名称。

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| 291 | 建立总装安装基准 | 基于总装坐标系及三基准面建立安装原点、安装面和中心轴。 |
| 292 | 创建空间包络 | 建立用于空间预留或禁入的矩形构造主体。 |
| 293 | 建立骨架布局 | 创建 Creo 原生骨架，集中管理宽、深、高、安装面和孔位。 |
| 294 | 从骨架驱动组件定位 | 用 Creo 坐标系重合约束把组件联到骨架定位站。 |
| 295 | 建立模块安装接口 | 在模块创建安装面、中心轴、接口原点及矩形四孔位基准点。 |
| 296 | 复制公共安装参照 | 按当前装配位置把指定基准和单段直线轮廓复制为目标模型的本地参照。 |
| 297 | 修改总装控制尺寸并核对联动 | 核对线性尺寸旧值，修改后列出实际联动的组件。 |
| 298 | 检测跨零件外部参照 | 读取组件使用的外部模型、源特征及状态。 |
| 299 | 检查循环引用和断链 | 分析可读取的外部引用图，报告循环成员、断链或无法确认项。 |
| 300 | 对比两版装配布局 | 按实例路径比较两个装配的组件、位姿和指定的局部接口。 |

创建总装安装基准时，两中心面通过原点、相互正交，安装基准沿指定坐标系 Z 方向偏移。模块接口使用模块本地基准，四个孔位为基准点。为防止修改同一零件的多个位置，复制参照和模块接口限当前装配中只有一个实例的目标。

骨架使用当前装配中的原生骨架特征。BWTL_WIDTH、BWTL_DEPTH、BWTL_HEIGHT 三个站分别由 BW_WIDTH、BW_DEPTH、BW_HEIGHT 控制。可通过 294 把未约束的普通零件坐标系联到一个站。297 核对旧值，修改尺寸并重生成，再核对实际组件位姿及模型版本戳。版本戳变化与实体几何变化分别看待。

第 296 项按照当前装配位姿复制基准面、轴、点、坐标系和单段直线轮廓。结果是目标模型本地特征。Creo 原生 Copy Geometry 在本机的自动创建测试中返回失败，因此本功能采用一次性复制。源参照修改后需要重新复制。

空间包络使用独立构造主体，保留在装配结构中。空间包络与禁入区分别标记为 SPACE 和 KEEPOUT。普通写操作由用户决定何时保存。

引用诊断报告 Creo 返回的活动、丢失、抑制、冻结和不可确认状态。循环结果基于可读取模型组成的有向引用图；未加载或被抑制的范围在回执中标明。两版对比需以不同的装配模型名加载，按实例路径匹配，比较实际位移、方向和指定的局部接口坐标系。无关装配的相同编号只代表路径对应。

安装后保存现有模型并正常重开 Creo 即可加载。需要回退时，在 BWTL 管理工具中选择 0.23.0-local.mechanism.1。会话数据和程序版本分别存放。
