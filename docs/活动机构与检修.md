# 活动机构与检修

在 Creo 10 的「BWTL → 插件功能 → 活动机构与检修」选择功能，也可在 BWTL 对话中描述目标。先用「装配结构」和「读取定位参照」确认当前装配的实例 ID 与基准。

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| 281 | 建立销轴连接 | 同轴安装新零件，登记旋转轴。 |
| 282 | 建立滑块连接 | 同轴安装新零件，登记直线滑动轴。 |
| 283 | 建立圆柱连接 | 登记绕轴旋转与沿轴滑动。 |
| 284 | 设置开门角度限位 | 保存销轴或圆柱的旋转上下限。 |
| 285 | 设置滑动行程限位 | 保存滑块或圆柱的行程上下限。 |
| 286 | 切换预设机构位置 | 切换闭合、检修或开启位置，核对实际组件姿态。 |
| 287 | 分段检查运动干涉 | 采样旋转或直线运动，报告干涉和最小间隙。 |
| 288 | 检查检修门开启空间 | 围绕门轴检查各采样姿态。 |
| 289 | 检查托盘和模块抽出空间 | 检查指定方向的直线抽出净空。 |
| 290 | 检查紧固工具操作空间 | 使用工具包络零件检查直线进出空间。 |

## 连接与姿态

281–283 向当前装配装入一个已有零件的新实例。基座为顶层装配或其直接子组件。两侧各需一根基准轴、一个与轴平行的径向零位面、一个与轴垂直的轴向零位面。轴向零位面的法向确定正方向。旋转上下限允许 −179.999° 到 179.999°，滑动上下限允许 −10000 到 10000 mm。闭合使用下限，检修使用中点，开启使用上限。圆柱的两轴可分别设限，预设只移动已设限的轴。

Creo 10.0.0.0 的原生机构创建和重定义在同一装配中重复调用可触发崩溃。本版以普通 Creo 装配实例承载位置，把连接参照、限位和当前位置保存在实例参数中，由 BWTL 写入姿态并读回核对。设置限位和切换预设时，实例 ID 保持。Creo 机构拖动、原生运动轴树与动力学仿真属于独立工作流。手工移动基座或受控组件后，若实际姿态偏离记录，BWTL 会拒绝继续写入。默认由用户保存装配。

例如「给门铰的 BWTL 销轴设置 0 到 100 度的限位，再切到检修位置」。已有连接时，回执应显示同一实例的实际角度为 50°。

## 只读检查

每次比较一个移动零件与一个障碍零件。在临时装配内按 2–25 个离散姿态采样，报告干涉、最小间隙和首个未通过的位置，核对原装配及两零件的版本戳。287 可检查旋转或直线运动。288 从当前姿态旋转，289–290 从当前姿态直线平移。旋转用度，平移和间隙用毫米。若有多个障碍，可分别检查。离散结果只覆盖采样姿态，尤其窄障碍或长行程需要适当加密采样。

## 验收与回退

用独立 Creo 10 会话连续创建三类连接、设置两类限位、切换预设并核对实际姿态，再运行四种空间检查。安装后，新开的 Creo 应显示「活动机构与检修」，已有窗口保存模型并正常重开即可加载新版本。

需要回退时，使用本机 BWTL 管理工具选择 0.23.0-local.enclosure.1。已有模型中的组件及参数由装配文件保存。会话历史与记忆存放在各会话独立数据目录中。回退后可核对 Creo 启动菜单、active.json 与功能列表。
