# 带靠背凳子整件生成

在 BWTL 聊天框发送「画个凳子，尺寸自己给。自己想象。加个靠背」。BWTL 从空白 Creo 或已有模型的会话另建一个零件，生成矩形凳面、四条方腿和后侧居中的直板靠背。可以指定尺寸，也可以让 BWTL 决定。四腿和靠背与凳面连为同一个实体。全部校验通过后显示零件并回复一次，默认不保存。

给已打开的 BWTL 四腿凳加靠背，可发送「给当前凳子加个靠背」。这个操作保留当前零件的凳面和四腿。

## 验证

从 Creo 10 的空白会话发送上面的整件指令，检查模型树中的 `QP_STOOL_LEGS` 与 `BWTL_STOOL_BACK`，并核对最终回执里的尺寸和保存状态。新建整件的任何原生步骤失败时，BWTL 会尝试清理本次未保存的临时零件，并报告清理结果。

## 回退

保存需要保留的模型并正常退出对应的 Creo 会话。用 BWTL 管理器回退到 `0.23.0-local.semantic.1`，再从桌面 Creo 快捷方式启动。每个独立会话的版本备份路径记录在安装状态文件中。
