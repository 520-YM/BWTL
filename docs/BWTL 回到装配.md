# BWTL 回到装配

在子零件或子装配的独立 Creo 窗口中，在 BWTL 说「回到装配」「返回父装配」或「放回到装配体」。也可从「插件功能 → 装配与定位 → 命名与建件」选择「回到装配」。

BWTL 优先回到打开当前组件时的原装配窗口，并核对该窗口实际包含当前组件。若从其他入口打开子件，则在本 Creo 进程已打开的窗口中按实际组件身份查找所属装配。同一层级有多个候选时会列出装配名称，可指定「回到装配 M26A0181001V00.ASM」。

这是窗口切换。父装配和子件留在同一 Creo 会话，已有几何与待保存改动保留。收到 Creo 的活动窗口和模型读回后，聊天才报告已回到装配。

本机从 0.23.0-local.chatrepair.1 升级到 0.23.0-local.returnasm.1。保存工作后正常重启 Creo 即可使用。需要回退时，通过 BWTL 管理功能恢复 0.23.0-local.chatrepair.1，再正常重启。
