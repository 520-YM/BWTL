# v6：按模板新建、自动执行

当前版本 codex_native_ai_v6.dll。protk.dat 已指向新版，TEXT_DIR 为 text-model-v6，目录内保留 Creo 要求的 text 子目录和中英资源。下次启动 Creo 加载，不热替换当前插件。

## 建模方式

1. 每次从正在运行的 Creo 读取 template_solidpart，加载该默认实体模板。目前磁盘配置是 C:/PTC/Pro_Stds-C/01_start_dir/mmks_part.prt，实际文件为 mmks_part.prt.1。
2. 先检查模板没有已有实体几何，再复制为新的独立零件，不编辑或覆盖源模板，不使用无模板空白零件作为后备。
3. 检查新副本至少有三个基准面、一个坐标系，保留模板的参数、材料、单位和其他内容。
4. 优先选择法向接近 Z 的模板基准面作为草绘面，选择与其垂直的另一基准面作为方向参考，用普通凸台拉伸建立实体。截面引用模板基准面，不再使用无参照的 FIRST_FEAT。
5. 重生成后，以临时指定密度计算体积并核对理论体积。临时密度不写入模型，不改变材料密度；这避免因缺少密度而误报质量属性失败。
6. 显示新零件，不自动保存 .prt 文件，不修改此前已有模型。执行过程会产生新的 Creo 窗口，这是用户发出建模指令后的原生 API 操作，不是鼠标键盘模拟。

模板缺失、已有实体、缺少所需基准面/坐标系、无法确定垂直参照时报告具体阶段并停止，不悄悄退回无模板建模。可能留下独立诊断副本；源模板不保存、不改动。

## 直接执行

已移除“执行建模”按钮。输入完整要求后按回车发送，或点击发送给 AI；本次 AI 回复产生合法的新建模协议后，宿主直接执行，无需二次确认。缺少形状、尺寸或孔类型则先询问。

恢复聊天、重启 Creo 或收到普通讨论回复不会触发旧方案重放。旧版本留下的待执行状态在新版初始化时清除。旧文本命令“执行建模”仅为兼容保留，不是正常流程需要的一步。

当前仍限定板/长方体/圆柱和一个中心通孔。不是任意建模动作，暂不支持复杂孔位、现有模型修改、装配或二维工程图。建模结果只有原生执行日志确认成功后才报告成功。

## v8：显式尺寸与草绘坐标基准修订

修订：先查找草绘的 PRO_2D_COORD_SYS，缺失时补建；给矩形长宽、外圆直径、孔径建立明确的驱动尺寸；以最小几何尺寸设置正的求解容差，再调用 ProSectionAutodim 添加剩余约束并求解，最后 ProSectionRegenerate。取消在欠约束截面上先调用 Solve 的步骤。仍使用模板基准面参照，不使用固定几何的刚性求解替代可编辑尺寸。
