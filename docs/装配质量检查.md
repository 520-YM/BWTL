
# 装配质量检查

BWTL `0.23.0-local.asmquality.1` 的入口为「插件功能 → 装配质量检查」。先激活顶层装配，按实际实例路径选择组件。除读取重生成状态和汇总已有报告外，检查在主表示、动态定位关闭时运行。

| 编号 | 功能 | 检查口径 |
| --- | --- | --- |
| 311 | 装配重生成诊断 | 读取 Creo 当前的重生成状态、失败特征、受影响子特征和实例路径。不会触发重生成。 |
| 312 | 按区域设置间隙规则 | 屏幕、玻璃、PCB 和机箱可各自输入实例对与最小间隙。规则随本次检查输入，允许在同次输入多组。 |
| 313 | 按白名单筛选干涉 | 最多检查 16 个活动零件实例。只有登记的实例对且实测体积不超过其上限才放行。接触与正体积干涉分别处理。 |
| 314 | 检查紧固孔对位误差 | 对两处真实内圆柱孔，以第一孔中截面测量偏心量，并计算两孔轴夹角。 |
| 315 | 检查面板齐平度 | 对两个实际实体平面测最大段差和夹角。 |
| 316 | 检查多点安装面共面性 | 第一面是基准，比较至少另外两个支撑面的最大偏离和夹角。 |
| 317 | 检查装配公差叠加 | 对输入的加减尺寸链做最坏情况叠加。负间隙表示过盈。 |
| 318 | 检查重心与支撑范围 | 用 Creo 当前密度设置，把重心投影到支撑坐标系 XY 平面，测量相对于凸支撑边界的最小内侧裕量。 |
| 319 | 检查装配外形与安装空间 | 对照坐标系中输入的空间边界，测量活动实体的投影包围范围，并报告超界方向与距离。 |
| 320 | 输出装配检查报告 | 汇总本会话当前装配最近 24 次检查。报告区分实测、不符合、未核实及无记录，可在聊天中读取或导出文本。 |

312、313 的规则与白名单由用户指定，本次检查的数据会进入当前报告。314–316 需要实际实体面编号，315–316 不采用基准面代替测量对象。317 以输入的尺寸链为准。318 需要按周向排列的 3–12 个凸多边形顶点，重心投影判定不涵盖动态载荷。319 的允许空间是指定坐标系里的长方体范围，可检查全部活动实体或仅核对指定实例。

报告会复核装配和组件版本、实例位置及工作目录。变更后应重新测量。导出时提供新的报告目录名，BWTL 在当前 Creo 工作目录创建该目录并生成 UTF-8 的 `report.txt`，拒绝已存在的同名目录。质量测量和报告不修改模型。

## 验证与回退

独立 Creo 10.0 测试使用已知间隙、干涉体积、孔轴偏心、面间段差和超界量的装配，核对读回数值、失败或未核实标识、报告导出、重名保护和旧报告失效。测试入口为 `tests/native_assembly_quality.c`。软件回归与隔离检查使用 `tests/Run-Regression.ps1` 和 `tests/Test-Isolation.ps1`。

正在运行的 Creo 会话保存后正常重启即可载入新版。需回退时，使用 BWTL 管理器恢复 `0.23.0-local.fieldwork.2`。
