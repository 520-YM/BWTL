# 霸威天龙 v18 功能表

更新日期：2026-10-28。适用环境：当前为 Creo Parametric 10.0.0.0 编译的原生助手。

本表按当前源码、已有测试记录和用户反馈整理。**“已接入”表示程序已有实现，不代表所有实际模型都验证成功。执行是否完成，以当次原生执行回执为准。**

## 三、读取基本信息

默认点击“读取当前模型”，或输入 `读取模型`、`读取基本信息`。以下字段按实际返回结果显示；未获取到的数据不会编造。

| 编号 | 功能 | 输出内容 |
|---|---|---|
| C01 | 读取名称 | 当前目标模型名及 prt/asm 后缀 |
| C02 | 读取类型 | 实体零件、钣金零件或装配 |
| C03 | 读取外形尺寸 | 当前几何包络尺寸，换算为毫米；空实体零件显示暂无实体 |
| C04 | 读取材料名称 | 读取指定材料参数，有效名称不存在时显示“未指定” |
| C05 | 读取重量 | 使用 Creo 质量属性返回值和质量单位；无法获取时明确提示 |

基本读取不遍历特征、尺寸、全部参数和边面，不输出内部编号或调试字段。默认摘要格式已接入；用户已反馈基本信息显示，v18 消息底色另需实际加载确认。

## 四、按需读取详细信息

| 编号 | 功能 | 本地命令 | 范围与限制 |
|---|---|---|---|
| D01 | 读取详细尺寸 | `读取详细尺寸` | 尺寸符号、原值、类型、所属特征及关系驱动等标记 |
| D02 | 读取特征信息 | `读取特征` | 特征名称、ID、类型和状态 |
| D03 | 读取模型参数 | `读取参数` | 已有模型参数的名称、类型、值和锁定状态 |
| D04 | 读取几何摘要 | `读取几何` | 边 ID/类型/长度，面 ID/类型/面积 |
| D05 | 展开完整读取结果 | `读取详细信息` 或 `读取全部信息` | 展开当前读取范围内的数据，不代表不限量 |

详细读取已有用户截图反馈。当前上限：256 个特征、256 个尺寸、64 个模型参数、各 64 个边和面；超限或读取失败会提示。单项详细读取仍可能带有其他项目的摘要标题。

## 六、当前零件内建模与修改

| 编号 | 功能 | 输入示例或适用范围 | 验证情况与限制 |
|---|---|---|---|
| F01 | 在当前空实体零件内创建首个矩形拉伸 | `在当前零件拉伸一个长100、宽80、高20毫米的长方体，不新建零件` | v16 起已接入；当前路径完整实机回执仍待确认 |
| F02 | 在当前空实体零件内创建正方体 | `在当前零件拉伸边长20毫米的正方体` | F01 的等边形式；不能缺少边长 |
| F03 | 在当前空实体零件内创建首个圆形拉伸 | 明确圆柱外径、高度及可选中心通孔 | 已接入；不是已有实体上的追加拉伸 |
| F04 | 修改已有驱动尺寸 | 明确目标尺寸和新值；例如将 d6 从80毫米改为100毫米 | 同一活动特征每次最多8项；关系驱动、反向尺寸及方向翻转不支持；已接入，实际场景待验证 |
| F05 | 修改已有字符串参数 | `把当前零件的 DESCRIPTION 参数改为测试板` | 参数须存在且未锁定，核对旧值；已接入，实际场景待验证 |
| F06 | 修改已有数值或布尔参数 | 支持浮点、整数和布尔，保留参数类型 | 不创建新参数，不借参数工具修改尺寸；实际场景待验证 |
| F07 | 抑制特征 | 明确指定已有孔、圆角、倒角或切除 | 仅活动、无子特征的目标；已接入，实际场景待验证 |
| F08 | 恢复特征 | 明确指定已普通抑制的上述特征 | 仅符合条件、无子特征的目标；已接入，实际场景待验证 |
| F09 | 重生成并检查模型 | `重新生成当前零件` | 检查失败特征，不自动保存；已接入 |

F01～F03 仅适用于空实体零件。基础拉伸在零件局部 XY 平面、沿 +Z；不另建零件，不适用于钣金板壁，不支持已有实体上的继续加料或切除。修改操作均以实际原生回执为准。

## 八、装配上下文

| 编号 | 功能 | 范围与限制 |
|---|---|---|
| H01 | 识别当前操作目标 | 区分装配窗口与实际激活的组件零件；已接入，装配场景待验证 |
| H02 | 读取当前装配信息 | 明确“当前装配/顶层装配/总装配”时以装配窗口模型为目标 |
| H03 | 修改装配驱动尺寸 | 使用已有尺寸工具，核对所属特征和旧值；不等于新增装配约束 |
| H04 | 修改装配已有参数 | 参数须存在且可写，核对类型及旧值 |
| H05 | 操作已激活的组件零件 | 支持范围同零件工具；需先激活正确组件，不自动选择或激活组件 |
| H06 | 修改组件后重生成所在装配 | 当前支持的尺寸/参数及基础拉伸路径包含装配重生成处理 |
| H07 | 重生成及保存当前装配 | 需明确提出；不自动清理旧版本 |

装配相关路径已接入，但不能概括为“所有装配操作均可用”。同一零件的全部实例共享模型，修改组件零件会影响其所有实例。

## 九、操作控制与校验

| 编号 | 功能 | 说明 |
|---|---|---|
| I01 | 完整指令自动执行 | 支持范围内、参数完整的请求无需再点“执行建模” |
| I02 | 缺少参数时询问 | 例如正方体缺边长时先询问，不编造尺寸 |
| I03 | 取消待执行操作或等待中的 AI 请求 | `取消操作` 或 `取消建模`；不撤销已经完成的修改 |
| I04 | 查看尚未执行的方案 | `查看方案`；正常自动模式中方案可能已经执行或清空 |
| I05 | 运行核心自检 | `自检零件工具`；创建不显示、不保存的独立测试零件，生成 `part-selfcheck.log` |
| I06 | 写入前检查目标 | 核对模型、版本、工作目录；装配组件还核对所在窗口/装配版本 |
| I07 | 核对旧值和写后结果 | 尺寸/参数等工具检查真实原值、重生成和读回结果 |
| I08 | 失败时尝试回滚 | 不能保证任何失败都能恢复；验证不通过会明确报告 |
| I09 | 拦截不合法或冲突指令 | 拒绝非法数字、多个执行协议等，不把当前操作悄悄改成另建模型 |

自检是程序提供的验证功能，不表示本轮或每台电脑的自检已经成功。尺寸、参数及抑制/恢复首次写入前要求通过相应核心自检。当前每次最多执行一项操作，不支持把复杂任务自动拆分并连续完成；“修改后保存”也不能假称已一次全部完成。

## 维护规则
