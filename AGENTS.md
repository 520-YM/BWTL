# BWTL development

- Keep BWTL separate from other Creo integrations. Use its own registration, process, source, data and logs.
- Preserve existing chats, memory and model files. Run model checks on disposable parts in a separate Creo session.
- Keep existing feature files and command protocols compatible. Run the regression suite and document feature changes, verification and rollback.
- Build with the separately installed PTC SDK. Keep credentials, logs, company files, chats and machine-specific settings out of new public releases.
