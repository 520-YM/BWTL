# 霸威天龙 v21.2 / 0.21.2-preview.1

Creo Parametric 10.0.0.0内的Windows原生AI助手，通过进程内Pro/TOOLKIT执行操作，不使用浏览器、MCP或截图键鼠模拟。

## 便捷安装

1. 双击 `BWTL-Setup-0.21.2-preview.1.exe`，选择安装目录和Creo实际读取的config.pro。
2. 由安装器配置注册和本机数据路径。完整作者聊天、记忆和功能索引在首次安装导入，升级保留安装者自己的记录。
3. 本机需准备Creo10、x64 C++运行库及可用的Codex登录环境。安装包不包含Creo、PTC SDK、公司模板和登录凭据。
4. 保存Creo工作后重启，首次按Creo提示允许插件。顶部点击“霸威天龙”，或在图形区依次按 c、d、x 打开霸威天龙 v21.2。
5. 先读取模型，再按功能说明在测试零件操作。更新支持版本并存、升级备份和回退，不自动关闭用户Creo。

详细步骤：[安装与数据迁移](docs/v20安装与数据迁移.md)。发行文件在dist；GitHub是否已有该版本以实际Release为准。

## 一键卸载

开始菜单选择“卸载霸威天龙”，或双击安装目录BWTL-Uninstall.exe。可分别选择删除程序文件和数据文件，默认保留聊天/记忆。详见[新版安装与卸载](docs/v21.1一键安装与卸载.md)。

## 功能与限制

保留此前聊天、记忆、模板空模型、基础造型、参数/尺寸和01—10工具。新增11—15：编辑独立关联草绘、真实关联投影、首个/已有单实体标准拉伸加料、定深/贯穿切除、旋转加料。

新增写入限独立普通单实体零件。自动装配、钣金专用建模、旋转切除及二维工程图尚未接通。不自动保存，不把有限测试说成任意模型都可操作。
